    Class LuaValueBuff

    数值可变的 buff，由 BuffAPI.CreateValueBuff 创建。挂到属性上之后调用 SetValue，属性会原地刷新。 A buff whose value can change, made by BuffAPI.CreateValueBuff. Once it is on a stat, SetValue refreshes that stat in place.
