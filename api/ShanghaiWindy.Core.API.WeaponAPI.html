    PredictLead(BaseInitSystem, BaseInitSystem, out Vector3)

    计算提前量瞄准点：现在开火、炮弹与运动中的目标相遇的位置（含下坠）。与游戏自己的提前量标记同一套算法， 使用射手的主武器（坦克为当前主炮的当前弹种，飞机为第一组武器）。联机时，本队看不到的敌方目标返回 false。 Compute the lead point: where a shell fired now meets the moving target, drop included. The same computation as the game's own lead marker, with the shooter's main weapon (a tank's main gun and its selected shell, an aircraft's first weapon). Online, an enemy target the local team cannot see returns false.

    Vector3 point 提前量瞄准点（世界坐标） Lead point in world space

    Type Description
    bool 是否算出 Whether a point was computed
