    FindDeep(Transform, string)

    在所有层级的子物体里按名字查找（含未激活物体，不含 root 自身），没有时返回 nil。在 C# 里一次完成，名字里不含 / 时不产生垃圾； 每一层先找直接子物体，再往下找。请在 OnVehicleReady 里查一次并缓存，返回 nil 就说明模型上没有这个节点，不要每帧重试。 Find a descendant by exact name at any depth (inactive ones included, root excluded); nil when there is none. Done in one C# call, without garbage unless the name contains '/'; each level checks its direct children before going deeper. Look it up once in OnVehicleReady and cache it: nil means the model has no such node, so do not retry every frame.
