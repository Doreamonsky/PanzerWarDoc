    GetInternalModule(GameObject)

    从模块所在的 GameObject 获取内部模块组件（不是 InternalModule 脚本本身），挂在模块物体上的脚本传 self.gameObject 即可。 模块组件在载具装配时创建：在 OnVehicleReady 里或之后调用；装配前、物体上没有模块时返回 nil。 Get the InternalModuleComponent (not the InternalModule script itself) from the module's GameObject; a script on the module object passes self.gameObject. The component is created when the vehicle is assembled: call this in OnVehicleReady or later. nil before that, or when the object has no module.
