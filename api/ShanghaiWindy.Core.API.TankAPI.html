    GetEngineState(BaseInitSystem, out float, out float, out int, out float, out bool)

    一次读取发动机和传动状态，数值与游戏的引擎声音、驾驶界面用的相同，来自本机的物理模拟。 履带车：全部有值。轮式车：开启了变速箱才有转速和档位变化，否则转速为 0、档位为 1。舰船：有转速和速度，档位为 1、倒车为 false。 固定式载具（炮台等）：转速、速度为 0，档位为 1。 Read the engine and drivetrain state in one call; the same values the game's engine sound and driving HUD use, from this machine's physics. Tracked: all values. Wheeled: rpm and gear change only with a gearbox enabled, else rpm 0 and gear 1. Ships: rpm and speed; gear 1 and reversing false. Fixed emplacements: rpm and speed 0, gear 1.
    Declaration
    [DocGen]
public static bool GetEngineState(BaseInitSystem vehicle, out float rpm, out float rpmPercent, out int gear, out float speedKmh, out bool reversing)
    Parameters
    Type Name Description
    BaseInitSystem vehicle 载具 Vehicle
    float rpm 发动机转速 Engine rpm
    float rpmPercent 转速百分比，0 到 100 Rpm as a percentage, 0 to 100
    int gear 档位，与驾驶界面显示的相同：1 为一档，履带车倒挡为 0 Gear as the driving HUD shows it: 1 is first gear, a tracked vehicle's reverse is 0
    float speedKmh 速度（公里/小时）；履带车和轮式车为车头方向的速度，倒车为负 Speed in km/h; for tracked and wheeled vehicles along the hull, negative when reversing
    bool reversing 是否在倒车 Whether it is reversing
    Returns
    Type Description
    bool 是否读到（不是地面载具或尚未装配好时为 false） Whether the state was read (false for a vehicle that is not a ground vehicle or not assembled yet)
