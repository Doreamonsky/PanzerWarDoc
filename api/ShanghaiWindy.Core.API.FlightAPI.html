    IsOnGround(BaseInitSystem)

    飞机是否着地，与游戏自己的起降判定相同：任一机轮接地；起落架放下时机轮附近有地面或建筑也算。 起落架放下且离地时，每次调用会为每个机轮做一次物理重叠检测（不分配内存），不需要每帧调用时请降低调用频率。 Whether the aircraft is on the ground, the same test the game uses for take-off and landing: any wheel touching down, or, with the gear down, ground or a building right at a wheel. With the gear down in the air each call runs one physics overlap per wheel (no allocation); call it less often than every frame where you can.
