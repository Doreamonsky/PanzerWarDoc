    Class LuaSubscription

    一次事件订阅。订阅时传入 owner（self.script）的，行为销毁时自动退订；目标载具被移除时也自动退订。也可以随时调用 Dispose 提前退订。 One event subscription. With an owner (self.script) it ends when the behaviour is destroyed; it also ends when the target vehicle is removed. Call Dispose to end it earlier.
