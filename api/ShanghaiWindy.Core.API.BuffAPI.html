    CreateValueBuff(string, bool, float)

    创建一个数值可变的 buff。用属性自带的 AddBuff 挂上一次（例如 weapon.DamageBuffedCoff:AddBuff(buff)），之后只调用 buff:SetValue(x)：属性原地刷新，不用反复移除再新建。不用时记得 RemoveBuff。 Create a buff whose value can change. Attach it once with the stat's own AddBuff (for example weapon.DamageBuffedCoff:AddBuff(buff)), then only call buff:SetValue(x): the stat refreshes in place, with no removing and re-creating. RemoveBuff it when done.
