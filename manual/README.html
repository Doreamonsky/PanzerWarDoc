    Panzer War 本地文档维护入口

    此目录是语雀不可用后的本地文档主库。现有 121 篇导出文档按 component、gameplay、mod、workshop 分类，导航和可读标题以 toc.yml 为准。

    Agent 查找文档

    1. 先在 toc.yml 搜标题并取得真实文件路径。
    2. 标题不确定时，用正文关键词搜索整个 Docs/manual。
    3. 旧语雀 slug 的本地对应关系在 legacy-yuque-links.json。
    4. 已知缺失内容和旧附件的处理结果在 RECOVERY.md，附件原始地址与替代方案保存在 legacy-yuque-attachments.json。

    本地校验

    python tools/test_manual.py

    校验工具只依赖 Python 标准库，会检查 Markdown 与 toc.yml 的本地目标、剩余语雀链接以及恢复清单。若旧内容重新带入语雀链接，可执行：

    python tools/test_manual.py --fix

    旧导出文件继续保留哈希文件名，避免破坏 DocFX 导航和图片引用；新建的人工维护页面使用可读的 kebab-case 文件名。
