    Integrate the water package

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run new-water-integration
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "sdkCheckout": "../../../Panzer-War-Mod-SDK"
  },
  "calls": []
}

    1. Check the SDK's water package

    Extract the full SDK as described in project setup. Verify that UnityProject/Packages/manifest.json declares com.windyverse.urp.water and that the SDK contains Packages/Sdk/com.windyverse.urp.water/package.json. Open Window → Package Manager and find Urp Water. Older toolkits required adding this package manually.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${sdkCheckout}/UnityProject/Packages/manifest.json"
      ]
    },
    "expect": {
      "contains": "\"com.windyverse.urp.water\": \"file:../../Packages/Sdk/com.windyverse.urp.water\""
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${sdkCheckout}/Packages/Sdk/com.windyverse.urp.water/package.json"
      ]
    },
    "expect": {
      "contains": "\"name\": \"com.windyverse.urp.water\""
    }
  }
]

    2. Check water quality

    The client uses separate quality tiers for PC and mobile. High and Ultra request geometry tessellation, enabled on devices that support tessellation shaders. The replay checks the tiers and the connected Editor's support. Check the rendered result on a map with water on the target device.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.WaterQualityTable/Get(high,false)/tessellation"
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.WaterQualityTable/Get(middle,true)/tessellation"
    },
    "expect": {
      "contains": "(Boolean) False"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.WaterSurfaceComponent/TessellationSupported"
    },
    "expect": {
      "contains": "(Boolean)"
    }
  }
]
