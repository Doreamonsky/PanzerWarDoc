    Build a separate .modpack for each target. The game requires AssetBundles built for the platform it runs on.

    Prerequisites

    • Install the matching Unity version and platform modules.
    • The project is registered in GameHub. If it is not, click Add Path in GameHub and point it at that Unity project.
    • Local file: dependencies (adjacent UnityProject / Packages layout) resolve correctly, and the SDK dependency matches the build for this platform.

    Create the soft-linked project

    1. In GameHub, select the target platform you want to build for.
    2. GameHub creates a soft-linked project for that platform; click Copy to copy its path.
    3. Open Unity Hub, click Add project from disk, and enter the path copied in step 2.
    4. Click the version, change Current Platform to the platform of the project you created, make sure the name matches, then click Open.
    5. After the project opens, check the target in File → Build Settings and wait for import to finish.

    GameHub's linked projects share source assets. Each platform keeps its own Library. Follow the GameHub and Unity Hub steps manually, then use MCP to check the target of the open project.

    Build and validate each platform separately

    1. For that platform, run Build Linked Objects to AssetBundle on the BuildPipeline.
    2. Then run Package Mod Now on the associated ModPackage.
    3. Keep the generated .modpack and its .modpack.json sidecar. Check the platform, Unity version, resource manifest and metadata, then test it in the game on that platform.

    After changing resources or switching platforms, repeat the first two build steps. The replay below verifies a Windows teaching package. Check Android and iOS builds on their corresponding platforms.
