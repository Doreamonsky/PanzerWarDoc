    Set up a mod project with GameHub

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run mod-env-setup-hub

    For a first project, follow the GitHub SDK setup guide. If your GameHub build offers Create Project, the steps below explain how to open its output.

    1. Create the project with GameHub

    1. In GameHub, select Create Project and choose an empty folder.
    2. Open the output directory and copy the path to the folder containing Assets, Packages/manifest.json, and ProjectSettings. If there is an outer folder with UnityProject inside, use the inner path and keep its neighboring local dependencies in place.
    3. Read m_EditorVersion in the generated project's own ProjectSettings/ProjectVersion.txt and follow the Unity version guide. GameHub uses the editor version declared by its project template.

    2. Open the project with Unity Hub

    In Unity Hub, select Projects → Add → Add project from disk and choose the path you copied. Open the project and wait for import and compilation to finish. If your GameHub has no project creation option, use the official SDK ZIP. The MCP recipe checks the open project.

    3. Bind the Steam game content

    Set the Steam game folder if you need the game assets in the Editor. Start with vehicle basics, the map wizard, or the voice pack walkthrough.
