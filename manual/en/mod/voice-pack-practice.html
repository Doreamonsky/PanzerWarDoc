    Following FMOD project setup, work in a usable Studio project:

    1. In the Audio Bin, create a subfolder under crew, then import the recordings.
    2. Under Events crew/ground, create a subfolder, duplicate a group with Ctrl+D, and rename the suffix (for example cn -> jp).
    3. Replace the original Playlist clips with your recordings while preserving the event parameters.
    4. Press Ctrl+2 to open Mixer and check that the new events route to dialogs. Separately, create a voice bank under Banks and assign the new events to it. Build the target platforms and check the .bank files in the corresponding folders under the FMOD project's Build directory.

    Back in Unity, create SoundBankBuildPiplineData. Assign the matching output folders for Desktop and Mobile. Use Pick Multi Banks to select the .bank files, then inspect the generated SoundBankConfig entries and platform paths before saving.
