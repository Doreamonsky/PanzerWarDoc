    Profile a Lua script

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run lua-profiler

    In an SDK project that includes Miku LuaProfiler, open Window → Analysis → Lua Profiler. Select local mode and enable Deep Lua when you need detailed Lua calls.

    Capture a short sample in a repeatable game scene. Look at self time, call count and the frame budget together. The older guide flagged frequent calls above 0.1 ms. The working budget depends on the device and scene.

    The client replay tests start, stop and reset in an isolated Lua coroutine. Profiling with the SDK window and measuring actual game cost remain pending.
