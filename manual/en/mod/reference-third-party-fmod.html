    Reference third-party FMOD banks in Unity

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run reference-third-party-fmod
    1. Collect the master bank, its corresponding .strings.bank, and the content banks from the same build. Use an FMOD version compatible with the project.
    2. Open FMOD → Edit Settings → Bank Import. For Single Platform Build, point to that platform's output folder. For Multiple Platform Build, choose the parent folder containing the actual platform folders such as Desktop and Mobile.
    3. Open the event picker after import and check that the event paths you need are present.
