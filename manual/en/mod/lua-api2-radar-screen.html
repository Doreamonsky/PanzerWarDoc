    1. Configure the ground radar

    Select the vehicle's VehicleTextData. Under Misc → AA Radar, expand groundAARadarData and enable hasRadar. The replay uses a 12,000 m detection range, 360° rotating search, and a rotation rate of 60°/s. For a directional radar, turn full rotation off and adjust the azimuth and elevation half angles.

    Field Meaning
    maxDetectionRange Maximum detection range in metres
    isFullRotation, fullRotationRate Full-rotation search and its rate in degrees per second
    searchAzimuthHalfAngle, searchElevationHalfAngle Half angles of the search region. The defaults are 45° / 30°.
    minElevationAngle, detectGroundTargets The ground-clutter filter defaults to 2° minimum elevation. Allowing ground contacts skips this filter. Range and scan coverage still apply.
    displayRanges The default display scales are 2,500 / 5,000 / 10,000 / 20,000 m.
    canUsePD, pdMinDetectableSpeed Pulse-Doppler mode and its speed threshold. The default threshold is 30 m/s.
    hasIFF Show friendly returns and mark them as friendly.

    2. Bind the script and update the list

    1. Save the script below as RadarScreen.lua and import it. On a child object of the vehicle prefab, add LuaBehaviorMono, assign the script to Behavior, save, and repack. LuaBehaviorMono walkthrough
    2. OnVehicleReady obtains the radar and subscribes to lock changes. The example refreshes contact text every 0.2 seconds. Unity can call OnGUI several times per frame, so it draws the cached text.
    3. Read the latest scan's contacts from index 0 to GetContactCount(radar) - 1. GetContact returns success, target, distance, azimuth, elevation, altitude, radial speed, and friendly status in that order. A chaff return has a nil target. Distance and altitude use metres, and radial speed uses m/s. Azimuth and elevation use the radar's frame of reference. Use GetContactWorldAzimuth for a north-up display. Use GetScanAzimuth for antenna yaw relative to its mount, from −180° to 180°.
    Behavior()
Property = {}

local RadarScreen = class("RadarScreen")
local GUI = CS.UnityEngine.GUI
local Rect = CS.UnityEngine.Rect

function RadarScreen:OnVehicleReady(vehicle)
    local ok, radar = RadarAPI.TryGetRadar(vehicle)
    if not ok then
        self.script:SetUpdateEnabled(false)
        return
    end
    self.vehicle = vehicle
    self.radar = radar
    self.lines = {}
    self.text = ""
    RadarAPI.OnLockChanged(self.script, radar, function(locked, target)
        if locked and target ~= nil then
            print("[Radar] locked " .. VehicleAPI.GetDisplayName(target))
        elseif not locked then
            print("[Radar] lock lost")
        end
    end)
    self.script:SetUpdateInterval(0.2)
end

function RadarScreen:OnUpdated()
    self.visible = self.radar ~= nil
        and VehicleAPI.IsLocalPlayer(self.vehicle)
        and RadarAPI.IsActive(self.radar)
    if not self.visible then
        return
    end
    local written = 0
    for index = 0, RadarAPI.GetContactCount(self.radar) - 1 do
        local ok, target, distance, azimuth, elevation, altitude, radialSpeed, isFriendly =
            RadarAPI.GetContact(self.radar, index)
        if ok then
            local name = target ~= nil and VehicleAPI.GetDisplayName(target) or "?"
            local bearing = RadarAPI.GetContactWorldAzimuth(self.radar, index)
            written = written + 1
            self.lines[written] = string.format("%s %s  %.1f km  %03.0f°  %.0f m",
                isFriendly and "+" or "!", name, distance / 1000, bearing, altitude)
        end
    end
    for index = written + 1, #self.lines do
        self.lines[index] = nil
    end
    self.text = table.concat(self.lines, "\n")
end

function RadarScreen:OnGUI()
    if self.visible then
        GUI.Label(Rect(20, 120, 360, 300), self.text)
    end
end

return RadarScreen

    3. Check detection and lock in the playground

    1. Drive the vehicle and turn the radar on. Bring an aircraft into the scan area and compare its displayed bearing, distance, and altitude. Turn radar off and check that the list disappears. Remote-player replicas do not scan on the local client.
    2. TryLock, Unlock, CycleTarget, and SwitchMode operate on the locally controlled vehicle. TryLock needs a contact on the radar scope and still takes the normal acquisition time. The script prints a [Radar] entry when the lock is acquired or lost.

    The MCP replay checks configuration, script binding, the missing-radar case, chaff display, expired rows, and list hiding when the radar is inactive. Detection and locking need an in-game scene.
