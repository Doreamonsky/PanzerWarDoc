    Configure Vehicle Zoom Ratios

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    This tutorial sets the binocular and sight zoom ratio ranges of a vehicle with a ZoomProfileData asset. Field names are kept exactly as they appear in the source.

    1. Create a ZoomProfileData asset

    In the Project window choose Create > A Panzer War - 装甲纷争 > G Ground Vehicle - 地面载具 > Base - 载具配置 > Zoom - 倍率 to create a ZoomProfileData asset. Expand Zoom Name (zoomName) and set Default Name to Tutorial Zoom.

    This example uses separate teaching assets and leaves existing vehicle configurations untouched.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.ZoomProfileData)",
        "${asset}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${asset}/zoomName/defaultName",
      "value": "Tutorial Zoom"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "static:UnityEditor.Selection/activeObject",
      "value": "@asset:${asset}"
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. Set the zoom ratio range

    minRatio defaults to 1.9 and maxRatio defaults to 3.5. Use positive ratios and keep minRatio less than or equal to maxRatio; this is an author constraint, with no validation here in code. The example sets minRatio = 2 and maxRatio = 8 as the low and high endpoints.

    At runtime these two values become the available ratio range: BaseVehiclePawn.GetZoomRatio reads minRatio and maxRatio from binocularZoomProfileData for binocular zoom and from zoomProfileData for sight zoom, and falls back to built-in ranges when the asset is null. VehicleCameraZoom then converts the ratio into a horizontal field of view and interpolates within that range.

    3. Vision override and thermal vision

    Enable Is Vision Override (isVisionOverride) to reveal Is Thermal Vision (isThermalVision). Both default to false; this example sets both to true. A runtime thermal lock can still disable thermal vision, so the setting does not guarantee an unconditional in-game effect.

    If you do not want to change the vision mode, keep both flags false; the zoom ratios still apply.

  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${asset}/isVisionOverride",
      "value": "true"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${asset}/isThermalVision",
      "value": "true"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/isThermalVision"
    },
    "expect": {
      "contains": "True"
    }
  }
]

    4. Assign it to vehicle parameters

    Choose the reference slot by purpose: binoculars use VehicleTextData.PSParameter.binocularZoomProfileData; the sight uses zoomProfileData on the active gun parameters. With sharedGunData, set tankFireParameter.zoomProfileData on that asset. Without a shared reference, set TFParameter.zoomProfileData on the vehicle. The same profile asset can be assigned to both slots.

    Save the parameter assets and read the references back. This recipe verifies editor assets and references; in-game FOV, thermal effects and mod loading remain unverified.

    Click to expand MCP actionsClick to collapse MCP actions
