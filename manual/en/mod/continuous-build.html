    Official mod repository

    1. Open Build modpack in the mod repository's GitHub Actions. Enter the affected packs and target platform.
    2. For a verification build, use publish=none and leave release empty. The workflow trims dependencies, fetches matching LFS objects, builds, and verifies the result.
    3. Download the .modpack and matching .modpack.json from that run's artifacts. Check the platform, GUID, and version.

    Local build manifest for an SDK project

    1. In ModPackageBuildPiplineData, reference ModPackageData and the assets to package.
    2. Add an entry to infos in the JSON file. Put the pipeline asset path in modNames and give copyInfo a platform matching the active target and a dedicated dstDir. Create the directory first. Set isPackage=true for an archive and keep isCleanDstFolder=false to preserve the destination contents.
    3. Call ShanghaiWindy.Editor.Utility_BuildPipline.BuildPiplineManifest(path) from your editor entry point and check the destination for the archive. Use Frontend.Editor.ModPackageWorkshopMeta.WriteSidecar(archivePath) if you need a sidecar.
