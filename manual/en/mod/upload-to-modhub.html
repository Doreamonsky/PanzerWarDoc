    Send a finished package to ModHub to manage release through the service.

    Open the upload center

    1. In Unity, open Framework → Editor Tools (Ctrl+G).
    2. Choose 04. Mod & Build → ModPackage Upload Center.
    3. Sign in through the panel's account section. If a Save Account option is offered, use it only on a machine you trust.

    Select the package

    • Fill in the .modpack file field, or the folder field. A folder is searched recursively for *.modpack files.
    • Build a separate package for each supported Unity build target, such as Windows (StandaloneWindows64), Android, or iOS. Multi-platform builds
    • Updates to an existing mod must keep the same stable GUID and increment the version. Keep the matching .modpack.json sidecar next to every package.

    Confirm before sending

    Upload opens a confirmation. Check the signed-in account, package, and version. Cancelling there leaves the package unsent. After confirming, check the server result or package list before retrying. Check the result even if you closed the window.

    Check the result locally

    Before uploading, run a local dry run: inspect the archive contents, confirm the platform and version, and verify the sidecar matches. A passing local check is not proof of publication; only the server result and the package list tell you what was accepted.
