    Create a mech

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run create-mech --capture
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "source": "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar",
    "vehicleData": "${fixture}/Tutorial_NativeVehicleData.asset",
    "vehicleText": "${fixture}/Tutorial_NativeText.asset",
    "vehicleInfo": "${fixture}/Tutorial_NativeVehicleInfo.asset",

    1. Prepare a rigged visual model and a separate damage model with the joints separated. Create idle, forward, strafe, and turn-in-place animations. Check how the rig lines up with the colliders.
    2. Add Animator, CharacterController, and MechAnimatorController to the same Rig object. Use Float parameters Walk and Turn for movement and turning. The legacy WalkSound animation event still resolves to a compatibility method, which currently performs no playback.

    1. Enable Is Mech in the mech parameters of VehicleTextData. For flight, enable isFlyable. To use flight animations, also enable hasFlyAnimation and configure a JetStart state and a JetLand trigger in Animator.
