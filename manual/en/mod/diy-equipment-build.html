    Build a DIY equipment mod

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run diy-equipment-build --capture
    Click to expand MCP actionsClick to collapse MCP actions

    1. Generate each part's prefab first. See 3D decorations for configuring the visual model and hitbox.
    2. Create a DIYDataBuildAssemble. Add the desired parts to Build Map. To populate it from a folder, assign a project folder containing the parts to Pack Folder, then choose Set files under folder to build. The tool rebuilds the list.

    1. Add the build group to the pipeline's linked objects and check the linked ModPackageData. Switch to the target platform, build the linked assets and the .modpack, and keep the matching .modpack.json.
    2. After installation, check that the parts can be selected, placed, and saved in the Tank Workshop.
