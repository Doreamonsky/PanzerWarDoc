    Export a vehicle workshop design as a mod

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run diy-to-mod
    1. Open the vehicle workshop settings. Under Share → Export Package, click Export. The game checks the current account's sharing permission.
    2. Check the file location in the export message. The game also tries to open Export Package inside the mods directory. Find Universal_<name>_<GUID>.modpack. It is already a ZIP archive and should keep its .modpack extension.

    Open the vehicle workshop settings in the game. Query the localized Export buttons, identify the one on the Export Package row, and pass its center in screen pixels to the click. Sharing permission is required. The directory was checked locally. The in-game click is pending verification.

      "y": "${exportY}"

    1. Send the package to the recipient and follow Install mods. To share an editable design, use Export Share Code in the workshop so the recipient can import it into the editor.
