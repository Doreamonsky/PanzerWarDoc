    Unity Editor Version Requirements

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run unity-engine-requirements

    1. Check your project's version

    Read m_EditorVersion in your project's ProjectSettings/ProjectVersion.txt. Public SDK release sdk-2026.11.04.1 uses Unity 2022.3.62f1. The DE, Free and FreeCN client source projects use Unity 2022.3.62f2.

    2. Install the Editor and platform modules

    Choose the installer for your operating system on the matching Unity release page, or install that version through Unity Hub. To build Android mods, add Android Build Support, Android SDK & NDK Tools and OpenJDK. To build iOS mods, add iOS Build Support.

    The MCP replay checks the open project's declared version and the running Editor. Complete the installation in Unity Hub.
