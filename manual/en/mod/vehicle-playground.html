    Debug a vehicle in the Vehicle Playground

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run vehicle-playground
    1. Set the Steam LuaProject path in the SDK project. Open Framework - 框架 → 0. Home Page and click Open Test Field. You can also double-click Packages/com.shanghaiwindy.middlelayer/Tools/RuntimeDebugger/VehiclePlayground.unity in the Project window.
    2. Save your scene before opening the test field. Enter Play mode and choose the vehicle and test mode. Use module damage mode to check individual components. Use HP mode to check overall durability or to start testing a vehicle whose module data is still incomplete.
    3. Click Play again in Unity's toolbar to exit Play mode when finished.
