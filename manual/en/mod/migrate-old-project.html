    Extract the complete SDK into a new directory, then bring over your own assets and their .meta files.

    1. Back up the old project and open the new one

    Copy the whole old project or keep a repository snapshot. Download the SDK as described in project setup and extract the full archive into a new directory, keeping UnityProject and Packages next to each other. Open the project with the Unity version named in ProjectSettings/ProjectVersion.txt and wait for import and compilation.

    2. Copy your assets

    Copy your own subfolders under Assets into the new project. Keep relative paths and the .meta files for both assets and folders. Unity uses their GUIDs to resolve asset references.

    3. Check references and rebuild

    Open the migrated prefabs and configuration and check for missing scripts, materials, shaders and dependencies. Follow the platform build guide to build and test each target. Keep the old project until the new one passes these checks.
