    Reduce a mesh in InstaLOD Studio

    中文 | English

    InstaLOD Studio is an optional external tool for editing a mesh before it goes back into the project. Nothing in the build pipeline depends on it; you can use it on a copy of a vehicle or prop mesh when the geometry needs decimation or cleanup that is easier outside Unity. The vendor's Getting Started guide covers installation and the general workflow.

    The button and menu labels below are screenshot observations from an older session. Treat them as the sequence to expect, not as a promise about the names in the version you are running.

    1. Set up a profile

    1. Start with a new profile: New Profile, choose the Optimize (AutoLow) template, then Create Profile. This gives you a decimation pipeline without assembling the operations by hand.
    2. Use File → Import Scene to load the mesh you want to work on. Work on a copy, so the original asset stays untouched.

    2. Decide how far to reduce

    The historic session left the default quality settings alone for a first attempt. If you need more reduction than the template gives, it is optional to switch Automatic Quality off and enter a Percent Triangles value by hand, for example 20. The percentage is a target for the operation, not a guaranteed final ratio, so read the result rather than assuming it.

    3. Run the operation and compare

    Press Start and let the pipeline finish, then compare the counts. In the observed example the scene went from 6,340 to 758 polygons and from 10,451 to 1,415 vertices. That is what that particular mesh produced with those settings; a different mesh or a different percentage will land elsewhere.

    Check the silhouette while the reduced mesh is still in the tool. A shape that looked acceptable at the original density can lose thin parts, flat panels or small details once the polygon count drops.

    4. Export to a separate file

    Use File → Export Scene and write to a new file. Keeping the exported mesh separate from the source makes it easy to compare the two and to discard the result if something went wrong.

    5. Reimport into Unity and inspect

    Import the exported file into a test folder in Unity and check it before replacing anything:

    • Silhouette: the reduced shape still reads as the same object from the angles the player sees.
    • Materials: the material assignments survived the export and still point at the intended surfaces.
    • UVs: texture coordinates are intact, so textures do not stretch or slide on the reduced mesh.
    • Pivots: the object's origin and orientation are where the project expects them, so turrets, guns, wheels and attachments still rotate and mount correctly.

    If any of these checks fails, adjust the settings and export again, or keep the original mesh and treat InstaLOD as a one-off experiment.
