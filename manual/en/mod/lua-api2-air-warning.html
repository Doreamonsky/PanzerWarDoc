    This vehicle Lua behaviour logs a warning when an enemy aircraft comes within range of the local player. It can also play an FMOD warning. Start with Lua Hello World if you need help importing and attaching a script.

    1. Import and configure the warning

    1. Create AirThreatWarning.lua under the Unity project's assets and copy the script below. In VehicleTextData → Misc → Vehicle Lua behavior, add a row, assign the script, and click Sync Properties. To bind through a prefab, add LuaBehaviorMono to an object in the owning vehicle hierarchy.
    2. Keep warnDistance at 3,000 m. Assign an FMOD event GUID to soundGuid, or leave it empty for the first log-only test.
    3. Save, repack, and test the vehicle. The script creates one query in OnVehicleReady and runs it every 0.5 seconds.
    Query field Value and use
    Kind VehicleKind.Flight matches aircraft. Other options include Any, Ground, and Army.
    Relation VehicleRelation.Enemy uses the team of the vehicle passed to Run(vehicle). Other values include Any and Friendly.
    MaxDistance warnDistance, measured in metres. A value of 0 removes that distance limit.
    MaxCount 1, so the sorted result contains only the nearest aircraft. The default capacity is 32.
    SortByDistance true, so the nearest result comes first. 
    Behavior()
Property = {
    warnDistance = { type = "number", value = 3000 },
    soundGuid = { type = "string", value = "" },
}

local AirThreatWarning = class("AirThreatWarning")

function AirThreatWarning:OnVehicleReady(vehicle)
    self.vehicle = vehicle
    self.query = VehicleAPI.CreateQuery()
    self.query.Kind = VehicleKind.Flight
    self.query.Relation = VehicleRelation.Enemy
    self.query.MaxDistance = self.warnDistance
    self.query.MaxCount = 1
    self.query.SortByDistance = true
    self.warned = false
    self.script:SetUpdateInterval(0.5)
end

function AirThreatWarning:OnUpdated()
    if self.query == nil or not VehicleAPI.IsLocalPlayer(self.vehicle) then
        return
    end
    local count = self.query:Run(self.vehicle)
    if count == 0 then
        self.warned = false
        return
    end
    if self.warned then
        return
    end
    local nearest = self.query:Get(0)
    if nearest == nil then
        return
    end
    self.warned = true
    print(string.format("[AirWarning] %s at %.0f m",
        VehicleAPI.GetDisplayName(nearest), self.query:GetDistance(0)))
    if self.soundGuid ~= "" then
        SoundAPI.PlayOneShot(self.soundGuid, self.transform.position)
    end
end

return AirThreatWarning

    2. Check when the warning repeats

    1. Drive the vehicle as the local player in the playground. Bring a visible enemy aircraft into range. Look for [AirWarning] followed by the nearest aircraft's name and distance. The script reads the first result with Get(0) and GetDistance(0).
    2. The warning should run once while detections remain in range. When the query becomes empty, the next detection can trigger it again. If you added a sound GUID, check that it plays at the vehicle's position.
    3. Check the local player, teams, and visibility. Online results follow team visibility. For scripts on maps or game modes, use RunAt(position, team) to query around a point for a chosen team.

    Older scripts polled scene rigidbodies and filtered aircraft in Lua. This example keeps one query and performs the filtering and sorting in the game. The MCP replay simulates a target appearing, remaining in range, and leaving. Check the actual sound and online visibility in game.
