    Dot and colon in Lua method calls

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run lua-self-dot-vs-colon

    item:add(3) passes item as the first argument. It is equivalent to item.add(item, 3). In function item:add(n), the first parameter is implicitly named self. Use a dot for ordinary functions that receive no instance.

    Compare the calls in Lua

    local item = { total = 2 }

function item:add(n)
    return self.total + n
end

assert(item:add(3) == 5)
assert(item.add(item, 3) == 5)
assert(math.abs(-3) == 3)

    With item.add(3), Lua assigns 3 to self and leaves n without an argument. To pass a method to an event, see Keep self in a Lua callback.
