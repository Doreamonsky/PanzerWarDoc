    Convert a vehicle into DIY parts

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run convert-to-diy-equipment --capture
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "source": "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar",
    "vehicleData": "${fixture}/Tutorial_NativeVehicleData.asset",
    "vehicleText": "${fixture}/Tutorial_NativeText.asset",
    "vehicleInfo": "${fixture}/Tutorial_NativeVehicleInfo.asset",
    "packModel": "${fixture}/Tutorial_NativePackModel.prefab",
    "vehicleName": "Docs-DIY-Convert-${runId}",
    "vehicleGuid": "fd9092ed4d67429f44c5${runId}"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}
    1. Prepare VehicleData with a matching VehicleInfo. Use the expected hull and Turret/Gun/Dym hierarchy for the main model. Check the hitbox and node positions, then save open scenes.
    2. Open the Vehicle Data Tool from the VehicleData Inspector. In the export settings, pick the model quality, assign an independent project folder, and select the hull, turret, and gun you want to export.

    1. Select Export As DIY Equipment and confirm. The tool exports the selected parts and removes new-style secondary turrets and extra fire points from the model copy. Check each resulting part asset, model pivot, hitbox, slot, and helper transform.

    Run in your editor after saving the scene and assigning exportFolder on VehicleData. Replace the variable with your VehicleData asset path.

    [
  {
    "tool": "gm_run",
    "arguments": {
      "id": "ExportVehicleDIY",
      "action": "Export",
      "params": "{\"vehicleListType\":\"List\",\"vehicleList\":[\"${yourVehicleData}\"]}",
      "confirm": true
    }
  }
]
    1. Add the intended parts to a DIY equipment build group. Build and install the mod, then check assembly in the Tank Workshop.
