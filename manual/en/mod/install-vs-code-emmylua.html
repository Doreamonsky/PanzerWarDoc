    Install VS Code and EmmyLua

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run install-vs-code-emmylua
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {},
  "calls": [
    {
      "tool": "inspect",
      "arguments": {
        "path": "static:System.Environment/GetFolderPath(LocalApplicationData)"
      },
      "expect": {
        "contains": "(String)"
      },
      "capture": {
        "localApp": {
          "regex": "\\(String\\) ([^\\r\\n]+)"
        }
      }
    },
    {
      "tool": "inspect",
      "arguments": {
        "path": "static:System.Environment/GetFolderPath(UserProfile)"
      },
      "expect": {
        "contains": "(String)"
      },
      "capture": {
        "profile": {
          "regex": "\\(String\\) ([^\\r\\n]+)"
        }
      }
    }
  ]
}

    1. Install the editor and the extension

    Install VS Code. In the Extensions view, search for @id:tangzx.emmylua and install EmmyLua. In a new terminal, use code --list-extensions and look for tangzx.emmylua. Current EmmyLua includes its own language server. Check the extension's current requirements.

    Click to expand MCP actionsClick to collapse MCP actions

    Checks the per-user installation on this Windows machine. Run the installer and Extensions actions manually.

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${localApp}/Programs/Microsoft VS Code/Code.exe"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/GetDirectories",
      "args": [
        "${profile}/.vscode/extensions",
        "tangzx.emmylua-*"
      ]
    },
    "expect": {
      "contains": "tangzx.emmylua"
    }
  }
]

    2. Add the project's API definitions

    Open the Lua source folder in VS Code. In Unity, use XLua → Generate EmmyLua for LuaCallCSharp to generate API definitions in the project's Build/EmmyLua/ folder. Include these definitions with the Lua sources in the VS Code workspace.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:GeneralEditor.Utility_XluaDefineEditor"
    },
    "expect": {
      "contains": "GenerateEmmyLuaForLuaCallCSharp"
    }
  }
]
