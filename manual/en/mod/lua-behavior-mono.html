    Attach a Lua behavior to an object

    中文 | English

    LuaBehaviorMono attaches a Lua script to a Unity scene object or prefab. This example checks the import and binding of a minimal behavior asset.

    1. Create the behavior script

    Save ExampleBehavior.lua under an asset folder in the Unity project. The project importer recognizes Behavior() as the behavior marker. Files under a LuaProject path are imported as plain text.

    Behavior()
Property = {}

local ExampleBehavior = class("ExampleBehavior")

return ExampleBehavior
    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/WriteAllText",
      "args": [
        "${script}",
        "Behavior()\nProperty = {}\n\nlocal ExampleBehavior = class(\"ExampleBehavior\")\n\nreturn ExampleBehavior\n"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/ImportAsset",
      "args": [
        "${script}",
        "ForceSynchronousImport"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. Bind the component

    Add LuaBehaviorMono and assign the imported ExampleBehavior asset to Behavior. If the script declares a Property table, use Sync Variable Property Definition to add missing instance fields. Existing values for the same names are retained. See Lua properties for instance overrides.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${prefab}",
        "mode": "create",
        "component": "ShanghaiWindy.Core.Lua.LuaBehaviorMono",
        "references": [
          {
            "property": "luaBehavior",
            "asset": "${script}",
            "type": "ShanghaiWindy.Core.Lua.LuaBehaviorScript"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "asset:${prefab}/LuaBehaviorMono/instanceLuaProperty/OverrideNilPropertyFrom",
      "args": [
        "@asset:${script}/luaProperty"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.PrefabUtility/SavePrefabAsset",
      "args": [
        "@asset:${prefab}"
      ]
    },
    "expect": {
      "contains": "--- GameObject ---"
    }
  }
]

    3. Save and verify

    Save the prefab and check that Behavior still points to ExampleBehavior. At runtime, the component on the scene object starts the behavior. See Hello World for a startup callback that prints a message.

  },

    "expect": {
      "contains": "class(\"ExampleBehavior\")"
    }
  }
