    Install Git and Git LFS on Windows if you plan to clone the public Mod SDK from GitHub. The GitHub release ZIP is ready for project setup after extraction.

    Steps

    1. Download the installer for your Windows architecture from Git for Windows.

    2. Run the installer, then open a new terminal.

    3. Run the command below. A version number confirms that the terminal can find Git.

      git --version

    If you clone the SDK with Git

    Open a new terminal, check that Git LFS is available, and enable it for your account.

    git lfs version
git lfs install

    Follow the download and clone guide to get the SDK. Fetch the large files from the repository root before opening UnityProject in Unity Hub.

    git lfs pull

    MCP checks the executables at the default installation location. Downloading, installing and cloning are manual steps.
