    1. In the Project window, choose Create → A Panzer War → P Pool → Pool Resource Identifier. A new asset gets its own GUID. To extend an existing effects pack, use the original identifier from its author.
    2. Create a VFX prefab and add PoolItemComponent to its root. For a projectile trail, assign the trail child to the component's Weapon Projectile list so replay and projectile previews can hide it.

    1. Create a Pool Resource and link the identifier. Add an entry and set Spawn Name to the key used by scripts or BulletVFX. Assign the prefab to Spawn Object. Set the instance count to -1 for on-demand allocation. Set a positive lifetime for ordinary one-shot effects. A lifetime of 0 delegates recycling to code.
