    This example registers an effect under TutorialVFX and uses it for a shell projectile. For your first shell, check the muzzle flash, projectile, and impact with the built-in effects in the tank tutorial before replacing them.

    1. Create an identifier and an effect prefab

    1. In Project, right-click and choose Create → A Panzer War → P Pool → Pool Resource Identifier. Set the display name. The game uses the identifier to list the installed effects pack as a choice, and Unity creates its GUID. To extend the old Ma Ge effects pack, obtain the original identifier from its author. An identically named new asset gets its own GUID.
    2. Put the particle effect on a separate GameObject and drag it into Project to save a prefab. Open it and add PoolItemComponent to the root. For a shell trail, add Trail Renderer to a child named Trail and assign that child to Weapon Projectile. Damage replay and projectile previews hide that trail. Save the prefab and check that the reference remains on the root component.

    2. Configure the pool resource

    From the same P Pool menu, create a Pool Resource. Assign the identifier from step 1. Expand Spawn Reses and click + to add an entry.

    Field Example Use
    Spawn Name TutorialVFX Key used at runtime. Choose a unique name for your own mod.
    Spawn Object Prefab from section 1 The pool instantiates this prefab when requested.
    Instance Count -1 Create instances on demand. Positive counts preload instances to reduce first-use stutter. Higher counts use more memory and load time.
    Life Time 3 seconds Recycle ordinary one-shot effects after this delay. Reserve 0 for effects recycled by code, such as jets of flame or beams.

    Save and click Refresh Spawn Res for Dropdown. If the key is missing, check that the entry was saved and has a prefab, then refresh again.

    3. Bind, package, and try the effect

    1. Select the shell and open its BulletVFX asset. Select TutorialVFX as the Weapon Projectile Effect. To keep the existing projectile appearance as a fallback, add TutorialVFX to the Override Weapon Projectile Effect list and leave the base key in place. Use Hit Ground or Hit Armor for impact effects. Return to the shell and verify its BulletVFX reference.
    2. If the vehicle and effect are in one pack, add Pool Resource and the vehicle to the same build pipeline. For separate packs, add Pool Resource to the effects pipeline's Linked Objects and build it. Add the effects pack's ModPackageData GUID to the vehicle pack's dependencies, then rebuild the vehicle pack. The dependency identifies a mod package. The resource identifier GUID is used for the effects pack selection.
    3. Install the builds for the same platform and shoot the ground and an armored target. Check the custom projectile, fallback effect, and one-shot effect recycling. If you see the base effect, check the exact spelling, whether the dependency loaded, and which effects pack is selected. When several installed pools have the same key, the selected effects pack has priority.
