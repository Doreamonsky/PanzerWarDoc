    Prepare models

    1. Set up the SDK project. Model in meters, with +Z forward and +Y up in Unity. Set the pivots for the body, turret, gun, and barrel. Tracked vehicles also need left and right wheels and tracks. Prepare textures, engine sounds, and firing sounds. See Blender axis correction.
    2. Make a separate damage model and follow the hitbox naming guide for armor and module nodes. Check materials and colliders after import.

    Configure assets

    1. In Framework - 框架 → 0. Home Page, open the Vehicle Creation Guide, then Open Vehicle Creation Tool. Enter a new name and create a Ground vehicle.
    2. Fill in VehicleInfo. Assign the damage model and configure modules in VehicleHitBox. Assign the main model, VehicleHitBox, and VehicleTextData to VehicleData. Configure weapons, sounds, wheel parameters, and tracks to suit the vehicle. Open the vehicle tool from the VehicleData Inspector to check model nodes and firing positions.

    Build and test

    1. In the VehicleData Inspector, click Pack Asset to generate the vehicle prefab. Pack it again after changing the hitbox or model nodes.
    2. Create a mod package for the target platform. Add VehicleInfo to its build pipeline. Install and use the Vehicle Playground to check movement, aiming, firing, and damage.
