    1. Import your decal image

    Put the image under Assets in the SDK project. A transparent PNG can preserve the area around the design. Check the texture import, its transparent edges, and orientation in the Inspector.

    2. Create the decal data

    1. In Project, select Create → A Panzer War → D Decoration → Decal. The public SDK's Assets/Template-Decal has a working layout to inspect.
    2. In VehicleDecalData, expand Texture List and click +. Drag the texture into the new row's Tex Prop asset slot and enter its Display Name. Use a separate row for each decal. The disabled Texture field shows the legacy direct reference.
    3. The Inspector assigns GUIDs to the asset and its entries. Keep those rows when updating a published decal. Enable Is OverSea for decals limited to overseas versions.

    3. Build and install the pack

    Add VehicleDecalData to the build pipeline's Linked Objects. The SDK includes Assets/ModManager/BuildPipline-Template-Decal.asset and Template-Decal.asset as a reference. Follow project setup to select the target platform, build linked resources, then package. Install the result and check the display name, transparency, and orientation in the vehicle decal list.
