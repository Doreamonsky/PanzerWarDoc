    Configure an amphibious vehicle

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run amphibious-vehicles --capture
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "vehicle": "${fixture}/Tutorial_AmphibiousVehicle.asset",
    "engine": "${fixture}/Tutorial_ShipEngine.asset",
    "buoyancy": "${fixture}/Tutorial_ShipBuoyancy.asset",
    "model": "${fixture}/Tutorial_AmphibiousBody.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    Start from an existing ground vehicle. This example keeps its ground drive and adds a ship controller.

    1. Enable amphibious control

    In the Mobility tab of VehicleTextData, expand Ship Params. Leave Is Total Controlled From Ship off and enable Is Ship Controller Enabled. Set Auto Enter Ship Controller Type to When Center Of Gravity Drown.

    This setting switches to ship control once the wheels lose contact and the center of gravity is submerged. Ground contact switches control back. Use isShip for a vehicle controlled entirely as a ship. For passive water interaction, leave both ship settings off and use the separate PassiveWaterInteractParameter settings.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar_VehicleTextData.asset",
        "${vehicle}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/isStationary",
      "value": "false"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/isShip",
      "value": "false"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/isShipControllerEnabled",
      "value": "true"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/autoSwitchShipControllerType",
      "value": "WhenCenterOfGravityDrown"
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. Set up the propeller path, engine and buoyancy

    Place a propeller node in the model prefab and add its path relative to the model root under Propeller Path. The example uses MainBody/Propeller.

    In the Project window, open Create > A Panzer War - 装甲纷争 > G Ground Vehicle - 地面载具 > Shared Data - 共享数据. Create a Ship Engine - 船舶引擎 and a Ship Buoyancy - 船舶浮力 asset. The example sets maxSpeedInKnots to 12 and buoyancyObjectLength to 6. Back in Ship Params, assign the assets to Engine Data and Buoyancy Data.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "create",
        "component": "UnityEngine.Transform",
        "children": [
          "MainBody",
          "MainBody/Propeller"
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.SharedShipEngineData)",
        "${engine}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.SharedShipBuoyancyData)",
        "${buoyancy}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${engine}/maxSpeedInKnots",
      "value": "12"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${buoyancy}/buoyancyObjectLength",
      "value": "6"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/propellerPointPaths",
      "value": "[\"MainBody/Propeller\"]"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/sharedShipEngineData",
      "value": "@asset:${engine}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/sharedShipBuoyancyData",
      "value": "@asset:${buoyancy}"
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    3. Save and verify

    After saving, check that the ground drive still uses TrackController, the ship controller is enabled, both shared assets are assigned, and the propeller path exists in the model. The example verifies the settings and path in the editor. Test the waterline, propulsion and controller switching with the complete vehicle on a map that has water.
