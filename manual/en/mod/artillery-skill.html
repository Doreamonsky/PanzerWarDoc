    This tutorial configures artillery support in a separate commander asset. The runtime skill is for offline vehicles. Verification covers editor assets and the teaching package, not an in-game salvo.

    1. Create a skill slot

    Add a skills group under CrewData.upgradableSkillContents and set the entry's friendshipRequirement to 0. Choose CrewSkillBuff for crewSkillRef, then ArtillerySkillConfig for its crewSkill. This is nested configuration rather than a standalone ScriptableObject.

    The configuration's version must equal GetVersion(), currently 3, or the skill is treated as incompatible. The recipe queries and writes that version. See the commander tutorial for basic setup and unlock conditions.

    The teaching commander reuses Aino's valid portrait references without changing that source commander. Configure your own portraits for production content; valid portrait references are required for packaging.

    2. Configure cooldown

    Set initialCdType = Ready and coolDownTime = 20 seconds. Ready starts fully charged; NotReady starts from zero. CustomRatio reveals customInitialCdRatio, the initially completed fraction of cooldown. A successful release resets the progress.

    Set the title and description on the outer CrewSkillBuff and add the translations for each. In the skill config, use hasSkillReadyVoice and hasSkillReleaseVoice if you want sounds. Enter the corresponding FMOD event GUIDs. FMOD setup

    3. Configure a shell group

    Expand spawnInfos and add one entry: dispersion = 10, attackAngle = 45, count = (2,4), timeDelay = (0,2) and fromDistance = 800. The integer count excludes the upper bound, so this example produces two or three shells. Each independently samples a delay of approximately 0–2 seconds.

    Set artilleryBulletData and add the matching loadName and actual BulletData reference to the same SafeRef's safeRefAssetProvider.assets. This example copies the existing 105-HE ammunition and uses the copied asset's GUID as the lookup key. Runtime matches that key to a reference; it does not automatically convert a display name or file path into ammunition.

    Select the copied ammunition asset. Verify the HE warhead and Bullet VFX reference in the Inspector, then check Explosion Range in the explosion settings. Review those fields for the intended in-game effect before binding a different ammunition asset to the skill.

    The local player's camera ray must hit a target. The spawn point adds an X-axis offset rotated around the global Z axis to that target point. At 45 degrees this changes both horizontal position and height; it is not a horizontal offset along the camera direction. dispersion is passed to the projectile.

    4. Save, check and build

    Save the SafeRef configuration, read back its version and serialized data, and add the commander to the teaching pipeline. The recipe builds a Windows teaching package and checks its ZIP, manifest and sidecar. It neither installs nor publishes the package.

    In-game verification still needs an offline match, enabled commander buffs, a valid commander selection and a target hit. Trajectory, effects and audio have not been tested.
