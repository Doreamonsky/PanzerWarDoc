    Record audio events with FMOD Profiler

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run fmod-profiler

    Profiler records audio events, levels, CPU usage, and memory. Set up the FMOD project and banks and load a Unity scene that can play the sound you want to diagnose.

    1. Enable the live connection

    1. In Unity, open FMOD → Edit Settings and select the platform you are testing. Use Play in Editor in the Editor or the target platform for a standalone build. Enable Live Update and read the Live Update Port. FMOD defaults to 9264. The Editor configuration used here reported 9000. Connect to the port shown for your platform. Rebuild a standalone player after changing its setting.

    1. In FMOD Studio, open the project that generated those banks. Enter Play Mode in Unity or start your test build.
    2. In Studio, choose File → Connect to Game. On the same computer, enter localhost:<port>, such as localhost:9000. For a separate test device, enter its reachable address and port. A green Live Update ON in the lower-right corner confirms the connection. FMOD Live Update

    2. Record and diagnose levels

    1. Open Window → Profiler in Studio and click the round Record button. Reproduce the issue once in Unity, then click Stop.
    2. Locate the test on the timeline. Select the event track in the left pane, look at the event instances and levels for that period, and compare them with Mixer CPU and memory usage.
    3. Open Window → Mixer and follow the event's output through its buses to the master. Listen to the running game and compare it with a Studio audition or an earlier reference recording.
    4. If timing looks correct but levels sound wrong, check the source audio, event and bus gains, and Unity volume settings separately. Save the session, change one setting, and record a second pass for comparison. Profiler can also record an audition directly in Studio. FMOD Profiler manual

    The MCP actions above read the connection settings for the Unity platform. Connect and record in FMOD Studio.
