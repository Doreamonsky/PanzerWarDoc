    Set up the mod project

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run get-started

    1. Download and extract the SDK

    Open the Panzer War Mod SDK release page, expand Assets, and download the release ZIP named Panzer-War-Mod-SDK-sdk-*.zip. It includes the DLLs and local dependencies. Extract the whole archive and keep UnityProject beside Packages so Unity can resolve dependencies. If you already have a project, start with the next step. You can also create one through GameHub.

    2. Check the project folder and version

    Check that UnityProject contains Assets/, Packages/manifest.json and ProjectSettings/ProjectVersion.txt. Install the version declared by the project using the Unity version guide.

    3. Open the project in Unity Hub

    1. In Unity Hub, choose Projects → Add → Add project from disk and select UnityProject. Check for the three paths listed in section 2 to identify the correct folder.
    2. Open the project from the list. If Hub reports a missing editor, install the version declared in ProjectVersion.txt, then open the project again. The first launch imports packages and compiles scripts.
    3. Once import finishes, check the Console. With compilation complete, look for Framework - 框架 in the menu bar. If the menu is missing, confirm that you opened the inner UnityProject folder and fully extracted the neighboring Packages folder.

    Next, set the Steam game folder if needed or build your first tank.
