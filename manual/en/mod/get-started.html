    Set up the mod project

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run get-started
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    1. Download and extract the SDK

    Open the Panzer War Mod SDK release page, expand Assets, and download the release ZIP named Panzer-War-Mod-SDK-sdk-*.zip. It contains the DLLs and local dependencies and opens without Git. GitHub's auto-generated Source code (zip) may only contain Git LFS pointers. Extract the whole archive and keep UnityProject next to Packages. For a Git checkout, follow the clone and LFS steps.

    2. Check the project folder and version

    Check that UnityProject contains Assets/, Packages/manifest.json, and ProjectSettings/ProjectVersion.txt. The verified public release sdk-2026.11.04.1 declares Unity 2022.3.62f1. For a later release, read m_EditorVersion from that download and follow the Unity version guide.

    3. Open the project in Unity Hub

    1. In Unity Hub, choose Projects → Add → Add project from disk and select UnityProject. Check for the three paths listed in section 2 to identify the correct folder.
    2. Open the project from the list. If Hub reports a missing editor, install the version declared in ProjectVersion.txt, then open the project again. The first launch imports packages and compiles scripts.
    3. Once import finishes, check the Console. With compilation complete, look for Framework - 框架 in the menu bar. If the menu is missing, confirm that you opened the inner UnityProject folder and fully extracted the neighboring Packages folder.

    4. Verify your setup with a bundled template

    1. In File → Build Settings, choose the target platform. For Windows, choose PC, Mac & Linux Standalone → Windows → x86_64. For Android, choose Android. Click Switch Platform when needed.
    2. In Project, select Assets/ModManager/BuildPipline-Template-Vehicle.asset. Click Build Linked Objects to AssetBundle and wait for it to finish.
    3. Select Assets/ModManager/Template-Blank-Vehicle.asset and click Package Mod Now. The Windows example outputs to UnityProject/Build/Mod-Package/StandaloneWindows64/Template-Blank-Vehicle/. After changing assets or platform, build the linked objects again before packaging.
    4. Follow Install mods to add the .modpack for your game's platform. For a map template, use BuildPipline-Template-Blank.asset and Template-Blank-Scene.asset in the same Project folder.

    Next, set the Steam game folder if needed or build your first tank. If your GameHub build can create projects, you can use the GameHub workflow to open the result.
