    Project download reference

    中文 | English

    1. Get the release package

    1. Open the Panzer War Mod SDK releases, expand Assets, and download Panzer-War-Mod-SDK-sdk-*.zip (public release sdk-2026.11.04.1 is about 600 MB).
    2. The same release's Assets include SHA256SUMS.txt and release.json; download both. release.json records that release's Unity information in a field named sdk.unity; the editor version string m_EditorVersion is not in release.json but in UnityProject/ProjectSettings/ProjectVersion.txt after extraction.
    3. Do not use the auto-generated Source code (zip) / Source code (tar.gz) archives; they may contain only Git LFS pointers. Follow project setup to extract and open the project, or create a project through GameHub if it offers Create Project.

    2. Verify the download on Windows

    In PowerShell, change to your download folder and replace the file name with the one you actually downloaded:

    Get-FileHash -Algorithm SHA256 .\Panzer-War-Mod-SDK-sdk-2026.11.04.1.zip

    Compare the printed Hash character by character with the entry for the same file name in SHA256SUMS.txt, ignoring case: PowerShell prints uppercase hex while the list may be lowercase or mixed case, so hexadecimal digests must be compared case-insensitively. Extract only when they match. A different file name means you compared the wrong line; a different hash means the download is corrupt or incomplete, or you fetched the wrong file or release, so check the file name and version and download it again.

    On macOS:

    shasum -a 256 Panzer-War-Mod-SDK-sdk-2026.11.04.1.zip

    On Linux:

    sha256sum Panzer-War-Mod-SDK-sdk-2026.11.04.1.zip

    3. Release ZIP versus Git and LFS

    Use the release ZIP (recommended): extract the whole archive, keep UnityProject next to Packages, and open UnityProject in Unity. The release bundles the real DLLs and local dependencies, so no Git or LFS install and no git lfs pull is needed.

    Use a Git clone: for readers who want to track repository updates or history. Install Git LFS and finish the pull before opening the project:

    git lfs install
git clone https://github.com/WindyVerse/Panzer-War-Mod-SDK.git
cd Panzer-War-Mod-SDK
git lfs pull

    If LFS has not finished, or you downloaded a source archive, binary files become pointer files. If a DLL opens as a few lines of text whose first line is version https://git-lfs.github.com/spec/v1, it is an LFS pointer rather than a real binary: for a Git checkout run git lfs pull again, and for a ZIP download use the named release ZIP instead of Source code. Pointer files cause Unity plugin-loading or DLL errors.

    The SDK is the public modding package. Official vehicles, maps and other assets live in the separate private Panzer-War-Mods repository, and the game itself is built from Panzer-War-Client. Use the SDK unless you are changing official assets or client code.
