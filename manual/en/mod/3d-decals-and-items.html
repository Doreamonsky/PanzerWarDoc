    Create a 3D decoration

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run 3d-decals-and-items --capture
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "item": "${fixture}/TutorialDecoration.asset",
    "visual": "${fixture}/TutorialDecorationVisual.prefab",
    "collision": "${fixture}/TutorialDecorationCollision.prefab",
    "hitbox": "${fixture}/TutorialDecorationHitBox.asset",
    "itemGuid": "728f6b42d4bf4915b234${runId}",
    "cooked": "${fixture}/728f6b42d4bf4915b234${runId}_pre.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}
    1. Create a DIYItemData asset in Unity and set its display name for the Tank Workshop.
    2. Keep the visual prefab's outer root empty. Place meshes, renderers, and other required components on child objects. The packer moves those children to the generated prefab. If you use LODs, check the resulting hierarchy and renderers.
    3. Assign the visual prefab to Visual Model. Assign a VehicleHitBox with a hitbox prefab to HitBox. Use Pack to generate the part prefab.
