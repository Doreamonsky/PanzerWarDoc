    Build an encrypted mod

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run encrypted-mods --capture

    Confirm that you have permission to modify and distribute the included assets.

    1. Enable Encryption in the mod build pipeline. The editor generates a key and IV for a new pipeline. Store them privately with authorized access. Retain the matching key and IV when updating an existing release.
    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${pipeline}/isEncryption",
      "value": "true"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.ModPackageBuildPipelineInspector/CreateKeys",
      "args": [
        "@asset:${pipeline}"
      ]
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${pipeline}/isEncryption"
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
