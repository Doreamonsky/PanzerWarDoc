    5. Activation

    Current buffs and skills, including summons, apply only offline while commanderCrewBuff is not closed. If effects are missing, check offline mode and commanderCrewBuff. Current code has SummonSkillsOnline = false; that is a fixed code property, not an Inspector setting to toggle.

    Click to expand MCP actionsClick to collapse MCP actions

    The fixed online rule can be queried in the editor. Offline mode and commanderCrewBuff are runtime conditions. This recipe does not launch the game or treat this query as verification of skill effects.

    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.CrewData/SummonSkillsOnline"
    },
    "expect": {
      "contains": "False"
    }
  }
]
    Click to expand MCP actionsClick to collapse MCP actions

    6. Packing and verification

    Add the CrewData asset to the build pipeline's Linked Objects (field linkedObjects). Assign valid portraits before packaging, and configure skill references and resources when skills are needed. The build emits a crew bundle keyed by the commander guid plus avatar bundles for portraits. After packaging, check the entry, portraits, unlock state and any configured skills offline.

    The shared recipe verifies editor operations, a Windows build, ZIP manifests and the sidecar for the teaching package. The package has not been installed or checked for skill effects in game. Screenshots illustrate field positions only.

    Click to expand MCP actionsClick to collapse MCP actions

    Plan and build the separate teaching package with the production builder, without publishing or installing it. In-game portrait and skill verification is still pending.
