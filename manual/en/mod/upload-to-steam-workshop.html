    Upload a mod to Steam Workshop

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run upload-to-steam-workshop --capture

    1. Run Mod-PW-Uploader/PW-Mod-Uploader.exe from the Steam installation. Create an item for a new mod, or select your existing item to update it. Supply the content, title, description, tags, and visibility. Use a preview under 1 MB.
    2. Confirm the Steam account and submit. If Steam requests acceptance of the agreement, review it from the prompt. After the upload completes, check the Workshop item's status and visibility. Steamworks Workshop API
