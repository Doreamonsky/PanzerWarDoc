    Merge PBR mask channels

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run merge-texture-channels
    1. In the mod SDK's GM Editor, open Remap PBR Masks.
    2. Assign metallic, occlusion, and smoothness. If you have a roughness map, put it in the smoothness slot and enable Is Roughness.
    3. Select Create Mask Map and save a PNG. The output uses the metallic texture's dimensions, or 512 × 512 if you omit metallic.
    Output channel Source
    R Red channel of metallic
    G Green channel of occlusion
    B 0
    A Red channel of smoothness, transformed by the tool. For roughness, the tool inverts the transformed value
