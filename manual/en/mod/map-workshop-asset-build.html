    Build props for the Map Workshop

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run map-workshop-asset-build --capture

    1. In a URP project, place the prop model at the origin and add a Box Collider or Mesh Collider. Set the root and its children to the Building layer and save the model as a prefab.
    2. Right-click the prefab in Project and choose ShanghaiWindy → DIYMap → PropFromSelection. Select an output folder under Assets. Check that the new DIYMapPropData references the visual model.
    3. In DIYMapPropData, set Render Type to URP. Click Create Prefab, then Create Icon. If Unity is still rendering the preview, wait for it and click again. Existing outputs show Update Prefab and Update Icon.

    1. Create a DIYMapDataBuildAssemble and add the props to BuildMap. To collect them by folder, set Pack Folder, click Set files under folder, and review the resulting list.
    2. Add the assembly to Linked Objects in ModPackageBuildPiplineData and build for the target platform. Check the archive for the .diymapassemble assembly and the corresponding .mapdiy prop.
