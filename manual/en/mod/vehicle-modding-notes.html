    Vehicle modding notes by 祝昔

    中文 | English

    Original notes by @情绪薫. These cases retain the author's examples and use current labels where available. Start with tank creation for a complete build.

    Find a model

    The author looked for free and paid assets on Sketchfab, GameModels3D, CGTrader, and other libraries. Some include interior meshes. Check the individual asset's terms for modification and redistribution, then check its textures, hierarchy, and scale. Sketchfab · GameModels3D · CGTrader

    Problems during creation

    1. Place model pivots

    In Blender Object Mode, open the 3D View's Options and select Affect Only → Origins. Use Move to place each pivot. Check the turret ring, the Gun elevation axis, the Dym recoil axis, and the axle centers for the road wheels and return rollers. On a regular wheel you can use Set Origin → Origin to Center of Mass (Volume). The author also used Parents when keeping children in position. Turn those options off afterward and test a rotation.

    2. Set up a turretless tank destroyer

    The author used a Jagdtiger. Choose Shift+A → Empty → Plain Axes and use G to move the empty to the gun mount. Name it Turret and parent Gun below it. Verify the chain Turret → Gun → Dym.

    3. Internal modules are missing

    Check Is Module Ready in VehicleInfo and use module mode in the playground. If the parts still do not appear, check the internal groups and ensure the vehicle references the right damage prefab. Module names · Playground modes

    4. The HitBox disappears while editing

    Check scene visibility in Hierarchy and the damage editor. The original screenshot used the menu on the right to restore visibility. Select one plate and confirm it still belongs to the vehicle's HitBox groups. Damage model setup

    5. The tank flips in the garage

    Check VehicleTextData → Mobility → Mass first. Then inspect the wheel contact and whether the hull collider penetrates the ground. Wheel physics

    6. The impact decal is oversized

    Open that shell's asset. Check Caliber in millimetres and make sure the Bullet VFX suits it. Test the same ammo from near and far.

    7. The mod is missing from the vehicle list

    The original case was missing its sound assignment. Check the runtime log for package target and version or missing asset references. Verify engine and firing audio and set VehicleInfo → Spawn Policy to Player Pick for a regular vehicle. Vehicle troubleshooting

    Refining the vehicle

    1. Animate a radar on its own pivot

    In Blender parent the radar to an empty at its axis, then parent the empty to the turret. Select the axis in Unity and open Window → Animation → Animation. Create a clip and key the starting and ending rotations. Assign and enable the Animator and its controller. Apply the materials, configure physical collision, and save the collision prefab. In game, check the radar can rotate independently while following the turret. Original animation video

    2. Orient individual track links

    Separate one link in Blender, set its origin to the volume center of mass, and use Snap → Selection to Cursor. Align it and apply Ctrl+A → Rotation. The author's left link was turned 180° relative to the right. Assign them to TrackMesh and LeftTrackMesh, then preview the whole loop to check corners and mirror orientation. Track preview

    3. Limit elevation by turret direction

    Open VehicleTextData → Turret → Override Ranges. Add a range for a direction with obstructions and set the beginning and ending traverse angles, elevation, and depression. The old symmetrical example used 138°–180°, 20° elevation, and 11° depression. Check for clipping on your own vehicle.

    4. Add a thumbnail

    Import your image, use Texture Type → Sprite (2D and UI) and Sprite Mode → Single, then click Apply. Assign the Sprite to the thumbnail in VehicleInfo. Thumbnail guide

    5. Set up external and internal reactive armor

    Select Reactive on the outer HitBox. The old example used a separate interior mesh to represent the reactive plates inside the structure and classified it as internal armor. Configure the outer block's protection and consumption first. Add the internal representation if needed. Reactive armor

    6. A plate is transparent in the armor viewer

    Inspect it with Blender's Face Orientation display. Enter Edit Mode with Tab, select the affected faces, and press Shift+N to recalculate outside. Export over the FBX and refresh Unity. Check that the plate appears in the intended HitBox group. A missing plate or wrong group can also cause a gap. Original normals video

    7. Remove texture from an interior mesh

    Put the internal model in the scene and open Mesh Renderer → Materials. The old example used Reset in the material menu. If the visual hull uses the same material, duplicate it first, then assign the copy or a neutral untextured material to the internal mesh. Save the prefab and check the internal view.

    8. Name the vehicle in the UI

    The old screenshot highlighted VehicleInfo → Localized Name. Fill in the default display name and the localized names. Keep the internal asset name unique. Save and check the vehicle list in both languages.

    9. Smooth a faceted barrel

    Select the barrel in Blender and use Shade Smooth. Check its shading and silhouette from the side and at the muzzle, then export.

    10. Legacy roof and coaxial guns

    The original SubTurret02 was the roof machine gun and used an empty for Dym. The coaxial SubTurret01 used three nested empties under the main gun's Dym so it followed the main gun. Verify the three paths and the muzzle. Legacy multiple turrets · Current multi-turret parameters

    11. Pair and spring track nodes

    Open VehicleTrackData. Put nodes that should sag under gravity in SpringNode. Use PairNodes to connect upper path nodes to nodes near the road wheels. The old screenshot used a link spacing of 0.12 m, spring node 15, and pairs 2→14, 3→13, 4→12, 5→11, and 6→10. Check your own indices and use Preview Track to inspect suspension compression.

    12. Reduce heavy pitch on starts and stops

    Edit CenterOfGravity in VehicleData, lower it by a small amount, and press K to save. Then tune WheelCollider → Forward Friction / Sideways Friction. The old screenshot used stiffness 1.7 forward and 4 sideways. Change one value at a time and test from the same speed. Physical wheels · Original WheelCollider discussion
