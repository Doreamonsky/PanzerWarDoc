    1. Import the script and attach it to a vehicle

    Create ChargedShot.lua in your Lua source folder and copy in the script below. Follow Lua Hello World to import it into Unity, then add the asset to the vehicle-level Lua behaviours in VehicleTextData. For a test prefab, you can also attach it with LuaBehaviorMono on an object in the vehicle hierarchy.

    Keep chargeTime = 4 seconds and maxBonus = 0.5 for the first test. The example uses weapon index 0. To pick another weapon, check the available count with WeaponAPI.GetWeaponCount and change the index. The script disables periodic updates if the weapon is missing or charge time is zero or negative.

    Use BuffAPI.CreateValueBuff to attach one mutable buff to the weapon's DamageBuffedCoff. Passing false for the second argument makes it additive. A value of 0.5 adds 50%. Passing true gives a multiplier that stacks multiplicatively. Keep one object and use SetValue to update it. An unchanged value leaves it as-is. On destruction, remove it with RemoveBuff.

    Behavior()
Property = {
    maxBonus = { type = "number", value = 0.5 },
    chargeTime = { type = "number", value = 4 },
}

local ChargedShot = class("ChargedShot")

function ChargedShot:OnVehicleReady(vehicle)
    local weapon = WeaponAPI.GetWeapon(vehicle, 0)
    if weapon == nil or self.chargeTime <= 0 then
        self.script:SetUpdateEnabled(false)
        return
    end
    self.weapon = weapon
    self.damage = weapon.DamageBuffedCoff
    self.charge = 0
    self.buff = BuffAPI.CreateValueBuff("Charged Shot", false, 0)
    self.damage:AddBuff(self.buff)
    WeaponAPI.OnFired(self.script, weapon, function()
        self.charge = 0
        self.buff:SetValue(0)
    end)
    self.script:SetUpdateInterval(0.1)
end

function ChargedShot:OnUpdated(dt)
    if self.buff == nil or not WeaponAPI.IsReloaded(self.weapon) then
        return
    end
    self.charge = math.min(self.charge + dt / self.chargeTime, 1)
    self.buff:SetValue(self.charge * self.maxBonus)
end

function ChargedShot:OnDestroyed()
    if self.buff ~= nil then
        self.damage:RemoveBuff(self.buff)
        self.buff = nil
    end
end

return ChargedShot

    2. Test reload, charge, and fire in order

    1. Let the weapon finish reloading. The script skips charging during reload.
    2. Wait about two seconds and fire once. Reload, wait more than four seconds, and fire again. Log self.charge temporarily to check that it grows by dt / chargeTime and stops at 1. The update interval is 0.1 seconds. The script accumulates the actual dt it receives.
    3. Check that OnFired clears both the charge and the buff amount. After removing the behaviour, check that its buff was removed from the weapon. To compare damage in game, keep the ammo, target, and hit location consistent.

    The replay uses xLua test doubles to check the reload gate, charge limit, firing reset, and cleanup.
