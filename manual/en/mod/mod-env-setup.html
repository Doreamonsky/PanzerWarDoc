    Set Up the Modding Environment

    中文 | English

    Choose the route that matches your situation. The detailed steps live in the linked guides; this page is only the entry point.

    First-time install

    1. Download the named SDK ZIP from GitHub Releases, then verify its hash and extract it fully using the download reference. The release bundles the binary files, so Git is not required.
    2. Install the Unity version declared by the project and the modules for your target platform, following the version requirements.
    3. Follow project setup to open UnityProject in Unity Hub, keep the sibling Packages folder, and build a bundled template to verify the environment after import.

    Maintain the project with Git

    1. Follow the download and clone guide to install Git LFS, clone the repository, and complete git lfs pull.
    2. Open UnityProject with the version declared in the project's ProjectVersion.txt and finish importing as described in project setup.
    3. When updating the SDK, extract or check out into a new folder. Do not overwrite the new package with the old SDK's Packages folder; carry your own assets forward with the migration steps.

    Migrate an old project

    1. Move your assets together with their .meta files, mod packages, and build pipelines into the new SDK, preserving existing asset references and mod identifiers.
    2. Confirm references resolve step by step, then rebuild the linked objects and package to test. See the migration guide for the detailed rules.
    3. If your local GameHub build offers Create Project, you can also use the GameHub workflow.
