    Set up aircraft landing gear animation

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run flight-vehicles --capture
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "base": "${fixture}/TutorialGear.controller",
    "override": "${fixture}/TutorialGearOverride.overrideController",
    "model": "${fixture}/TutorialFlight.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}

    1. Create an Animator Override Controller. Use the SDK's Assets/Template-Flight/Collision/BF-110.controller as the base controller. Replace BF-110_Flying, BF-110_Gear, and BF-110_Landing with your clips. In the template, the Gear clip plays forward to retract and backward to deploy.

    1. Add an Animator to Refer in the dynamics prefab and assign the override asset to Controller. The aircraft build reads the component from this node. Keep the GearDown and GearUp triggers and the initial flight state named in FlightTextData.flyingAnimationName. Test deployment and retraction in game.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "create",
        "component": "UnityEngine.Animator",
        "children": [
          "Refer",
          "Refer/GearDoor"
        ],
        "child": "Refer",
        "references": [
          {
            "property": "m_Controller",
            "asset": "${override}",
            "type": "UnityEngine.RuntimeAnimatorController"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${model}/Refer/GetComponent(Animator)/runtimeAnimatorController/name"
    },
    "expect": {
      "contains": "TutorialGearOverride"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${base}/parameters/0/name"
    },
    "expect": {
      "contains": "GearDown"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${base}/parameters/1/name"
    },
    "expect": {
      "contains": "GearUp"
    }
  }
