    Create a map with the public SDK

    1. Follow project setup to download the release ZIP and open UnityProject in Unity Hub.
    2. Locate Assets/Template-Scene in Project. Follow the map wizard to create your own scene.
    3. To verify your setup first, select BuildPipline-Template-Blank.asset in Assets/ModManager and build its linked objects. Then select Template-Blank-Scene.asset and package it. Build Windows and Android separately and install the .modpack for your game's platform. Multi-platform builds

    Maintain official maps and DIY parts

    Maintainers with access can clone the official mods repository and keep Projects and Packages in their original layout. Follow the official asset workflow to fetch the required Git LFS files, then open Projects/Maps. Its Packages/manifest.json resolves local UPM dependencies from the same repository. Official mods repository

    Content Repository path
    Official maps Packages/Maps/<pack>, for example Packages/Maps/Provisional
    DIY map parts Packages/Maps/DIYBuildings, Packages/Maps/DIYJapaneseBuildings, and Packages/Maps/DIYOfficial
    Shared dependencies Packages/Maps/Shared and the dependencies listed in each map pack's package.json

    In Unity's Project window, expand Packages to find the assets. Keep .meta files alongside the scenes and assets you edit. Create a work branch and use git status to check which packages, dependencies, and .meta files changed. For shared assets, check the upstream source before committing and requesting review.     Identify paths from the earlier project layout

    OfficialURPMaps, com.shanghaiwindy.urpmaps/Scenes, and com.shanghaiwindy.diymapconfigs refer to the earlier layout. The old instructions placed three GitLab checkouts for the vehicle project, maps, and shared resources under one parent folder. Use those names when tracking down historic assets. For current maps and DIY parts, use the unified repository paths above.
