    A built-in vehicle queue is a resource asset packed into a mod. It lists the vehicles a match may offer, is read-only in game, and feeds the battle-configuration vehicle picker.

    Not to be confused with PresetVehicleQueueConfig, a saved per-player config, not a packed asset.

    3. Add one vehicle entry

    In Vehicle Guids click + to add one entry, then fill its two strings: Comment = an author note, Vehicle Guid = the vehicle load identifier.

    The identifier is what VehicleInfo exposes: assetGuid, or the lower-cased vehicleName when assetGuid is empty. Copy it from your own driveable VehicleInfo; do not use the Unity .meta GUID or VehicleTextData.editorAssetGuid.

    Select that VehicleInfo asset and click Copy Asset GUID to copy the correct identifier, then paste it into Vehicle Guid.

    The example Comment: T-34-85 No.215 with Vehicle Guid: a922ecf1-f7ce-45f9-b0f8-86a23ec26c2c is official AAA2 content, illustrative only, and not automatically supplied to your project.

    The list is a set of eligible vehicles, not quantities: the item count is the entry count, and there is no spawn quantity field. How many vehicles actually appear is decided by mode settings.

    4. Pack with the vehicles

    • The asset's Guid is its bundle name with variant vehiclequeue: <Guid>.vehiclequeue
    • Add the asset to the mod build pipeline's Linked Objects (linkedObjects)
    • Entries are strings, so they do not pull in the vehicles: put each referenced vehicle's content in this pack or an installed dependency

    5. Select in the battle-config picker

    Built-in queues appear in the current picker next to the player's own queues and are read-only in game; to change a shipped queue, edit the asset and rebuild. Lookup covers room presets, war-zone configs and built-in Match queues, so keep Match here.

    The asset defaults to Lobby; that list is not used by the current battle-configuration picker.

    A queue that shows no entries usually means the string matches no registered VehicleInfo, the vehicle is not driveable, it cannot spawn on the loaded map, or the vehicle content is missing from the pack and its dependencies. Check the identifier, dependency content and vehicle eligibility when this happens.

    Menu path, field names and behavior come from source and Inspector checks; the pictures are real editor captures. The shared recipe verifies the queue-definition package's Windows build, ZIP manifests and sidecar. It does not include the T-34 model and has not been installed or run in game.
