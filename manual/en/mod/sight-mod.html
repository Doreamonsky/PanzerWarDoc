    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    1. Create a UserSightData asset in Unity. Set its display name and mil convention.
    2. In Ballistics, add a group. In crosshairDistances, enter range in meters, number for the label, and notchSize to adjust the mark's length. The horizontal scale uses mils in crosshairHorRanges.
    3. For a custom reticle, turn off the appropriate horizontal and vertical center lines, then add your own lines.

    1. Add UserSightData to the build pipeline. To make it the vehicle's default sight, assign it to TankFireParameter.customSightData. If the vehicle uses shared firing data, set it in that asset.
    2. Build and install the mod, then check the sight in game. The game checks the player's override for the vehicle, the vehicle's own sight, and the global default in that order.
