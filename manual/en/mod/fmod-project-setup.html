    Set up an FMOD project

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run fmod-project-setup
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "sdkCheckout": "../../../Panzer-War-Mod-SDK"
  },
  "calls": []
}

    1. Open the project and build banks

    Install FMOD Studio first. If you have a complete .fspro project, open it in Studio and build banks for the target platform. Check the Desktop output for Master.strings.bank. If you already have platform banks, go to step 2.

    To unpack PanzerWar-FMod-UGC-Project/PanzerWar-FMod-Project.fspackage from the SDK, use File → Open and choose a new directory. In the Studio 2.02.09 test, unpacking succeeded but Studio reported missing Workspace, Mixer and Master Bank data when loading. If you see this warning, use a complete project or existing banks.

    With Studio connected, use FMOD MCP's list_banks to check the project and build_banks to build it. The Unity MCP recipe below checks the SDK archive and an existing Desktop bank.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${sdkCheckout}/PanzerWar-FMod-UGC-Project/PanzerWar-FMod-Project.fspackage"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "../Fmod/Build/Desktop/Master.strings.bank"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    2. Point Unity at the build

    Open FMOD → Edit Settings → Bank Import. Under Source Type, choose FMOD Studio Project and set Studio Project Path to the .fspro. For a set of already built platform banks, choose Multiple Platform Build and set Build Path to the folder containing subfolders such as Desktop and Mobile.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:FMODUnity.Settings/Instance/HasSourceProject"
    },
    "expect": {
      "contains": "(Boolean)"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:FMODUnity.Settings/Instance/sourceBankPath"
    },
    "expect": {
      "contains": "Build"
    }
  }
]

    3. Refresh and check events

    Select FMOD → Refresh Banks, then search for the event in FMOD → Event Browser. To create a voice pack, continue with the voice pack walkthrough. The replay checks a known event in the current Editor's cache.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:FMODUnity.EventManager/EventFromPath",
      "args": [
        "event:/aircraft/engines/engine01/engine01_cockpit"
      ]
    },
    "expect": {
      "contains": "parameter:/engine01_cockpit/zoom"
    }
  }
]

    The command-line build produced Desktop banks from Studio's bundled example. Saving and refreshing in the Unity settings UI still need verification.
