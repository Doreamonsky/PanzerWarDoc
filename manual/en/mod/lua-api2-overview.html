    Lua API 2 overview

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run lua-api2-overview

    1. Check the client version

    These examples use GAME_API_VERSION 2 or later. To support older clients, check (GAME_API_VERSION or 1) >= 2. The replay reads the client API version and checks the version branches in xLua.

    2. Pick callbacks and queries

    • Handle startup in OnStarted and use OnVehicleReady to access assembled vehicle components. OnVehicleReady can also run in the garage. Use VehicleAPI.IsGarage to check the context. See vehicle initialization timing.
    • Create and reuse a battle query with VehicleAPI.CreateQuery. Cache model nodes found by TransformAPI.FindDeep or FindAllDeep during initialization. Handle missing results according to each API signature. C# arrays and contact indices start at zero.
    • Pass self.script to subscriptions so they end when the behaviour is destroyed. Weapons, modules, landing gear and radar expose change events.
    • Use self.script:SetUpdateInterval(seconds) for slower updates. Use SetUpdateEnabled(false) for event-driven behaviours. Draw cached results in OnGUI.
    • Angles generally use degrees and distances use metres. Check the signature for speed units. For example, GetSpeedKmh returns kilometres per hour.
