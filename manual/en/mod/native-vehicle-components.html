    Use the universal slots on VehicleAttachmentMonoComponent to configure an external ammo model and a wave shield in the vehicle's model prefab. Vehicle packing collects these attachments from the model hierarchy.

    1. Connect the external ammo model

    Add VehicleAttachmentMonoComponent inside the model prefab and keep Attachment Slot Type set to Universal. Expand Slot and choose VehicleAmmoVisualAttachment from its type dropdown.

    1. Set Ammo Visual Type to Show Hide.
    2. Enter the corresponding gun module GUID in Connect Gun Guid. The screenshot uses a placeholder.
    3. Drag the external ammo object from the prefab into Visual Model. The example uses ExternalShell.

    Choose Follow Bullet if the model should follow the fired projectile. That mode exposes the follow offset and specific fire point fields.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "create",
        "component": "ShanghaiWindy.Core.VehicleAttachmentMonoComponent",
        "child": "AmmoVisual",
        "children": [
          "AmmoVisual",
          "ExternalShell",
          "WaveShield",
          "ShieldPivot"
        ],
        "managedReferences": [
          {
            "property": "slot.attachment",
            "type": "ShanghaiWindy.Core.VehicleAmmoVisualAttachment",
            "values": {
              "ammoVisualType": 0,
              "connectGunGuid": "00000000000000000000000000000001"
            }
          }
        ],
        "references": [
          {
            "property": "slot.attachment.visualModel",
            "child": "ExternalShell",
            "component": "UnityEngine.GameObject"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    2. Set up the wave shield

    Add a second universal attachment in the model and choose VehicleWaveShieldAttachment. Assign the shield's pivot to Wave Shield. The example uses ShieldPivot, a default angle of 0°, an active angle of 35°, and a rotation speed of 30° per second.

    Check the two poses against the red and yellow guides in the Scene view. In game, the active state of the ship controller determines which pose the wave shield rotates toward.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.VehicleAttachmentMonoComponent",
        "child": "WaveShield",
        "managedReferences": [
          {
            "property": "slot.attachment",
            "type": "ShanghaiWindy.Core.VehicleWaveShieldAttachment",
            "values": {
              "defaultAngle": 0,
              "activateAngle": 35,
              "angleSpeed": 30
            }
          }
        ],
        "references": [
          {
            "property": "slot.attachment.waveShieldTransform",
            "child": "ShieldPivot",
            "component": "UnityEngine.Transform"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    4. Regenerate and pack the vehicle

    Confirm that MainModel in VehicleData points to the edited model, then regenerate the packed prefab. Check that the wave shield attachment has generated its DefaultAngle and ActivateAngle pose nodes. Build the mod pack with a pipeline linked to the vehicle's VehicleInfo. See the vehicle setup guide for asset and pipeline setup.

    The recipe checks both pose nodes, the external ammo reference, and the Windows teaching package using a copy of a complete vehicle. Check motion and display in game after installing the updated pack.
