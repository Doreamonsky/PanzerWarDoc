    Installing TortoiseGit

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run install-tortoisegit
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {},
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:System.Environment/GetEnvironmentVariable",
        "args": [
          "ProgramFiles"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [A-Z]:\\\\"
      },
      "capture": {
        "programFiles": {
          "regex": "\\(String\\) ([^\\r\\n]+)"
        }
      }
    }
  ]
}

    TortoiseGit adds Git actions to Windows Explorer. Install Git for Windows first.

    1. Open the official download page at https://tortoisegit.org/download/.
    2. Check whether your Windows is x64 or ARM64, then download the installer for that architecture.
    3. Run the installer and follow its prompts.
    4. For a localized interface, also download the language pack for the same architecture, matching the version you installed.
    5. Right-click any folder in Explorer; the menu should list TortoiseGit.
    6. On Windows 11 the entry may be under "Show more options"; expand it to find TortoiseGit.
    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${programFiles}\\TortoiseGit\\bin\\TortoiseGitProc.exe"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    MCP checks the executable at the default installation location. Check the installer and context menu manually.
