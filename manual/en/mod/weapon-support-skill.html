    This tutorial configures offline weapon support and copies the official Altius support prefab to demonstrate custom resources, a flight path and weapon nodes. It does not build a usable drone model from scratch.

    1. Create a skill slot

    Add an entry to skills under CrewData.upgradableSkillContents and set friendshipRequirement = 0. Choose CrewSkillBuff for crewSkillRef, then WeaponSupportSkillConfig for its crewSkill. version must equal the current GetVersion(), which is 3. See the commander tutorial for details.

    The teaching commander reuses Aino's valid portrait references without changing that source commander. Configure your own portraits for production content; valid portrait references are required for packaging.

    3. Initialize support configuration

    Create a weaponSupportInfo instance before editing its fields; the declaration does not initialize one. visualType supports None (0), Altius (1) and Custom (9999). Altius uses the resource key Altius-U-Skill.prefab, which must be loadable. None loads no model.

    Set duration = 30, isScouting = false, scoutSpottingDuration = 5 and maxScoutingDistance = 1000. Distance and line-of-sight scouting checks run only when scouting is enabled. The image shows the final configuration after switching to Custom below.

    4. Assign a custom model

    Copy the official Altius-U-Skill.prefab to Tutorial_Support.prefab. Preserve WeaponSupportMonoComponent on its root and its visualModel, rigidBody and weapon references. customZoomPoint is the gunner view point.

    Create ManualNameBuildPiplineData. In bundleNameMaps, assign the prefab to bundleObject and use a complete name plus variant, such as tutorial-support-shared.prefab. Add the naming asset to ModPackageBuildPiplineData.linkedObjects. Then set visualType = Custom and customVisualModel to that same complete resource key. The recipe generates a distinct name per run.

    5. Configure the path and refresh weapon nodes

    Select moveType = FollowSpine and assign a SplineContainer with a nonzero path length to followSpline. This example keeps the template's path, sets followSplineVelocity = 50 and makes followSplineVelocityCurve equal to 1 throughout 0–1. Movement speed is the curve multiplier times the configured speed. A new component's default single-key curve has value zero and will not advance. Stationary does not traverse a path.

    After editing the gun, turret and node paths in fireSystemParameters, click Refresh Weapon Transforms. This generates fireSystemTransforms, simpleFireGunGuids and simpleFireTurretGuids. Keep these references consistent within the support prefab. Support firepower belongs to that asset and does not need the parent vehicle's main-gun GUID. The recipe invokes the same refresh method and saves the prefab.

    6. Save, check and build

    Check the skill version, nonzero curve multiplier, and the template weapon's generated nodes and GUIDs. Then build and verify the Windows teaching package. The skill remains restricted to offline vehicles. A successful build does not verify in-game visuals, firing, cooldown or scouting.

    Runtime verification still needs an offline match, enabled commander buffs and a valid commander. Teaching packages are neither installed nor published.
