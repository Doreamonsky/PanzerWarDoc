    Start with the main gun model from the first-tank guide. Set up the turret and gun pivots first, then configure traverse, elevation and stabilizers.

    1. Set up the main gun hierarchy

    1. Create Turret → Gun → Dym below the visual model root. Parent the turret mesh to Turret and the recoiling barrel mesh to Dym. Put the turret pivot on the turret ring and the Gun pivot at the elevation axis. Dym moves with recoil.
    2. Check model axes, with local +Z forward and +Y up. Place FFPoint, EffectStart and the gunner camera reference as in the main model setup. Rotate and elevate the model by hand to check that the muzzle and reference points follow their intended parts.
    3. Inspect the generated prefab. The assembler names the runtime nodes TurretTransform, GunTransform, and GunDym. Keep Turret/Gun/Dym in the source model for the next build. Bind secondary turrets separately using the multi-turret data.

    2. Set traverse, stabilization and limits

    Open the Turret tab of VehicleTextData. With no Shared Turret Data (sharedTurretData) assigned, edit Turret Params (MTParameter). With a shared asset assigned, open it and edit turretParameter. Duplicate the shared asset first to tune one vehicle.

    Field Teaching values and purpose
    maxTurretAngle 180° allows 180° on either side. A value of 45° allows 45° on either side.
    isNonSymmetricTurret Enables separate maxTurretNegativeAngle and maxTurretPositiveAngle, for example −30° and +45°.
    UpMaxDegree, DownMaxDegree Use 20° and 6° on the teaching tank. For a normal setup, enter depression as a positive magnitude, so 6° permits six degrees down.
    turretDegreesPerSecond, gunDegreesPerSecond Set 18°/s for horizontal traverse and 12°/s for elevation.
    offset Horizontal offset. Keep 0° when the turret's zero pose already faces forward.
    ffPointAlignType Selects the aiming alignment reference, the Gun root or the recoiling Dym barrel. Keep the working setup for the first test and compare the resulting muzzle direction.

    To clear the engine deck or another fixture, add an Override Range for that sector. Symmetric ranges mirror on both sides. Enable asymmetric override ranges for separate sectors, then fill in their start and end azimuths and the elevation and depression available inside each. Aim across the boundary to test how the limits change.

    The vertical stabilizer has its own speed, elevation and depression limits. The horizontal stabilizer has its own speed and angle. Verify the base limits first. Enable stabilization and compare while moving. In module mode, moduleData.hasOverride can select separate traverse and elevation rates. See the fixed-mount and suspension guide for casemates, hull-assisted traverse and hydraulic suspension.

    3. Test the turret and muzzle

    Save and rebuild. Stop on level ground and aim at both ends of the travel. A limited turret should stop at its configured bounds. Compare traverse and elevation rates. Use high and low targets to verify the muzzle orientation and elevation limits. Enable stabilization and repeat while turning and driving over rough ground. Fire once and watch the recoil, armor hitboxes and muzzle effect follow their parts.

    • If the turret never moves, check the source hierarchy, effective limits and rates, and the shared asset.
    • If the model rotates while the sight points elsewhere, check pivot axes, horizontal offset and FFPoint.
    • If parts clip, check sector limits and hitbox grouping. Regenerate the prefab after changing the visual hierarchy.
