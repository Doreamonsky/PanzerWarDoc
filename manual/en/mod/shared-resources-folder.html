    Current SDK layout

    The SDK contains the project in UnityProject and the shared resources package beside it in Packages/Sdk/com.shanghaiwindy.middlesharedresources.

    Extract the complete SDK as described in project setup and keep those two folders next to each other.

    The package already contains these directories; keep the exact case and spelling:

    • SharedVFX
    • FMod
    • SharedInternalDamage/Preset

    Dependency and package inspection

    1. Confirm that UnityProject/Packages/manifest.json references the package ID com.shanghaiwindy.middlesharedresources.
    2. Confirm that the actual package directory Packages/Sdk/com.shanghaiwindy.middlesharedresources exists.
    3. Open Window → Package Manager in Unity and find Panzer War Middle Shared Resources.
