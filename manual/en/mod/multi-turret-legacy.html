    Configure legacy multiple turrets

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP. The command also captures screenshots in both languages.

    python Docs/Manual/manual/tools/tutorials.py run multi-turret-legacy --capture
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "source": "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar",
    "vehicleData": "${fixture}/Tutorial_NativeVehicleData.asset",
    "vehicleText": "${fixture}/Tutorial_NativeText.asset",
    "vehicleInfo": "${fixture}/Tutorial_NativeVehicleInfo.asset",
    "packModel": "${fixture}/Tutorial_NativePackModel.prefab",
    "vehicleName": "Docs-Legacy-Turret-${runId}",
    "vehicleGuid": "205563420ee989807e2${runId}",
    "cooked": "${fixture}/205563420ee989807e2${runId}_pre.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}

    Existing vehicles can keep using VehicleTextData → Old Multi-Turret. For new configurations, see New Multi-Turret in the same Inspector.

    1. Give the secondary weapon three nested model nodes. The example places TutorialSubTurret under Turret, followed by TutorialSubGun and TutorialSubDym.

  {

    "arguments": {

      "args": [
        "${source}_Model.prefab",

    "expect": {
      "contains": "(Boolean) True"

    "tool": "prefab_edit",

      "json": {
        "path": "${packModel}",
        "mode": "update",
        "component": "UnityEngine.Transform",

          "Turret/TutorialSubTurret/TutorialSubGun/TutorialSubDym"

      "contains": "TutorialSubDym"
    }
  }
]
    1. Add a MultiFireSystemData entry. Resolve turretPath from the model root, gunPath from the secondary turret, and dymPath from the secondary gun. The example uses Turret/TutorialSubTurret, TutorialSubGun, and TutorialSubDym in that order.
    2. Set ffPointOffSet and effectStartOffSet to distances from the barrel origin along local +Z. The sample uses 2.5 and 1.25. Configure ammunition, reload and sound along with traverse and elevation parameters, or assign shared gun and turret assets. For a turret-mounted anti-tank missile, put the launcher under Turret and align its local forward direction with the launch direction.
