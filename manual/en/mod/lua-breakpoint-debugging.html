    Debug Lua with breakpoints

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run lua-breakpoint-debugging

    Install VS Code and EmmyLua, then open the Lua source that matches the running target.

    1. In Run and Debug, select EmmyLua Attach Debug and choose your local Unity Editor or game process, such as PanzerWar-DE. Attach debugging requires Lua symbols in the target.
    2. Set a breakpoint to the left of the line number. Trigger the script in game, for example by starting the Hello World behaviour.
    3. When the breakpoint is hit, open Variables and use Step Over. If it remains unbound, check that both the file path and source match the running script.

    The replay checks line information and local variables in the project's xLua. Test VS Code attachment and symbol availability with the specific build.
