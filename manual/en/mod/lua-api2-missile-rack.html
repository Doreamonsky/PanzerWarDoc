    Attach the script to the vehicle model and add children such as Missile_1 and Missile_2 in hierarchy order. Set the zero-based weaponIndex and the text to match in object names, modelPrefix. Matching is case-sensitive.

    The script caches the models during initialization and shows the first models in the list according to the weapon's current ammo count. An ammo change refreshes the display. When ammo decreases, the models at the end disappear first.

    Behavior()
Property = {
    weaponIndex = { type = "number", value = 1 },
    modelPrefix = { type = "string", value = "Missile_" },
}

local MissileRack = class("MissileRack")

function MissileRack:OnVehicleReady(vehicle)
    self.weapon = WeaponAPI.GetWeapon(vehicle, self.weaponIndex)
    if self.weapon == nil then
        return
    end
    self.models = TransformAPI.FindAllDeep(self.transform, self.modelPrefix)
    self:Refresh()
    WeaponAPI.OnAmmoChanged(self.script, self.weapon, function()
        self:Refresh()
    end)
end

function MissileRack:Refresh()
    local left = WeaponAPI.GetTotalAmmo(self.weapon)
    for index = 0, self.models.Length - 1 do
        self.models[index].gameObject:SetActive(index < left)
    end
end

return MissileRack
