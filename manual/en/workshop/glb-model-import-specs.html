    GLB model import specifications for the workshop

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run glb-model-import-specs

    1. Prepare the visual model and textures

    Preview the model in Blender. The PBR example uses base color, metallic and roughness, baked ambient occlusion, and a normal map. A simpler material needs base color and can add a normal map. Route the normal map to the Normal input. Preview the result and prepare distant meshes with Blender's reduction tools or an external editor. Blender glTF guide · InstaLOD Studio

    2. Organize meshes for the importer

    Use Shift+A → Empty → Plain Axes in Blender to create four empty objects. The importer classifies meshes by their direct parent's case-sensitive name.

    Parent Direct child meshes
    Visual Visual models. Place reduced LOD meshes under the matching source mesh.
    Collider Hull collision geometry. Use simple convex pieces to cover the needed areas.
    HitBox External armor. Split plates with different thicknesses or types.
    Module Low-poly internals for post-penetration damage. Name each module for its type, armor, and HP.

    Use a naming pattern such as Body_LOD0, then Body_LOD1 through Body_LOD3. Place Body_LOD0 directly under Visual and the reduced meshes below it from nearest to farthest. The importer recognizes uppercase LOD and reads those children in hierarchy order. Parts that can take shell hits need the appropriate external and internal meshes. The hull also needs physical collision. Damage model naming

    Visual
  Body_LOD0
    Body_LOD1
Collider
  HullCollision
HitBox
  HullFront_65
Module
  Engine_40_10

    To generate this teaching file from a source checkout with Blender on your PATH, run:

    blender --background --factory-startup --python-exit-code 1 --python Docs/Manual/tutorials/glb-model-import-specs/create_sample.py -- Temp/ManualMcp/WorkshopGLB/Tutorial.glb

    3. Export and import into the workshop

    1. Select the empty objects and meshes you intend to export. Choose File → Export → glTF 2.0, select binary .glb, enable Selected Objects, and export.
    2. On Windows, open Model Import in the Tank Workshop and choose the GLB file. The picker can import the selection directly. You can also confirm the file and choose Import Mesh.
    3. On Android, open the .glb in Panzer War: Definitive Edition from the file manager. Open Model Import in the workshop and enter the filename including .glb. The game looks for it in its Installs directory.
    4. Inspect the visual, collision, and damage groups. Rotate articulated parts to check their alignment. Fit them to the vehicle, save a test preset, and take it for a drive. Tank Workshop basics
