    Configure procedural tracks in the Tank Workshop

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run track-editor-tutorial

    1. Choose the procedural track hull

    Start a new vehicle and search the hull catalog for Procedural Track. The example comes from Vehicle Extension Pack (III). It is a hull with a turret slot. Select it and use the wheel and track categories in the inspector. Fit the road wheels first, then check the return rollers, sprocket, idler, and track loop.

    The road-wheel settings include count, radius, width, spacing, and position. Start by changing the count from 5 to 6. Check in side view that the track clears the hull and covers the contact wheels. For wheeled configurations, check the tires, motor, and steering separately.

    2. Check collision

    If you build a custom body on the procedural hull, you can give it collision using an Editable Poly part. Select that part and enable its collider. A body collider that touches the ground ahead of the road wheels can leave the wheels unsupported. Check how the shape behaves on slopes and obstacles. Polygon editing

    3. Adjust the center of gravity and drive

    In the hull or mobility settings, put the center of gravity between the two wheel rows and inside the hull. If the tank tips when starting or turning, try a small reduction in height. Save and compare steering, braking, and wheel contact on the same flat route and slope before adjusting suspension.

    For a workshop replay, locate the part with vehicle_rules and inspect its current fields with vehicle_props. Use vehicle_set_props to change only the fields you need and read them back. For Unity SDK tracks and WheelCollider, see Track IK and tank creation.

    Replay on a new workshop vehicle. This checks the wheel and center-of-gravity settings. Use the article steps to check driving and the polygon collider.

    [
  {
    "tool": "vehicle_new",
    "arguments": {},
    "expect": {
      "contains": "ok new vehicle"
    }
  },
  {
    "tool": "vehicle_catalog",
    "arguments": {
      "type": "hull",
      "search": "Procedural Track"
    },
    "expect": {
      "contains": "1dae31c6-7e26-483d-8a88-4dd5ec25b830"
    }
  },
  {
    "tool": "vehicle_equip",
    "arguments": {
      "itemGuid": "1dae31c6-7e26-483d-8a88-4dd5ec25b830",
      "slotIndex": 0,
      "isMain": true
    },
    "expect": {
      "contains": "built=True"
    },
    "capture": {
      "track": {
        "regex": "ruleGuid=([\\w-]+)"
      }
    }
  },
  {
    "tool": "vehicle_props",
    "arguments": {
      "ruleGuid": "${track}"
    },
    "expect": {
      "contains": "roadWheelNumber"
    }
  },
  {
    "tool": "vehicle_set_props",
    "arguments": {
      "ruleGuid": "${track}",
      "json": "{\"roadWheelNumber\":{\"isEnabled\":true,\"value\":6},\"centerOfGravityHeight\":{\"isEnabled\":true,\"value\":0.45},\"centerOfGravityForward\":{\"isEnabled\":true,\"value\":0.05}}"
    },
    "expect": {
      "contains": "rebuilt"
    }
  },
  {
    "tool": "vehicle_props",
    "arguments": {
      "ruleGuid": "${track}"
    },
    "expect": {
      "contains": "\"roadWheelNumber\":{\"isEnabled\":true,\"value\":6}"
    }
  },
  {
    "tool": "vehicle_focus",
    "arguments": {
      "ruleGuid": "${track}"
    },
    "expect": {
      "contains": "ok focused"
    }
  },
  {
    "tool": "camera_set",
    "arguments": {
      "yaw": 90,
      "pitch": 8,
      "distance": 8
    },
    "expect": {
      "contains": "yaw:90"
    }
  }
]
