    Tank Workshop basics

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run tank-workshop-basics
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "testPreset": "Tutorial ARL-44 (local test)",
    "partSet": "Tutorial ARL-44 Turret (local test)"
  },
  "calls": []
}

    Enter the Tank Workshop from the garage. Start a new vehicle, equip a hull, pick the hull's turret slot, then pick the turret's gun slot. Mark the hull, turret, and gun as primary. For a matching set, try ARL-44 Hull, ARL-44 Turret, and 90 MM DCA 45. To build a standalone vehicle mod in the SDK, see the tank creation guide.

    1. View and adjust parts

    These are the desktop shortcuts shown in the earlier tutorial. Use the current bindings if you remapped controls. The on-screen tools are available on touch devices.

    Shortcut Action
    W A S D, Q E Move or raise and lower the workshop camera
    1, 2, 3, 4 Slot, move, rotate, and scale
    Ctrl+Z, Ctrl+Y Undo and redo
    Ctrl+C, Ctrl+V, Ctrl+X Copy, paste, and cut

    Pick a part in slot mode. Switch to move, rotate, or scale as needed. Undo unwanted edits and check the result from another angle.

    2. Move a turret to another hull

    Select the turret on the original vehicle and click Copy. Switch to the new hull, select a compatible slot, and paste. To reuse the assembly across saves, use Save as Part Set, then place the set in a compatible slot. Check that the gun and attachments transferred. Copies start without primary flags, so select the turret and gun in turn and click Set as primary on each.

    3. Save and test-drive

    Save a separate preset before choosing Test Drive. Test moving, braking, turning, aiming, and firing. Click Stop Act to return to the workshop. If the vehicle cannot save or drive yet, check the hull, turret, main gun, and their slots.

    Workshop tools include vehicle_catalog, vehicle_rules, vehicle_equip, vehicle_part_set_save, vehicle_part_set_place, and vehicle_save. Use an isolated test preset when replaying these operations.
