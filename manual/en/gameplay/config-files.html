    Edit the battle configuration

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run config-files
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "template": "${fixture}/battleConfig.yaml.default",
    "custom": "${fixture}/battleConfig.yaml"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    1. Find the configuration folder

    On Windows, look for the saves folder next to the game executable. On Android and iOS, look under saves in the game's persistent data directory. Use the connected MCP instance to query the application data paths.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/dataPath"
    },
    "expect": {
      "contains": "(String)"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/persistentDataPath"
    },
    "expect": {
      "contains": "(String)"
    }
  }
]

    2. Copy and edit the template

    Launch the game to generate battleConfig.yaml.default. Copy it to battleConfig.yaml in the same folder and keep the template's version field. This example changes the ramming damage multiplier from its default of 1 to 1.25.

    ramDamageCoff: 1.25
    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.BattleConfigAuthoring/WriteTemplate",
      "args": [
        "${template}"
      ]
    },
    "expect": {
      "contains": "battleConfig.yaml.default"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.BattleConfigAuthoring/WriteCopy",
      "args": [
        "${template}",
        "${custom}",
        "1.25"
      ]
    },
    "expect": {
      "contains": "battleConfig.yaml"
    }
  }
]

    3. Validate and launch

    Confirm that the file is named battleConfig.yaml and its version matches the current template. The game reads the configuration at startup and uses the defaults if the file is invalid or the version differs. The sample uses the project's YAML reader to verify a temporary file. Check the collision effect in game.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.BattleConfigAuthoring/Read",
      "args": [
        "${template}"
      ]
    },
    "expect": {
      "regex": "ramDamageCoff[^\\r\\n]*\\b1\\b"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.BattleConfigAuthoring/Read",
      "args": [
        "${custom}"
      ]
    },
    "expect": {
      "regex": "(?s)versionCode[^\\r\\n]*\\b1\\b.*ramDamageCoff[^\\r\\n]*\\b1\\.25\\b"
    }
  }
]
