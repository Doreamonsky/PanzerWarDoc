    Troubleshoot startup and back up saves

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run crash-and-launch-problems
    Click to expand MCP actionsClick to collapse MCP actions

    Prepare the teaching sample. The recipe provides ${variables}.

    {
  "variables": {
    "sample": "${fixture}/saves/profile/example.txt",
    "backup": "${fixture}/backup/saves",
    "restore": "${fixture}/recovered/profile/example.txt"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    1. Collect the failure details

    Record the game version, platform, error message and steps to reproduce it. Save the runtime log from the failing session before trying a fix.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/consoleLogPath"
    },
    "expect": {
      "contains": "(String)"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.SavePath/File",
      "args": [
        "example.txt"
      ]
    },
    "expect": {
      "contains": "saves/example.txt"
    }
  },
  {
    "tool": "logs",
    "arguments": {
      "count": 20
    }
  }
]

    2. Quit and back up your saves

    Quit the game completely. Copy the entire saves folder or archive it outside the app directory. On Windows it is beside the game executable. On Android and iOS it is under the app's persistent data directory. Back up mods separately if you need downloaded content.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/CreateDirectory",
      "args": [
        "${fixture}/saves/profile"
      ]
    },
    "expect": {
      "contains": "DirectoryInfo"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/CreateDirectory",
      "args": [
        "${fixture}/backup"
      ]
    },
    "expect": {
      "contains": "DirectoryInfo"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/WriteAllText",
      "args": [
        "${sample}",
        "Documentation save fixture"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.FileUtil/CopyFileOrDirectory",
      "args": [
        "${fixture}/saves",
        "${backup}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${backup}/profile/example.txt"
      ]
    },
    "expect": {
      "contains": "Documentation save fixture"
    }
  }
]

    3. Verify the backup and restore if needed

    Open the backup in a separate location and check that its files are readable and subfolders are intact. If you need to reinstall, verify that backup first, then use the official package for your platform. Quit the game after reinstalling and restore the files into the active saves directory. Keep the original backup until the game starts and loads your saves.

    The replay verifies copying and recovering a scratch backup, including its file contents.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.FileUtil/CopyFileOrDirectory",
      "args": [

        "${fixture}/recovered"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {

        "${restore}"
