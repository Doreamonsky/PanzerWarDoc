    Install mods

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run install-mods

    Download a .modpack built for the platform where you run the game. Windows, Android and iOS each require a corresponding build.

    1. Find the mods folder

    On Windows, use the mods folder beside the executable you actually launch. On Android and iOS, use mods under the game's persistent data directory. In the iOS Files app, open the folder for the installed game.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.ResourceManager.ResourceConsts/GetModDir()/FullName"
    },
    "expect": {
      "contains": "mods"
    }
  }
]

    2. Stage the package

    Find or create Installs under mods. Copy the complete .modpack directly into it, keeping the original extension and archive intact.

    Click to expand MCP actionsClick to collapse MCP actions

    Build a Windows teaching archive and copy it to a scratch mods/Installs folder. A downloaded mod does not need to be rebuilt.

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/Editor/DocumentationSamples/preset-vehicle-queue/Tutorial_VehicleQueue.asset",
        "${asset}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "asset:${pipeline}/linkedObjects/Add",
      "args": [
        "@asset:${asset}"
      ]
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.EditorUtility/SetDirty",
      "args": [
        "@asset:${pipeline}"
      ]
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/SaveAssets",
      "args": []
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  },
  {
    "tool": "modpack_plan",
    "arguments": {
      "pipeline": "${pipeline}"
    },
    "expect": {
      "equals": {
        "ok": true,
        "built": false
      },
      "contains": "\"vehiclequeue\""
    },
    "phase": "build"
  },
  {
    "tool": "modpack_build",
    "arguments": {
      "pipeline": "${pipeline}"
    },
    "expect": {
      "equals": {
        "ok": true,
        "archiveExists": true,
        "published": false,
        "installed": false
      }
    },
    "capture": {
      "archivePath": {
        "path": "archivePath"
      }
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:Frontend.Editor.ModPackageWorkshopMeta/WriteSidecar",
      "args": [
        "${archivePath}"
      ]

    "expect": {
      "contains": ".modpack.json"

  {

      ]
    },

    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {

  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Copy",
      "args": [
        "${archivePath}",
        "${staged}"
      ]
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  }
]

    3. Restart and check

    Restart the game to scan the top level of Installs. Check whether the mod content is available. If it is missing, check the platform, file location and archive integrity, then consult the runtime log. The replay verifies a Windows teaching archive and its staging. The game completes installation during startup.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${staged}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    },
    "phase": "build"
  }
