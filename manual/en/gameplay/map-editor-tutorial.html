    Create a map in the Map Workshop

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run map-editor-tutorial
    1. From the garage, enter the Map Workshop. Start with a blank map. Place the terrain and use invisible walls to enclose its edges. Separate overlapping surfaces to prevent Z-fighting.
    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "editor_status",
    "arguments": {}
  }
]
    Click to expand MCP actionsClick to collapse MCP actions

    Game-session example. Run map_new in a new teaching session. Get asset IDs from the catalog and keep the rule IDs returned by placement. Repeat wall placement and adjust the size to fit your map.

    [
  {
    "tool": "runtime_enter_mode",
    "arguments": {
      "mode": "93affaa7-4524-4c55-8a1b-3045a2310e8b"
    }
  },
  {
    "tool": "map_state",
    "arguments": {}
  },
  {
    "tool": "map_new",
    "arguments": {}
  },
  {
    "tool": "map_catalog",
    "arguments": {
      "search": "${terrainName}",
      "detail": true
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${terrainAsset}",
      "pos": "0,0,0"
    }
  },
  {
    "tool": "map_catalog",
    "arguments": {
      "search": "${wallName}",
      "detail": true
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${wallAsset}",
      "pos": "0,0,100"
    }
  },
  {
    "tool": "map_transform",
    "arguments": {
      "ruleGuid": "${wallRule}",
      "scale": "2,1,1"
    }
  }
]

    Game-session example. Get a tag asset ID from the catalog and keep each returned rule ID. The enum values represent team A, team B, and patrol.

    [
  {
    "tool": "map_catalog",
    "arguments": {
      "search": "${tagAssetName}",
      "detail": true
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${tagAsset}",
      "pos": "0,0,-50"
    }
  },
  {
    "tool": "map_props",
    "arguments": {
      "ruleGuid": "${tagRule0}"
    }
  },
  {
    "tool": "map_set_props",
    "arguments": {
      "ruleGuid": "${tagRule0}",
      "json": "{\"tag\": 0}"
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${tagAsset}",
      "pos": "0,0,50"
    }
  },
  {
    "tool": "map_props",
    "arguments": {
      "ruleGuid": "${tagRule1}"
    }
  },
  {

    1. Save under a new name. Return to the garage and select the map in a compatible game mode to check both teams' spawn positions and vehicle movement. You can first use the test range to check map and terrain loading. Runtime detail depends on distance and the assets' LOD settings.

    Game-session example. Pick a new save name if TutorialMap exists. The test range verifies loading. Check team spawns in a compatible battle mode.

    "arguments": {}
  },

    "tool": "runtime_exit_mode",
    "arguments": {}
  },
  {

      "mode": "PlayField",
      "map": "TutorialMap"

  }
