    Ravenfield map compatibility

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run ravenfield-map-support

    The current client has disabled registration of Ravenfield .rfl maps. The older folder layout, matching YAML, and manual ZIP workflow apply to the legacy version. To create a map for the current game, use the Map Workshop.

    Before distributing a Ravenfield map, make sure you have permission to publish it and its assets.
