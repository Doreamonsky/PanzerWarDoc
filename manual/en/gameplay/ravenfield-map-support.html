    Ravenfield map compatibility

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run ravenfield-map-support

    The current client has disabled registration of Ravenfield .rfl maps. To create a map for the current game, use the Map Workshop.

    Before distributing a Ravenfield map, make sure you have permission to publish it and its assets.

    View the legacy Steam map and configuration format

    Use these steps to identify old files or recover settings from a legacy archive. The former Steam Free edition supported the Maps - Mod Tools category of the Ravenfield Workshop. Subscribed items were downloaded to the Steam library under steamapps/workshop/content/636480, in a subfolder for each item. Legacy Ravenfield Workshop category

    1. Locate the file ending in .rfl. Installations that supported this format used steamapps/common/PanzerWar-DE/dlc/PanzerWar/Mods/StandaloneWindows64_RvlMaps.
    2. When a compatible client started, it generated map-name.rfl.yaml next to the map. To correct misplaced spawn points, set isCustomPoints: true and update the coordinates for both teams. Add one x, y, and z block per point. This example retains the original field names and capitalization.
    isCustomPoints: true
customTeamASpawnPoints:
- x: 0
  y: 0
  z: 0
- x: -4
  y: 0
  z: -4
- x: 4
  y: 0
  z: 4
customTeamBSpawnPoints:
- x: 0
  y: 0
  z: 0
customPartolPoints:
- x: 0
  y: 0
  z: 0
tileSize: 512
voxelSize: 2
    1. The original sharing workflow put the .rfl and its YAML in a ZIP named StandaloneWindows64_Example.modpack. Some old maps may fail to load or crash a legacy client.
