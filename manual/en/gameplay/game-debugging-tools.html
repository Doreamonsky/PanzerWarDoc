    Check game resources with debug commands

    中文 | English

    Run this command at the repository root to replay the examples through the local Unity MCP.

    python Docs/Manual/manual/tools/tutorials.py run game-debugging-tools

    1. Open the debug console

    Launch the game and wait for content to load. Open the game debug console. If you use MCP, check the connected project and runtime state before running a check.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "editor_status",
    "arguments": {},
    "expect": {
      "contains": "\"projectPath\""
    }
  }
]

    2. Choose a resource check

    Command Resources to check
    DebugDIY Vehicle DIY prefabs
    DebugMapDIY Map DIY prefabs
    DebugVehicles Vehicle resources

    Enter the command for the assets you need to check. Large resource sets can take time. Review the runtime log for load failures and record the operation that led to them. The editor replay verifies MCP connectivity and log access. Run the three resource checks in a running game.

    Click to expand MCP actionsClick to collapse MCP actions 
    [
  {
    "tool": "logs",
    "arguments": {
      "count": 3
    }
  }
]
    Click to expand MCP actionsClick to collapse MCP actions
