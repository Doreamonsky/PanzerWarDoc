    5. 闪退 & 无法进入问题解决方案 Crashes & Failure to Launch: Solutions

    此文档记录一些遇到的版本问题，以及解决方案。

    This document records some of the version-related problems that have been reported, together with their solutions.

    灰屏卡住 Stuck on a Grey Screen

    将 Documents/ShanghaiWindy/PanzerWarMods 文件夹重命名为 PanzerWarMods-Bak，进入游戏，车库左侧模组，点击申请外部 SDCard 权限。然后退出游戏，将 Documents/ShanghaiWindy/PanzerWarMods-Bak 重命名为 PanzerWarMods

    Rename the folder Documents/ShanghaiWindy/PanzerWarMods to PanzerWarMods-Bak, launch the game, open Mods on the left side of the garage, and click to request external SDCard permission. Then quit the game and rename Documents/ShanghaiWindy/PanzerWarMods-Bak back to PanzerWarMods.

    闪退 Crashes

    在升级完成版本后，进入某个场景发生闪退，可能是由部分老旧数据不兼容导致游戏闪退。解决方案：备份游戏存档，然后删除游戏，重新安装游戏。请务必看备份存档！

    If the game crashes when you enter a scene after upgrading to a new version, the crash may be caused by some old data that is no longer compatible. Solution: back up your game saves, then uninstall and reinstall the game. Be sure to read the "Backing Up Saves" section below first!

    备份存档 Backing Up Saves

    手动备份存档 Backing Up Saves Manually

    注意：一定要按如下步骤一步一步进行操作，切记不要跳步骤！

    Note: follow the steps below one by one, and never skip a step!

    1. 打开文件管理器 选择目录 Android / data / com.ShanghaiWindy.PanzerWarDEM / files / saves 长按选择复制，复制到 Android / data 目录下。

    若同时想要备份模组，可将 Android / data / com.ShanghaiWindy.PanzerWarDEM / files / mods 长按复制到 Android / data 目录下。

    1. 删除游戏，重新安装

    2. 正常打开游戏至车库，然后退出游戏

    3. 将 Android / data / saves 目录 复制到 Android / data / com.ShanghaiWindy.PanzerWarDEM / files / saves 下

    4. 打开游戏，确认数据

    5. 若要恢复模组数据，请完成步骤 1 的备份。然后，将 Android / data / mods 目录 复制到 Android / data / com.ShanghaiWindy.PanzerWarDEM / files / mods 下

    6. 打开游戏，确认 Mod

    7. Open your file manager, select the directory Android / data / com.ShanghaiWindy.PanzerWarDEM / files / saves, long-press it to copy it, and paste it into the Android / data directory.

    If you also want to back up your mods, long-press Android / data / com.ShanghaiWindy.PanzerWarDEM / files / mods and copy it into the Android / data directory as well.

    1. Uninstall the game, then reinstall it.
    2. Launch the game normally, go all the way to the garage, then quit the game.
    3. Copy the Android / data / saves directory into Android / data / com.ShanghaiWindy.PanzerWarDEM / files / saves.
    4. Launch the game and check that your data is there.
    5. To restore your mod data, you must have made the optional mods backup described in step 1. Then copy the Android / data / mods directory into Android / data / com.ShanghaiWindy.PanzerWarDEM / files / mods.
    6. Launch the game and check that your mods are there.
