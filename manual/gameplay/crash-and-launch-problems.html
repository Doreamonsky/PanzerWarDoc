    排查启动故障与备份存档

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run crash-and-launch-problems
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "sample": "${fixture}/saves/profile/example.txt",
    "backup": "${fixture}/backup/saves",
    "restore": "${fixture}/recovered/profile/example.txt"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    1. 保留故障信息

    记录游戏版本、平台、错误提示和复现步骤。找到运行日志，保留出问题时的记录，再尝试修复。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/consoleLogPath"
    },
    "expect": {
      "contains": "(String)"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.SavePath/File",
      "args": [
        "example.txt"
      ]
    },
    "expect": {
      "contains": "saves/example.txt"
    }
  },
  {
    "tool": "logs",
    "arguments": {
      "count": 20
    }
  }
]

    2. 退出游戏并备份

    完全退出游戏，复制整个 saves 目录，或将它压缩到应用目录之外。Windows 的 saves 在游戏可执行文件旁，Android 和 iOS 的 saves 在应用持久化数据目录下。需要保留下载的模组时，单独备份 mods。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/CreateDirectory",
      "args": [
        "${fixture}/saves/profile"
      ]
    },
    "expect": {
      "contains": "DirectoryInfo"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/CreateDirectory",
      "args": [
        "${fixture}/backup"
      ]
    },
    "expect": {
      "contains": "DirectoryInfo"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/WriteAllText",
      "args": [
        "${sample}",
        "Documentation save fixture"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.FileUtil/CopyFileOrDirectory",
      "args": [
        "${fixture}/saves",
        "${backup}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${backup}/profile/example.txt"
      ]
    },
    "expect": {
      "contains": "Documentation save fixture"
    }
  }
]

    3. 核对备份并按需恢复

    先在另一个位置打开备份，确认文件可读、子目录完整。若必须重装，请先验证这份备份，再使用对应平台的官方安装包。重装后退出游戏，将存档恢复到实际使用的 saves 目录。保留原备份，直到游戏能启动并读取存档。

    教学回放验证了临时目录的备份复制、恢复和文件内容。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.FileUtil/CopyFileOrDirectory",
      "args": [
        "${backup}",
        "${fixture}/recovered"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${restore}"
      ]
    },
    "expect": {
      "contains": "Documentation save fixture"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${sample}"
      ]
    },
    "expect": {
      "contains": "Documentation save fixture"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${backup}/profile/example.txt"
      ]
    },
    "expect": {
      "contains": "Documentation save fixture"
    }
  }
