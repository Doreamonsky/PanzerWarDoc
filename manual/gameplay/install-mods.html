    安装模组

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run install-mods
    点击展开 MCP 操作点击收起 MCP 操作

    先下载与当前运行平台匹配的 .modpack，再把文件放入游戏的安装队列。Windows、Android 和 iOS 各用对应平台构建的包。

    1. 找到模组目录

    Windows 使用实际启动的游戏可执行文件旁的 mods 目录。Android 和 iOS 使用游戏持久化数据目录下的 mods。在 iOS 的「文件」应用中，打开当前游戏对应的目录。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.ResourceManager.ResourceConsts/GetModDir()/FullName"
    },
    "expect": {
      "contains": "mods"
    }
  }
]

    2. 暂存安装包

    在 mods 下找到或创建 Installs。将完整的 .modpack 直接复制进去，保留原扩展名和压缩包结构。

    点击展开 MCP 操作点击收起 MCP 操作

    先生成可校验的 Windows 教学包，再复制进临时 mods/Installs。无需重建已经下载的模组包。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/Editor/DocumentationSamples/preset-vehicle-queue/Tutorial_VehicleQueue.asset",
        "${asset}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "asset:${pipeline}/linkedObjects/Add",
      "args": [
        "@asset:${asset}"
      ]
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.EditorUtility/SetDirty",
      "args": [
        "@asset:${pipeline}"
      ]
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/SaveAssets",
      "args": []
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  },
  {
    "tool": "modpack_plan",
    "arguments": {
      "pipeline": "${pipeline}"
    },
    "expect": {
      "equals": {
        "ok": true,
        "built": false
      },
      "contains": "\"vehiclequeue\""
    },
    "phase": "build"
  },
  {
    "tool": "modpack_build",
    "arguments": {
      "pipeline": "${pipeline}"
    },
    "expect": {
      "equals": {
        "ok": true,
        "archiveExists": true,
        "published": false,
        "installed": false
      }
    },
    "capture": {
      "archivePath": {
        "path": "archivePath"
      }
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:Frontend.Editor.ModPackageWorkshopMeta/WriteSidecar",
      "args": [
        "${archivePath}"
      ]
    },
    "expect": {
      "contains": ".modpack.json"
    },
    "capture": {
      "sidecarPath": {
        "regex": "\\(String\\) (.+)"
      }
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${sidecarPath}"
      ]
    },
    "expect": {
      "contains": "${packageGuid}"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/CreateDirectory",
      "args": [
        "${fixture}/mods/Installs"
      ]
    },
    "expect": {
      "contains": "DirectoryInfo"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Copy",
      "args": [
        "${archivePath}",
        "${staged}"
      ]
    },
    "expect": {
      "contains": "OK:"
    },
    "phase": "build"
  }
]

    3. 重启并检查

    重启游戏，启动流程会扫描 Installs 顶层的安装包。检查模组内容是否可用。如果没出现，先核对平台、文件位置和包是否完整，再查阅运行日志。教学回放已验证 Windows 模组包构建与暂存。实际安装由游戏启动流程完成。

    点击展开 MCP 操作点击收起 MCP 操作

  {

    "arguments": {

      "args": [
        "${staged}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    },
    "phase": "build"
  }
