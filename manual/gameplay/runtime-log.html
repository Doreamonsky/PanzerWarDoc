    开启和读取运行日志

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run runtime-log
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "marker": "${fixture}/log.debug"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    1. 确认实际目录

    连接到要排查的应用，读取 Application.persistentDataPath。这是发布版检查 log.debug 的目录。查看磁盘日志时，可用 Application.consoleLogPath 查询当前实例的日志文件路径。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/persistentDataPath"
    },
    "expect": {
      "contains": "(String)"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/consoleLogPath"
    },
    "expect": {
      "contains": "(String)"
    }
  }
]

    2. 开启发布版日志

    在持久化数据目录下创建 log.debug。文件可以为空，确保系统没有额外追加 .txt 后缀。重启游戏以重新检查标记。编辑器和调试构建默认开启日志。

    点击展开 MCP 操作点击收起 MCP 操作

    回放只在临时目录创建标记。发布版使用该应用自己的持久化数据目录。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/WriteAllText",
      "args": [
        "${marker}",
        ""
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${marker}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    3. 读取日志

    在连接的实例上调用 logs，读取调试缓冲区中的近期记录。向开发者提供问题发生时间和操作步骤。示例已验证路径查询、临时标记创建和 MCP 日志查询，发布版重启未实测。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "logs",
    "arguments": {
      "count": 20
    }
  }
]
