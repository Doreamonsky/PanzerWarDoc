    Ravenfield 地图兼容性

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run ravenfield-map-support

    当前客户端停用了 Ravenfield 的 .rfl 地图注册。旧教程中的目录、同名 YAML 和手工 ZIP 流程只适用于当时的版本。当前制作地图请使用地图工坊。

    分发 Ravenfield 地图之前，请确认你有权发布该地图和其中使用的资源。
