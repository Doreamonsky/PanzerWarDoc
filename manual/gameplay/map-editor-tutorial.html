    在地图工坊制作地图

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run map-editor-tutorial
    1. 从车库进入地图工坊。新建一张空白地图，先铺地形，再用空气墙封住边界。避免平面完全重叠，以免出现 Z-fighting 闪烁。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "editor_status",
    "arguments": {}
  }
]
    点击展开 MCP 操作点击收起 MCP 操作

    游戏会话示例。仅在新建的教学地图中运行 map_new。先从目录取得素材 ID，放置后记录返回的规则 ID。重复放置边界并按地图尺寸调整。

    [
  {
    "tool": "runtime_enter_mode",
    "arguments": {
      "mode": "93affaa7-4524-4c55-8a1b-3045a2310e8b"
    }
  },
  {
    "tool": "map_state",
    "arguments": {}
  },
  {
    "tool": "map_new",
    "arguments": {}
  },
  {
    "tool": "map_catalog",
    "arguments": {
      "search": "${terrainName}",
      "detail": true
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${terrainAsset}",
      "pos": "0,0,0"
    }
  },
  {
    "tool": "map_catalog",
    "arguments": {
      "search": "${wallName}",
      "detail": true
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${wallAsset}",
      "pos": "0,0,100"
    }
  },
  {
    "tool": "map_transform",
    "arguments": {
      "ruleGuid": "${wallRule}",
      "scale": "2,1,1"
    }
  }
]
    1. 放置 A 队出生点 TeamAStartPoint、B 队出生点 TeamBStartPoint 和巡逻点 PatorlPoint。保存需要三种 Tag 各至少一个。把两队出生点分开，给载具留出足够的空间。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.eTag/TeamAStartPoint"
    },
    "expect": {
      "contains": "(eTag) TeamAStartPoint"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.eTag/TeamBStartPoint"
    },
    "expect": {
      "contains": "(eTag) TeamBStartPoint"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.eTag/PatorlPoint"
    },
    "expect": {
      "contains": "(eTag) PatorlPoint"
    }
  }
]
    点击展开 MCP 操作点击收起 MCP 操作

    游戏会话示例。先从素材目录取 Tag 的素材 ID，每次放置后记录各自的规则 ID。Tag 枚举顺序为 A 队、B 队、巡逻点。

    [
  {
    "tool": "map_catalog",
    "arguments": {
      "search": "${tagAssetName}",
      "detail": true
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${tagAsset}",
      "pos": "0,0,-50"
    }
  },
  {
    "tool": "map_props",
    "arguments": {
      "ruleGuid": "${tagRule0}"
    }
  },
  {
    "tool": "map_set_props",
    "arguments": {
      "ruleGuid": "${tagRule0}",
      "json": "{\"tag\": 0}"
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${tagAsset}",
      "pos": "0,0,50"
    }
  },
  {
    "tool": "map_props",
    "arguments": {
      "ruleGuid": "${tagRule1}"
    }
  },
  {
    "tool": "map_set_props",
    "arguments": {
      "ruleGuid": "${tagRule1}",
      "json": "{\"tag\": 1}"
    }
  },
  {
    "tool": "map_place",
    "arguments": {
      "itemGuid": "${tagAsset}",
      "pos": "0,0,0"
    }
  },
  {
    "tool": "map_props",
    "arguments": {
      "ruleGuid": "${tagRule2}"
    }
  },
  {
    "tool": "map_set_props",
    "arguments": {
      "ruleGuid": "${tagRule2}",
      "json": "{\"tag\": 2}"
    }
  },
  {
    "tool": "map_items",
    "arguments": {}
  }
]
    1. 用新名称保存，返回车库后在适用的游戏模式中选这张图，检查两队出生位置和载具通行。可先在试验场确认地图与地形能正确加载。运行时会按距离和物件的 LOD 设置显示细节。
    点击展开 MCP 操作点击收起 MCP 操作

    游戏会话示例。若 TutorialMap 已存在，挑个新名称。进入试验场可检查加载，两个队伍的出生检查还需进入支持这张图的对战模式。

    [
  {
    "tool": "map_navmesh",
    "arguments": {}
  },
  {
    "tool": "map_save",
    "arguments": {
      "name": "TutorialMap",
      "overwrite": false
    }
  },
  {
    "tool": "map_maps",
    "arguments": {}
  },
  {
    "tool": "runtime_exit_mode",
    "arguments": {}
  },
  {
    "tool": "runtime_enter_mode",
    "arguments": {
      "mode": "PlayField",
      "map": "TutorialMap"
    }
  }
]
