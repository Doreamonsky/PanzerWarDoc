    修改战斗配置

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run config-files
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "template": "${fixture}/battleConfig.yaml.default",
    "custom": "${fixture}/battleConfig.yaml"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    1. 找到配置目录

    在 Windows 查找游戏可执行文件旁的 saves 目录。在 Android 和 iOS，配置目录为游戏持久化数据目录下的 saves。连接 MCP 后可查询实际的应用数据路径。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/dataPath"
    },
    "expect": {
      "contains": "(String)"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/persistentDataPath"
    },
    "expect": {
      "contains": "(String)"
    }
  }
]

    2. 复制模板并修改

    启动游戏生成 battleConfig.yaml.default。把它复制为同目录下的 battleConfig.yaml，保留模板的版本字段。以下示例将撞击伤害系数从默认的 1 改成 1.25。

    ramDamageCoff: 1.25
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.BattleConfigAuthoring/WriteTemplate",
      "args": [
        "${template}"
      ]
    },
    "expect": {
      "contains": "battleConfig.yaml.default"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.BattleConfigAuthoring/WriteCopy",
      "args": [
        "${template}",
        "${custom}",
        "1.25"
      ]
    },
    "expect": {
      "contains": "battleConfig.yaml"
    }
  }
]

    3. 核对并启动

    确认文件名为 battleConfig.yaml，版本与本次生成的模板一致。游戏启动时读取配置，格式错误或版本不匹配时会使用默认值。本页通过项目的 YAML 读取器验证了临时文件，实际碰撞效果要在游戏里检查。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.BattleConfigAuthoring/Read",
      "args": [
        "${template}"
      ]
    },
    "expect": {
      "regex": "ramDamageCoff[^\\r\\n]*\\b1\\b"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.BattleConfigAuthoring/Read",
      "args": [
        "${custom}"
      ]
    },
    "expect": {
      "regex": "(?s)versionCode[^\\r\\n]*\\b1\\b.*ramDamageCoff[^\\r\\n]*\\b1\\.25\\b"
    }
  }
]
