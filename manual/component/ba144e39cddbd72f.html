    2. VehicleTextData 使用说明 Usage Guide

    VehicleTextData 是一个用于配置载具（如坦克、机甲、汽车等）的各种参数的类。本文档将指导您如何在 Unity Inspector 界面上使用它。

    VehicleTextData is a class used to configure the various parameters of a vehicle (such as a tank, mech, or car). This document explains how to use it in the Unity Inspector.

    基础 Basics

    玩家状态参数 (基础数据) Player State Parameters (Basic Data)

    PSParameter - 这个属性包含了玩家状态的基本参数。例如，生命值、国家、载具类型等。

    PSParameter - This property contains the basic player state parameters, such as health, country, and vehicle type.

    移动 Movement

    履带参数 Track Parameters

    PTCParameter - 仅在载具使用履带时显示，此属性包含了履带控制器的参数。例如，坦克的动力，速度，负重轮参数，独立悬挂履带等。

    PTCParameter - Shown only when the vehicle uses tracks. This property contains the track controller parameters, such as the tank's power, speed, road wheel parameters, and independently suspended tracks.

    机甲参数 Mech Parameters

    MechParameter - 包含机甲控制器的参数。例如，机甲的转向速度，飞行参数等。

    MechParameter - Contains the mech controller parameters, such as the mech's turning speed and flight parameters.

    汽车参数 Car Parameters

    CarControllerParameter - 包含汽车控制器的参数。

    CarControllerParameter - Contains the car controller parameters.

    开火 Firing

    共享主炮数据 Shared Main Gun Data

    SharedGunData - 此属性用于存储可以在多个载具之间共享的主炮数据。包括炮弹类型、射速、弹道、弹药容量等。

    SharedGunData - This property stores main gun data that can be shared across multiple vehicles, including shell type, rate of fire, ballistics, and ammunition capacity.

    主炮参数 Main Gun Parameters

    TFParameter - 当没有共享主炮数据时显示，此属性包含了主炮的参数。例如，射速、弹道、炮口初速、后坐力等。

    TFParameter - Shown when there is no shared main gun data. This property contains the main gun parameters, such as rate of fire, ballistics, muzzle velocity, and recoil.

    自爆参数 Self-Destruct Parameters

    VehicleSelfExplosionParams - 包含载具自爆功能的相关参数。例如，自爆范围、自爆伤害、自爆延迟等。

    VehicleSelfExplosionParams - Contains the parameters for the vehicle self-destruct feature, such as blast radius, blast damage, and detonation delay.

    炮塔 Turret

    共享炮塔数据 Shared Turret Data

    SharedTurretData - 用于存储可以在多个载具之间共享的炮塔数据。包括炮塔旋转速度、炮管升降速度、最大仰角等。

    SharedTurretData - Stores turret data that can be shared across multiple vehicles, including turret rotation speed, gun barrel elevation speed, and maximum elevation angle.

    炮塔参数 Turret Parameters

    MTParameter - 当没有共享炮塔数据时显示，此属性包含了炮塔的参数。例如，炮塔旋转角度、炮管升降速度、最大俯角等。

    MTParameter - Shown when there is no shared turret data. This property contains the turret parameters, such as turret rotation angle, gun barrel elevation speed, and maximum depression angle.

    新多炮塔 New Multi-Turret

    多炮塔数据 Multi-Turret Data

    MultiFireSystemData - 此属性包含了多炮塔系统的数据。例如，每个炮塔的炮弹类型、射速、弹道等。

    MultiFireSystemData - Contains the data for the multi-turret system, such as the shell type, rate of fire, and ballistics of each turret.

    简单多炮塔数据 Simple Multi-Turret Data

    SimpleVehicleFireSystemParameters - 此属性包含了简单多炮塔系统的参数。例如，炮塔旋转速度、炮管升降速度等。

    SimpleVehicleFireSystemParameters - Contains the parameters for the simple multi-turret system, such as turret rotation speed and gun barrel elevation speed.
