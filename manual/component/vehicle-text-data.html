    VehicleTextData 使用说明

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    VehicleTextData 是载具配置的 ScriptableObject。本页只讲在 Unity Inspector 中选中资产、找到字段、填写值并核对结果。

    1. 选择资产

    1. 在 Project 窗口选中主类型为 VehicleTextData 的 .asset。创建菜单位置为 A Panzer War - 装甲纷争/G Ground Vehicle - 地面载具/Base - 载具配置/Vehicle Configuration - 载具配置参数。如果新建资产，将它赋给目标 VehicleData 的 vehicleTextData 引用。下文图片使用独立教学样例 Tutorial_VehicleTextData；在你的工程里请选择实际要制作的载具资产。
    2. 确认 AssetName 和 editorAssetGuid 属于目标载具；两者都是只读的资产标识字段，不能在此编辑。
    3. editorAssetGuid 是 Unity 制作资产的 GUID，不是队列使用的 vehicleGuid。队列载具 ID 由 VehicleInfo.GetLoadGUID() 返回，两者含义不同，不要互相代填。

    点击展开 MCP 操作点击收起 MCP 操作

    CreateAsset 对应新建资产；inspect_set 的对象引用赋值对应拖放到引用槽。以下把新建的配置赋给独立的 VehicleData；只读字段仅查询。

    2. 设置生命值与视野

    1. 在 基础 分组下展开 基础数据（字段 PSParameter）。
    2. 在 摄像机控制 分组中找到 血量（PSParameter.Health，图中标记 1）。代码默认值为 1200，本例教学值也填 1200。
    3. 在 视野 分组中找到 观察范围（PSParameter.viewRange，图中标记 2）。允许范围是 220–5000，代码默认值为 220，本例教学值填 600。
    4. 保存资产，再重新选中该资产，确认 PSParameter.Health 与 PSParameter.viewRange 已写入目标资产，而不是其他资产。

    PSParameter.Health=1200 和 PSParameter.viewRange=600 只是教学取值，不是官方平衡建议。

    3. 高级参数

    点击对应的 移动、开火、炮塔 或 多炮塔 标签页，再按下表寻找字段；杂项 位于标签页下方。

    字段 Inspector 分组与含义 显示条件与读取行为
    sharedGunData 共享主炮数据（开火） 始终显示；非空时 GetTankFireParam() 返回其中的 tankFireParameter。
    TFParameter 主炮参数（开火） 仅当没有 sharedGunData 时显示；此时 GetTankFireParam() 返回它。
    sharedTurretData 共享炮塔数据（炮塔） 始终显示；非空时 GetTurretParam() 返回其中的 turretParameter。
    MTParameter 炮塔参数（炮塔） 仅当没有 sharedTurretData 时显示；此时 GetTurretParam() 返回它。
    PTCParameter 履带参数（移动） 仅在 GetGroundType() 返回 TrackController（IsTrackController() 为真）时显示。
    MultiFireSystemData 旧版多炮塔系统（弃用） 旧版多炮塔列表，新载具不要新增。
    simpleVehicleFireSystemParameters 新版多炮塔系统 当前多炮塔配置列表，元素类型为 SimpleVehicleFireSystemParameter。
    vehicleSelfExplosionParams 自爆数据（杂项） 元素类型为 VehicleSelfExplosionTextParameter 的数组，按数组元素填写。

    PTCParameter 的显示由 GetGroundType() 的判定顺序决定：isStationary → Stationary，MechParameter.isMech → MechController，LuaVehicleControllerParameter.isLua → Lua，ShipControllerParameter.isShip → Ship，其余情况才返回 TrackController。因此只把模型做成履带车，并不保证该字段出现。

    sharedGunData 和 sharedTurretData 是共享引用：多个载具指向同一资产时，修改会影响所有引用者；没有共享引用时才分别使用 TFParameter 或 MTParameter。教学样例保留了 sharedGunData 引用，所以该样例中 TFParameter 不显示；这对只练习生命值与视野的步骤没有影响。

    4. 检查

    1. 确认 AssetName 和 editorAssetGuid 未变，PSParameter.Health 与 PSParameter.viewRange 已写入目标资产。
    2. Inspector 截图只能证明字段位置与分组，不能证明运行时效果；要确认实际表现，需要在游戏内做一次检查。
    3. 如果后续需要调整高级参数，先确认上表的显示条件，再去对应分组里寻找字段。
