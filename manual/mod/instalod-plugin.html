    使用 InstaLOD 生成载具 LOD

    中文 | English

    LOD 生成随模组 SDK 一起提供：SDK 清单已引用同仓库的兄弟包 com.shanghaiwindy.simplygon，该包内置 InstaLOD 和 InstaLodMeshProvider。使用公开 SDK 时不需要手动安装任何包。实际承担 LOD 处理的是 InstaLOD，尽管包名和字段名写作 simplygon。

    普通自动 LOD 在 VehicleData.isGenLOD 启用时执行。高级模式还需要同时满足 isPriorityAdvanceLOD 与 EditorStorage.useSimplygon 为 true；useSimplygon 默认是 false，因此在你显式开启前高级模式不会生效。

    1. 在载具数据上启用 isGenLOD。若需要高级减面，先在 Window → InstaLOD 完成本机授权，再启用载具的优先使用先进的 LOD 技术与编辑器配置中的接入 Insta Lod 插件。高级减面报授权错误时，可关闭项目级开关后用普通 LOD 重新打包。 InstaLOD 官方说明
    2. 重新 Repack 该载具，让管线执行。
    3. 查看生成的 prefab 及其 LODGroup，确认实际产出的层级。层级数量和命名取决于资产本身，不要假定固定的节点名。

    下面的截图流程属于历史记录：包安装与配置界面来自更早版本的客户端，不要把其中的标签当作当前 UI 的承诺。

    • Package Manager → Add package from disk，选择提供方的 package.json；更早的 SDK 还需要提供方授权。
    • Framework → Gm → Editor Config → Use Insta Lod，再 Save。
    • Repack，然后 Open Vehicle Data Tool → View Packed Asset。

    共享烘焙目录的默认网格路径为 Assets/Res/Cooked/SimplifiedMeshGroup。载具选择本地烘焙时，检查它的输出目录下的 SimplifiedMeshGroup。旧图中主车体节点的后缀为 100、75、50、30，实际层级以本次生成的 LODGroup 为准。管线之外的网格编辑见 InstaLOD Studio。
