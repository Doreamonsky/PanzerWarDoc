    配置载具缩放倍率

    中文 | English

    下方 MCP 示例使用独立教学资产。${变量} 由共享配方提供；在仓库根目录运行以下命令可创建样例、逐组执行并重拍两种语言。调用经本机 Unity MCP 的相同路由执行。

    python Docs/Manual/manual/tools/tutorials.py run zoom-ratio-config --capture
    点击展开 MCP 操作点击收起 MCP 操作

    教学样例的准备操作（仅用于复现配图，不修改官方资产）。

    {
  "variables": {
    "asset": "${fixture}/Tutorial_ZoomProfile.asset",
    "vehicle": "${fixture}/Tutorial_VehicleTextData.asset",
    "gun": "${fixture}/Tutorial_SharedGun.asset"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    本教程用 ZoomProfileData 资产为载具设置双目与瞄准镜的缩放倍率范围。所有字段名保持源代码中的原始拼写。

    1. 创建 ZoomProfileData 资产

    在 Project 窗口选择 Create > A Panzer War - 装甲纷争 > G Ground Vehicle - 地面载具 > Base - 载具配置 > Zoom - 倍率，创建 ZoomProfileData 资产。展开 倍率名称（zoomName），把默认名称填为 Tutorial Zoom。

    本例使用独立教学资产，不修改现有载具配置。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.ZoomProfileData)",
        "${asset}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${asset}/zoomName/defaultName",
      "value": "Tutorial Zoom"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "static:UnityEditor.Selection/activeObject",
      "value": "@asset:${asset}"
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. 设置缩放倍率范围

    minRatio 默认值为 1.9，maxRatio 默认值为 3.5。请使用正数倍率，并让 minRatio 小于或等于 maxRatio；这是作者约束，代码没有在此处校验。教程示例采用 minRatio = 2、maxRatio = 8，分别设置低倍与高倍端点。

    运行时会读取这两个值来得出可用的倍率范围：BaseVehiclePawn.GetZoomRatio 对双目读取 binocularZoomProfileData 的 minRatio 与 maxRatio，对瞄准镜读取 zoomProfileData 的同样字段；资产为空时会退回到内置的默认区间。VehicleCameraZoom 随后按倍率换算水平视场角，并在区间内做插值。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${asset}/minRatio",
      "value": "2"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${asset}/maxRatio",
      "value": "8"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/minRatio"
    },
    "expect": {
      "contains": "2"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/maxRatio"
    },
    "expect": {
      "contains": "8"
    }
  }
]

    3. 视觉覆盖与热成像

    勾选 是否重载成像（isVisionOverride）后，才会显示 是否具有热成像（isThermalVision）。两项默认均为 false，本例均设为 true。运行时的热成像锁定条件仍可禁止热成像；此开关不是无条件启用游戏效果的保证。

    如果不打算改变视觉模式，就保持两个开关为 false，缩放倍率仍然照常生效。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${asset}/isVisionOverride",
      "value": "true"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${asset}/isThermalVision",
      "value": "true"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/isThermalVision"
    },
    "expect": {
      "contains": "True"
    }
  }
]

    4. 指派到载具参数

    按用途选择引用槽：双目使用 VehicleTextData.PSParameter.binocularZoomProfileData；瞄具使用实际火炮参数的 zoomProfileData。有 sharedGunData 时在其 tankFireParameter.zoomProfileData 设置；没有共享引用时，在载具的 TFParameter.zoomProfileData 设置。同一个倍率资产可以用于两个槽位。

    指派完成后保存并读回引用。本配方验证编辑器资产与引用，未验证游戏内视场角、热成像效果或模组加载。

    点击展开 MCP 操作点击收起 MCP 操作

    对象引用赋值对应把倍率资产拖到引用槽。本例创建独立参数资产并读回引用，未进入游戏验证视角或热成像效果。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.VehicleTextData)",
        "${vehicle}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.SharedGunData)",
        "${gun}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/PSParameter/binocularZoomProfileData",
      "value": "@asset:${asset}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${gun}/tankFireParameter/zoomProfileData",
      "value": "@asset:${asset}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/sharedGunData",
      "value": "@asset:${gun}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vehicle}/PSParameter/binocularZoomProfileData/name"
    },
    "expect": {
      "contains": "Tutorial_ZoomProfile"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vehicle}/GetTankFireParam()/zoomProfileData/name"
    },
    "expect": {
      "contains": "Tutorial_ZoomProfile"
    }
  }
]
