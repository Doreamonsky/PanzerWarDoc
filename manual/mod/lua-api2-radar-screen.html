    22.7.3 用例：防空雷达屏幕 Example: Air-Defence Radar Screen

    游戏自带完整的雷达系统：按雷达方程探测、地杂波、地形遮挡、锁定捕获时间、给目标的雷达告警，以及游戏自己的雷达界面。你只需要在载具数据里配置 groundAARadarData，雷达就会工作；脚本负责的只是你自己设计的那块屏幕。

    The game includes a complete radar system: detection via the radar equation, ground clutter, terrain occlusion, lock-on capture time, radar warnings to the target, and the game's own radar interface. You only need to configure groundAARadarData in the vehicle data for the radar to work; the script is only responsible for the screen you design yourself.

    配置雷达 Configuring the Radar

    在载具数据（VehicleTextData）的 groundAARadarData 里勾选 hasRadar，常用的字段：

    In the vehicle data (VehicleTextData), tick hasRadar within groundAARadarData. Commonly used fields:

    字段 Field 含义 Meaning
    maxDetectionRange 最大探测距离（米）
    Maximum detection range (m)
    isFullRotation / fullRotationRate 360° 旋转搜索及其转速（度/秒）
    360° rotating search and its rate (°/s)
    searchAzimuthHalfAngle / searchElevationHalfAngle 搜索区的水平与俯仰半角
    Half angles of the search area
    minElevationAngle 低于这个俯仰角的目标按地杂波过滤
    Targets below this elevation are filtered as ground clutter
    detectGroundTargets 打开后不做地杂波过滤，可以探测地面载具（战场搜索雷达）
    Skips the clutter filter so ground vehicles are detected (battlefield search radar)
    displayRanges 屏幕可切换的量程
    Display ranges you can switch between
    canUsePD / pdMinDetectableSpeed 脉冲多普勒模式及最低可探测速度
    Pulse-Doppler mode and its minimum detectable speed
    hasIFF 敌我识别；没有时无法区分友军
    IFF; without it friendly contacts cannot be told apart

    屏幕脚本 The Screen Script

    Behavior()
Property = {}

local RadarScreen = class("RadarScreen")

local GUI = CS.UnityEngine.GUI
local Rect = CS.UnityEngine.Rect

function RadarScreen:OnVehicleReady(vehicle)
  -- 雷达参数在载具数据的 groundAARadarData 里配置，这里只读结果
  -- The radar is configured in the vehicle data (groundAARadarData); the script only reads it
  local ok, radar = RadarAPI.TryGetRadar(vehicle)
  if not ok then
    self.script:SetUpdateEnabled(false)
    return
  end

  self.vehicle = vehicle
  self.radar = radar
  self.text = ""

  RadarAPI.OnLockChanged(self.script, radar, function(locked, target)
    if locked then
      print("[Radar] locked " .. VehicleAPI.GetDisplayName(target))
    else
      print("[Radar] lock lost")
    end
  end)

  -- 每秒刷新 5 次列表就够了 / Five list refreshes a second are enough
  self.script:SetUpdateInterval(0.2)
end

function RadarScreen:OnUpdated(dt)
  -- 玩家可能在编组的载具之间切换，所以每次刷新时判断，而不是在 OnVehicleReady 里关掉
  -- The player may switch between the vehicles of a group, so check on every refresh instead of turning updates off once
  self.visible = VehicleAPI.IsLocalPlayer(self.vehicle) and RadarAPI.IsActive(self.radar)
  if not self.visible then
    return
  end

  local lines = {}
  local count = RadarAPI.GetContactCount(self.radar)
  for i = 0, count - 1 do
    local ok, target, distance, azimuth, elevation, altitude, radialSpeed, isFriendly = RadarAPI.GetContact(self.radar, i)
    if ok then
      local name = target ~= nil and VehicleAPI.GetDisplayName(target) or "?"
      local bearing = RadarAPI.GetContactWorldAzimuth(self.radar, i)
      lines[#lines + 1] = string.format("%s %s  %.1f km  %03.0f°  %.0f m",
          isFriendly and "+" or "!", name, distance / 1000, bearing, altitude)
    end
  end
  self.text = table.concat(lines, "\n")
end

function RadarScreen:OnGUI()
  if self.visible then
    -- 只画缓存好的文字，不在 OnGUI 里计算 / Draw the cached text only; compute nothing in OnGUI
    GUI.Label(Rect(20, 120, 360, 300), self.text)
  end
end

return RadarScreen

    要点：

    Key points:

    • 目标列表用 GetContactCount 和 GetContact 读取。GetContact 一次返回多个值：是否成功、目标载具、距离、方位、俯仰、高度、径向速度、是否友军。目标是箔条回波时，目标载具为 nil。

    • GetContact 给出的方位和俯仰是雷达自身坐标系下的角度（度）。画北向朝上的屏幕时，用 GetContactWorldAzimuth 取世界方位。

    • 想让模型上的天线跟着转，可以读 RadarAPI.GetScanAzimuth：它是天线相对安装座的偏航角，范围 -180 到 180 度。

    • 列表每秒刷新 5 次，OnGUI 只画缓存好的文字。不要在 OnGUI 里计算，它一帧会被调用好几次。

    • 远程玩家的载具副本不会在本地运行雷达，读到的目标数为 0；联机时读取敌方载具的雷达也返回 0。

    • RadarAPI.TryLock、Unlock、CycleTarget、SwitchMode 只对玩家正在控制的载具生效。TryLock 和玩家按键锁定一样：目标必须在雷达屏幕上，并且有捕获时间。

    • The target list is read using GetContactCount and GetContact. GetContact returns multiple values at once: success status, target vehicle, distance, azimuth, elevation, altitude, radial velocity, and whether it is a friendly unit. If the target is a chaff echo, the target vehicle is nil.

    • The azimuth and elevation provided by GetContact are angles (in degrees) in the radar's own coordinate system. When drawing a screen with north at the top, use GetContactWorldAzimuth to get the world azimuth.

    • If you want the antenna on the model to rotate accordingly, you can read RadarAPI.GetScanAzimuth: it is the yaw angle of the antenna relative to its mount, ranging from -180 to 180 degrees.

    • The list refreshes 5 times per second, and OnGUI only draws cached text. Do not perform calculations in OnGUI, as it is called multiple times per frame.

    • Vehicle replicas for remote players do not run the radar locally, so the number of targets read will be 0; in online battles, reading the radar of enemy vehicles also returns 0.

    • RadarAPI.TryLock, Unlock, CycleTarget, and SwitchMode only work on the vehicle currently controlled by the player. TryLock works like the player's lock key: the target must be on the radar scope, and the lock takes the acquisition time.
