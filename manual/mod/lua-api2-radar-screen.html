    1. 配置地面雷达

    选中载具的 VehicleTextData，在杂项 → 防空雷达展开 groundAARadarData，启用 hasRadar。回放示例采用 12,000 m 最大探测距离、360° 旋转搜索和 60°/s 转速。定向雷达可关掉旋转搜索，再调方位和俯仰半角。

    字段 含义
    maxDetectionRange 最大探测距离，单位米
    isFullRotation、fullRotationRate 全向轮转搜索与转速，单位度/秒
    searchAzimuthHalfAngle、searchElevationHalfAngle 搜索区各自的半角，默认 45°／30°。
    minElevationAngle、detectGroundTargets 俯仰低于 2° 的回波默认按地杂波过滤。允许地面目标时绕过这一项过滤，距离和扫描范围仍然生效。
    displayRanges 屏幕可切换的量程，默认 2,500／5,000／10,000／20,000 m。
    canUsePD、pdMinDetectableSpeed 脉冲多普勒模式与速度门限，默认门限 30 m/s。
    hasIFF 开启时显示并区分友军回波。

    2. 绑定并更新列表

    1. 把下方脚本保存为 RadarScreen.lua，导入 SDK 工程。选中载具预制体的子节点，挂上 LuaBehaviorMono，把脚本拖进 Behavior，然后保存并重打包。LuaBehaviorMono 用法
    2. OnVehicleReady 取得雷达并订阅锁定变化。示例每 0.2 秒刷新文字。Unity 每帧可能多次调用 OnGUI，所以绘制时直接用缓存。
    3. 从 0 到 GetContactCount(radar) - 1 读取最近扫描的回波。GetContact 依次返回成功标记、目标、距离、方位、俯仰、高度、径向速度和友军标记。箔条的目标为 nil，距离和高度以米计，径向速度以 m/s 计。方位与俯仰使用雷达参考系。北向朝上的屏幕用 GetContactWorldAzimuth，外观天线可用 GetScanAzimuth 取得相对安装座的 −180° 至 180° 偏航。
    Behavior()
Property = {}

local RadarScreen = class("RadarScreen")
local GUI = CS.UnityEngine.GUI
local Rect = CS.UnityEngine.Rect

function RadarScreen:OnVehicleReady(vehicle)
    local ok, radar = RadarAPI.TryGetRadar(vehicle)
    if not ok then
        self.script:SetUpdateEnabled(false)
        return
    end
    self.vehicle = vehicle
    self.radar = radar
    self.lines = {}
    self.text = ""
    RadarAPI.OnLockChanged(self.script, radar, function(locked, target)
        if locked and target ~= nil then
            print("[Radar] locked " .. VehicleAPI.GetDisplayName(target))
        elseif not locked then
            print("[Radar] lock lost")
        end
    end)
    self.script:SetUpdateInterval(0.2)
end

function RadarScreen:OnUpdated()
    self.visible = self.radar ~= nil
        and VehicleAPI.IsLocalPlayer(self.vehicle)
        and RadarAPI.IsActive(self.radar)
    if not self.visible then
        return
    end
    local written = 0
    for index = 0, RadarAPI.GetContactCount(self.radar) - 1 do
        local ok, target, distance, azimuth, elevation, altitude, radialSpeed, isFriendly =
            RadarAPI.GetContact(self.radar, index)
        if ok then
            local name = target ~= nil and VehicleAPI.GetDisplayName(target) or "?"
            local bearing = RadarAPI.GetContactWorldAzimuth(self.radar, index)
            written = written + 1
            self.lines[written] = string.format("%s %s  %.1f km  %03.0f°  %.0f m",
                isFriendly and "+" or "!", name, distance / 1000, bearing, altitude)
        end
    end
    for index = written + 1, #self.lines do
        self.lines[index] = nil
    end
    self.text = table.concat(self.lines, "\n")
end

function RadarScreen:OnGUI()
    if self.visible then
        GUI.Label(Rect(20, 120, 360, 300), self.text)
    end
end

return RadarScreen

    3. 在试车场检查探测和锁定

    1. 驾驶这辆车并开启雷达，让一架飞机进入实际搜索区，检查列表的方位、距离与高度。关掉雷达，列表应隐藏。远程玩家的载具副本不会在本机扫描。
    2. TryLock、Unlock、CycleTarget、SwitchMode 只对本地控制的载具操作。TryLock 要求从雷达当前可见回波中选目标，仍要等待捕获时间。锁定或丢失后，示例应往 Console 写一条 [Radar] 日志。

    MCP 回放核对配置、脚本绑定以及无雷达、箔条、过期行与非活跃雷达的列表逻辑。实际探测和锁定需要游戏场景。
