    07. VFX Mod 特效模组

    Identifier 资源标识

    通过资源标识，创建特效包的选项，保证可以选择不同的特效包进行切换

    The resource identifier creates the entry for a VFX package, so that different VFX packages can be selected and switched between.

    旧版“马哥特效包”的共享 Identifier 资产已经无法恢复。若只是制作自己的特效包，请在 Project 窗口选择 Create > A Panzer War - 装甲纷争 > P Pool - 对象池 > Pool Resource Identifier - 对象池标识 新建 Identifier，再将其关联到下方的 Pool Resource。Identifier 的 GUID 会自动生成。

    The shared Identifier asset of the old “马哥特效包” VFX package can no longer be recovered. If you are only building your own VFX package, create a new Identifier from the Project window with Create > A Panzer War - 装甲纷争 > P Pool - 对象池 > Pool Resource Identifier - 对象池标识, then link it to the Pool Resource below. The GUID of the Identifier is generated automatically.

    若必须向旧特效包追加资源，需要从原特效包作者处取得同一个 Identifier 资产；新建资产的 GUID 不同，不能作为兼容替代。

    If you really need to add resources to an old VFX package, you must obtain the very same Identifier asset from the author of that package. A newly created asset has a different GUID and cannot serve as a compatible replacement.

    Pool Resource 特效资源

    创建 Pool Resource ，关联 Identifier。

    Create a Pool Resource and link the Identifier to it.

    添加 Spawn Reses

    Add Spawn Reses.

    特效名称：特效的键值，可自定义，然后在 Bullet VFX 中选择自定义的特效键值进行关联

    VFX name: the key of the effect. You may name it freely, then select this custom key in Bullet VFX to link the two.

    特效物体：特效的预制体

    VFX object: the prefab of the effect.

    预加载实例数量，在加载场景的时候，预先加载一批特效进内存，减少游戏时的卡顿，但是填写过大的一个数量，会导致加载时间的增加。 填写 -1 则表示运行时根据需求再创建。

    Preload instance count: loads a batch of effects into memory while the scene is loading, which reduces stutter during play. Entering too large a number increases the loading time. Enter -1 to create instances on demand at runtime instead.

    生命时长：特效播放的时长，时间到之后会被回收以便下次使用。 请不要填写 0，0 是为了喷火，激光等特殊特效所准备的

    Lifetime: how long the effect plays. When the time is up, the effect is recycled so it can be used again. Do not enter 0 — 0 is reserved for special effects such as flamethrowers and lasers.

    特效对象池的物体，请挂载 PoolItemComponent。 若此物体是炮弹的 Weapon Projectile , 请将其拖尾特效挂到指定位置

    Attach PoolItemComponent to the objects in the VFX pool. If the object is the Weapon Projectile of a shell, attach its trail effect at the designated position.

    Using the VFX 特效的使用

    在重载中，选择你的特效。如果不使用重载的选项，请务必将你的特效的模组包的放入你的载具依赖的 guid 中。

    Select your effect in the override settings. If you do not use the override option, make sure the guid of your VFX mod package is added to the dependency guids of your vehicle.

    Build 打包

    将 Pool Resource 放入 BuildPipline

    Put the Pool Resource into the BuildPipline.
