    VRM 角色用 Unity 内的 VRM 插件处理。先准备模型和骨骼参考点，再导出回源文件，最后才配置数据并打包。

    1. 导入 VRM 模型

    把 .vrm 文件拖入 Unity 的 Project 窗口完成导入，再把导入后的资源拖到 Hierarchy。新实例的角色根节点带有 Vrm10Instance，骨骼和 SpringBone 位于其下。

    使用第三方模型时，先核对现有 Center 引用。如果缺失或指向不合适的对象，再按下文修正。

    2. 修正 SpringBone 中心参考点

    1. 按 Ctrl+G 打开 Framework → Editor Tools，在搜索框输入 VRM Util，打开 VRM 工具。
    2. 在 Hierarchy 展开角色根节点，把它的 Root 子物体拖到 Center。Unity 会绑定该子物体自身的 Transform。
    3. 把带 Vrm10Instance 的角色根（示例名 DemoVrm）拖到 Vrm 10 Instance。
    4. 点击 Set Center Transform。

    这一步会逐条写入 SpringBone 的 Center 引用，让骨骼物理围绕角色的实际中心计算。之后在场景里移动角色，检查头发和裙摆不会抖动或飞出。

    3. 导出 VRM 1.0

    1. 选中角色根节点，再点顶部菜单的 VRM1 → Export VRM 1.0...。
    2. 在导出窗口核对 ExportRoot 指向该角色根，Meta 页的 Name 和 Authors 与授权信息一致。
    3. 导出到源 .vrm 的同一路径以覆盖它；源文件不可写时，另存一个可写的副本，然后在数据里重新绑定这个新路径。副本需要保留原模型的许可。

    不要删改 Meta 里的许可字段。重新导出时应保持原有的作者、许可和允许用途不变，只更新你想更新的内容。

    4. 配置 VRM 角色数据

    在 Project 窗口用 Create > A Panzer War - 装甲纷争 > C Config - 配置 > VRM Character - VRM 人物 新建 VrmCharacterData。

    • VRM 模型路径：指向以 .vrm 结尾的源文件。
    • GUID：该资源自身的标识，生成后保持稳定，发布过的资源不要改动。
    • 高度、半径、舱盖起点位置：当前默认值分别为 1.6、0.25、0.5。旧截图中出现的 1.56、0.15、0.84 只是示例数值，请按模型实测填写。
    • 桌面端贴图尺寸上限、移动端贴图尺寸上限：当前默认分别为 1024 和 512。选 None 会保留源 PNG/JPG；选择具体尺寸会把贴图压到 DXT/ASTC 并限制在该边长内。

    舱盖的开关与乘员上下车位置见载具舱盖适配。

    5. 打包前的检查

    构建时收集器会把源 .vrm 文件复制成 <GUID>-model.vrm 放进包内，并按当前打包平台套用贴图上限。Unity 场景内对模型、骨骼和材质的改动不会被打包，除非已经导出回 .vrm。

    因此调整完骨骼参考点或授权信息后，先完成上面的导出，再开始构建。打包前确认模型路径可读、GUID 稳定，以及桌面端和移动端的上限符合本次发布要求。

    6. 在 CrewData 中引用

    在 CrewData 的 VRM 角色GUID 字段填入第 4 步的 VrmCharacterData GUID。打包后检查角色的高度、半径、舱盖起点和贴图尺寸是否与配置一致。乘员数据的完整字段见成员数据。
