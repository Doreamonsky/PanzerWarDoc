    22.7.5 用例：模块被毁时播放动画 Example: Animation When a Module Is Destroyed

    某个内部模块（例如弹药架、发动机）被击毁时，播放一个 Animator 触发器，例如炸开舱盖或冒出火焰。

    When an internal module (for example, an ammunition rack or engine) is destroyed, play an Animator trigger, such as blowing open a hatch or emitting flames.

    以前的写法是每帧读取模块血量，还要猜测血量字段叫什么名字。InternalModuleAPI.OnStateChanged 在模块状态变化时直接通知脚本。

    The previous approach was to read the module's health every frame and guess the name of the health field. InternalModuleAPI.OnStateChanged notifies the script directly when the module's state changes.

    把脚本挂在内部模块所在的物体上，在属性里关联带 Animator 的物体，并填写触发器名称。

    Attach the script to the object containing the internal module, link the object with the Animator in the properties, and enter the trigger name.

    Behavior()
Property = {
  animator = { type = "object", value = nil },           -- 要播放动画的 Animator 所在物体 / Object with the Animator to trigger
  triggerName = { type = "string", value = "Destroyed" },
}

local ModuleDestroyedTrigger = class("ModuleDestroyedTrigger")

-- 脚本挂在内部模块所在的物体上 / Attach this script to the internal module's object
function ModuleDestroyedTrigger:OnVehicleReady(vehicle)
  -- 模块组件在载具装配完成后才有，所以在 OnVehicleReady 里取
  -- The module component exists only once the vehicle is assembled, so get it in OnVehicleReady
  local module = InternalModuleAPI.GetInternalModule(self.gameObject)
  if module == nil or self.animator == nil then
    print("[ModuleTrigger] no module or animator on " .. self.gameObject.name)
    return
  end

  local animator = ComponentAPI.GetNativeComponent(self.animator, "Animator")
  InternalModuleAPI.OnStateChanged(self.script, module, function(oldState, newState)
    if InternalModuleAPI.IsDestroyed(module) then
      animator:SetTrigger(self.triggerName)
    end
  end)
end

return ModuleDestroyedTrigger

    要点：

    Key points:

    • 模块组件在载具装配完成后才创建，所以在 OnVehicleReady 里用 InternalModuleAPI.GetInternalModule(self.gameObject) 获取；在 OnStarted 里可能还取不到。

    • 状态变化包括损坏、摧毁和修复。需要区分时，可以读 newState，或者调用 IsDestroyed、GetHitPointRatio。

    • 需要知道每次受到的伤害时，用 InternalModuleAPI.OnDamaged。

    • The module component is only created after the vehicle is assembled, so use InternalModuleAPI.GetInternalModule(self.gameObject) in OnVehicleReady to retrieve it; it may not be available in OnStarted.

    • State changes include damage, destruction, and repair. To distinguish between them, you can read newState, or call IsDestroyed and GetHitPointRatio.

    • To know the damage received each time, use InternalModuleAPI.OnDamaged.
