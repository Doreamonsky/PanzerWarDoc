    用这段脚本在弹药架或发动机等内部模块损毁时播放演示动画，例如打开盖板，或播放发动机火焰。脚本在游戏发出模块事件时更新，可以省去逐帧读取模块血量。

    1. 配置 Animator 并绑定脚本

    1. 打开伤害模型的 Prefab Mode。把要播放动画的物体放在该预制体内，例如作为模块的子节点，给它添加 Animator 并绑定 Animator Controller。在 Animator → Parameters 用 + → Trigger 创建 Destroyed。为目标动画建状态并设置过渡条件 Destroyed。
    2. 将下方 Lua 脚本导入 Unity。在内部模块所在物体上添加 LuaBehaviorMono 并绑定脚本。
    3. 将有 Animator 的物体拖到 animator，填写 triggerName，字符和大小写需与控制器一致。保存预制体。

    脚本在 OnVehicleReady 获取模块，因为 OnStarted 时伤害模型可能仍未装配。如果测试时没有触发，先核对脚本是否与内部模块挂在同一节点，再检查 animator 引用。

    Behavior()
Property = {
    animator = { type = "object", value = nil },
    triggerName = { type = "string", value = "Destroyed" },
}

local ModuleDestroyedTrigger = class("ModuleDestroyedTrigger")

function ModuleDestroyedTrigger:OnVehicleReady(vehicle)
    local module = InternalModuleAPI.GetInternalModule(self.gameObject)
    if module == nil or self.animator == nil then
        return
    end
    local animator = ComponentAPI.GetNativeComponent(self.animator, "Animator")
    if animator == nil then
        return
    end
    local wasDestroyed = InternalModuleAPI.IsDestroyed(module)
    InternalModuleAPI.OnStateChanged(self.script, module, function()
        local destroyed = InternalModuleAPI.IsDestroyed(module)
        if destroyed and not wasDestroyed then
            animator:SetTrigger(self.triggerName)
        end
        wasDestroyed = destroyed
    end)
end

return ModuleDestroyedTrigger

    2. 验证状态和动画

    1. 在试车中让该模块从完好变为损毁。只有第一次进入损毁状态时应触发动画。修复后再损毁一次，应能再次触发。
    2. 如果你需要按状态切换不同动画，让 OnStateChanged 回调接收 (oldState, newState)，结合 GetHitPointRatio(module) 判断血量比例。每次受伤都需要反馈时，可以另外订阅 OnDamaged，其回调参数是本次扣除的血量。
    3. 按示例把 self.script 作为订阅所有者。行为销毁时订阅自动解除。

    回放验证 xLua 的状态和触发次数。实际 Animator 状态过渡在游戏中检查。
