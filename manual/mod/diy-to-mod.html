    将载具工坊设计导出为模组

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run diy-to-mod
    1. 打开载具工坊的设置，在 分享 → 导出模组包 一行点 导出。游戏会检查当前账号是否有分享权限。
    2. 导出提示会显示文件位置，游戏也会尝试打开模组目录下的 Export Package。找到 Universal_<名称>_<GUID>.modpack。它已经是 ZIP 格式的模组归档，保留 .modpack 扩展名。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.ResourceManager.ResourceConsts/GetModDir()/FullName"
    },
    "expect": {
      "contains": "(String)"
    }
  }
]
    点击展开 MCP 操作点击收起 MCP 操作

    在游戏中打开载具工坊的设置。以当前界面的语言填写导出按钮文字，从查询结果定位「导出模组包」一行，再填写该按钮中心的屏幕坐标。需要有分享权限。本地检查了导出路径，实机点击待验证。

    [
  {
    "tool": "ui_query",
    "arguments": {
      "type": "Button",
      "text": "${exportLabel}"
    }
  },
  {
    "tool": "mouse_click",
    "arguments": {
      "x": "${exportX}",
      "y": "${exportY}"
    }
  }
]
    1. 把模组包交给收件人，按安装模组导入。要让对方继续编辑设计，可在工坊使用 导出分享码，再由对方在编辑器内导入。
