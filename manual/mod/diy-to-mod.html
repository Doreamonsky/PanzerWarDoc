    19. DIY-> Mod 工坊内容转模组

    我希望所有人都能创造模组，制作模组不应仅限于拥有电脑和技术的人员。因此，工坊增加了发布 mod package 的功能。与分享码不同，分享的 mod package 是只读的，无法在工坊中编辑。

    I hope everyone can create Mods — making a Mod should not be something only people with a PC and technical skills can do. That is why the workshop added the ability to publish a mod package. Unlike a share code, a shared mod package is read-only and cannot be edited in the workshop.

    1. Create Content - 创建内容

    在工坊点击发布后，会生成对应的 zip 与 mod package 文件。

    文件位于以下路径：

    （电脑） SteamLibrary\steamapps\common\PanzerWar-DE\dlc\PanzerWar-DE\Mods\Export Package

    （手机）Android\data\com.ShanghaiWindy.PanzerWarDEM\files\Mods\Export Package

    When clicking share button in the workshop,the game will generate zip and mod package file.

    The file is located at

    （PC）SteamLibrary\steamapps\common\PanzerWar-DE\dlc\PanzerWar-DE\Mods\Export Package

    （Mobile）Android\data\com.ShanghaiWindy.PanzerWarDEM\files\Mods\Export Package

    2. Sharing - 分享

    Mod Package

    Mod package 文件可分享到各种社区、QQ 群或网盘。

    Mod package files can be shared through communities, QQ groups and cloud storage.

    Mod.io

    zip 文件可用于上传至 https://pw.mod.io/add

    Mod package 文件可作为正常模组进行安装

    zip file can be uploaded to https://pw.mod.io/add

    Mod package can be installed as normal Mod

    3. Mod.io Upload - Mod.io 上传

    upload zip file and click all platforms as approved

    上传 zip 文件，并将所有平台勾选为 approved

    国内访问 Mod.io 需要翻墙

    Accessing Mod.io from mainland China requires a VPN.
