    Unity 编辑器版本要求

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run unity-engine-requirements

    1. 确认工程版本

    打开工程的 ProjectSettings/ProjectVersion.txt，查找 m_EditorVersion。公开 SDK 发行版 sdk-2026.11.04.1 使用 Unity 2022.3.62f1。客户端 DE、Free 和 FreeCN 源码工程使用 Unity 2022.3.62f2。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "ProjectSettings/ProjectVersion.txt"
      ]
    },
    "expect": {
      "contains": "m_EditorVersion: 2022.3.62f2"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/unityVersion"
    },
    "expect": {
      "contains": "(String) 2022.3.62f2"
    }
  }
]

    2. 安装编辑器和目标平台模块

    1. 从 Unity 官网 安装 Unity Hub。安装公开 SDK 使用的 2022.3.62f1 时，可以在 Windows 按 Win+R，输入 unityhub://2022.3.62f1/4af31df58517，按回车交给 Hub。也可以打开该版本的安装页。
    2. 确认 Hub 显示的安装版本与工程声明一致。如果 Hub 无法下载，在发行页的 Manual installs 下载对应系统的编辑器安装包。安装后在 Hub 的 Installs 使用 Locate 添加已有编辑器。
    3. 在 Hub 的编辑器版本条目选择 Add modules。只装需要的目标平台支持。构建 Android 时勾选 Android Build Support。需要完整 Android 工具链或构建 Android Player 时，同时安装该版本配套的 Android SDK & NDK Tools 与 OpenJDK。构建 iOS 模组时安装 iOS Build Support。
    4. 在 Installs 查看编辑器版本与模块，再回到项目初始化打开 SDK 工程。

    MCP 回放核对已打开工程和编辑器的版本。Unity Hub 安装由读者完成。
