    Unity 编辑器版本要求

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run unity-engine-requirements

    1. 确认工程版本

    打开工程的 ProjectSettings/ProjectVersion.txt，查找 m_EditorVersion。公开 SDK 发行版 sdk-2026.11.04.1 使用 Unity 2022.3.62f1。客户端 DE、Free 和 FreeCN 源码工程使用 Unity 2022.3.62f2。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "ProjectSettings/ProjectVersion.txt"
      ]
    },
    "expect": {
      "contains": "m_EditorVersion: 2022.3.62f2"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/unityVersion"
    },
    "expect": {
      "contains": "(String) 2022.3.62f2"
    }
  }
]

    2. 安装编辑器和目标平台模块

    在对应的 Unity 发行页选择与操作系统匹配的安装包，或用 Unity Hub 安装该版本。构建 Android 模组时，安装 Android Build Support、Android SDK & NDK Tools 和 OpenJDK。构建 iOS 模组时，安装 iOS Build Support。

    MCP 回放核对已打开工程和编辑器的版本。Unity Hub 安装由读者完成。
