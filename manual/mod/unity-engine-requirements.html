    Unity 编辑器版本要求

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run unity-engine-requirements
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "sdkCheckout": "../../../Panzer-War-Mod-SDK"
  },
  "calls": []
}

    1. 确认工程版本

    1. 先确定要打开的工程，再读它的版本声明。公开 SDK 解压后，查看 UnityProject/ProjectSettings/ProjectVersion.txt 中的 m_EditorVersion。GitHub 发行版 sdk-2026.11.04.1 声明 Unity 2022.3.62f1；该发行版同时提供 release.json 与 SHA256SUMS.txt 供核对。
    2. 使用新发行版、GameHub 生成的工程或已迁移的工程时，一律以该工程 ProjectVersion.txt 的值为准，不要沿用旧教程里的版本号。
    3. 维护客户端 DE、Free 或 FreeCN 源码时，按客户端工程要求使用 Unity 2022.3.62f2。客户端工程的 f2 与 SDK 的 f1 是不同工程各自的声明，不要混用。
    点击展开 MCP 操作点击收起 MCP 操作

    先读取公开 SDK 的 ProjectVersion，再读取当前客户端工程的项目配置和正在运行的编辑器版本。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${sdkCheckout}/UnityProject/ProjectSettings/ProjectVersion.txt"
      ]
    },
    "expect": {
      "contains": "m_EditorVersion: 2022.3.62f1"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "ProjectSettings/ProjectVersion.txt"
      ]
    },
    "expect": {
      "contains": "m_EditorVersion: 2022.3.62f2"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.Application/unityVersion"
    },
    "expect": {
      "contains": "(String) 2022.3.62f2"
    }
  }
]

    2. 安装编辑器和目标平台模块

    1. 从 Unity 官网 安装 Unity Hub。安装公开 SDK 使用的 2022.3.62f1 时，可以在 Windows 按 Win+R，输入 unityhub://2022.3.62f1/4af31df58517，按回车交给 Hub。也可以打开该版本的安装页。
    2. 确认 Hub 显示的安装版本与工程声明一致。如果 Hub 无法下载，在发行页的 Manual installs 下载对应系统的编辑器安装包。安装后在 Hub 的 Installs 使用 Locate 添加已有编辑器，并确认 Hub 列表中该版本可用。
    3. 在 Hub 的编辑器版本条目选择 Add modules。按 SDK 说明，构建 Android 模组时安装 Android Build Support 及其配套的 Android SDK & NDK Tools、OpenJDK。构建 iOS 模组时安装 iOS Build Support。只安装自己目标平台需要的模块。
    4. 在 Installs 查看编辑器版本与模块，再回到项目初始化打开 SDK 工程。

    MCP 回放核对公开 SDK 文件中的版本，以及本地打开的客户端工程与编辑器版本。
