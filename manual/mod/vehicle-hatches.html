    载具舱门配置教程

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run vehicle-hatches --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "asset": "${fixture}/Tutorial_Hatch.prefab",
    "sourceMesh": "${fixture}/Tutorial_HatchSource.obj"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    本教程用独立的 Tutorial_Hatch.prefab 说明舱口标记、活动部件和双面网格配置。示例提供教学节点和网格，不包含完整载具；字段名保持源代码拼写。

    1. 添加并注册组件

    • 在舱盖物体上添加 VehicleHatchAttachmentMonoComponent，展开 hatchAttachmentSlot.attachment 编辑嵌套配置。
    • 同一物体上配置 VehicleAttachmentMonoComponent：将 attachmentSlotType 设为 Specific，specificAttachmentMonoComponent 引用舱盖组件，供运行时发现附件。项目 CustomEditor 会自动补这个伴随组件；配方显式创建并保存它。

    检查伴随组件引用的是当前舱盖组件。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "create",
        "component": "ShanghaiWindy.Core.VehicleHatchAttachmentMonoComponent",
        "values": {
          "hatchAttachmentSlot": {
            "attachment": {}
          }
        },
        "children": [
          "HatchCenter",
          "LeftHand",
          "RightHand",
          "HatchPivot",
          "HatchPivot/HatchMesh"
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.VehicleAttachmentMonoComponent",
        "values": {
          "attachmentSlotType": 1
        },
        "references": [
          {
            "property": "specificAttachmentMonoComponent",
            "component": "ShanghaiWindy.Core.VehicleHatchAttachmentMonoComponent"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    2. 舱口中心、手部标记与铰链

    • hatchRadius=0.5，hatchTransform 是舱口开口中心。
    • leftHandSlotTransform、rightHandSlotTransform 是手部放置标记，不是运动的铰链或枢轴。
    • 运动枢轴来自各 activeParts 条目的 activePartTransform：把独立的运动枢轴赋予 activePartTransform，初始 local rotation 保持单位旋转。

    预期检查：舱口中心位于开口处，手部标记未被当作铰链，枢轴初始旋转为单位值。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.VehicleHatchAttachmentMonoComponent",
        "values": {
          "hatchAttachmentSlot": {
            "attachment": {
              "hatchRadius": 0.5
            }
          }
        },
        "references": [
          {
            "property": "hatchAttachmentSlot.attachment.hatchTransform",
            "child": "HatchCenter"
          },
          {
            "property": "hatchAttachmentSlot.attachment.leftHandSlotTransform",
            "child": "LeftHand"
          },
          {
            "property": "hatchAttachmentSlot.attachment.rightHandSlotTransform",
            "child": "RightHand"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    3. 设置运动参数

    • isSemiOpen=false 时显示 activeParts。
    • 每个条目：axis=(1,0,0)、activeAngle=90、closeAngle=0、moveSpeed=120。
    • 运行时按 localRotation=Quaternion.AngleAxis(angle,axis) 设置，直接覆盖原 local rotation，不叠加增量。
    • isSemiOpen 是状态或显示条件；设置它并不保证运行时代码会禁用已有 activeParts 动画。

    预期检查：枢轴初始旋转为单位值，旋转结果不依赖原始朝向。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.VehicleHatchAttachmentMonoComponent",
        "values": {
          "hatchAttachmentSlot": {
            "attachment": {
              "isSemiOpen": false,
              "activeParts": [
                {
                  "axis": {
                    "x": 1,
                    "y": 0,
                    "z": 0
                  },
                  "activeAngle": 90,
                  "closeAngle": 0,
                  "moveSpeed": 120
                }
              ]
            }
          }
        },
        "references": [
          {
            "property": "hatchAttachmentSlot.attachment.activeParts.Array.data[0].activePartTransform",
            "child": "HatchPivot"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    4. 保存并检查

    • 校验组件、枢轴与运动参数，并确认运行时发现条件。
    • 保存 prefab，读回活动枢轴引用、moveSpeed 和伴随组件类型。实际开合、乘员手部位置和完整载具加载仍需在游戏中确认。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/GetComponent(ShanghaiWindy.Core.VehicleAttachmentMonoComponent)/attachmentSlotType"
    },
    "expect": {
      "contains": "Specific"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/GetComponent(ShanghaiWindy.Core.VehicleHatchAttachmentMonoComponent)/hatchAttachmentSlot/attachment/activeParts/0/activePartTransform/name"
    },
    "expect": {
      "contains": "HatchPivot"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/GetComponent(ShanghaiWindy.Core.VehicleHatchAttachmentMonoComponent)/hatchAttachmentSlot/attachment/activeParts/0/moveSpeed"
    },
    "expect": {
      "contains": "120"
    }
  }
]

    5. 按需烘焙双面网格

    打开舱盖后如果需要显示网格背面，将相应 MeshFilter 填入 doubleSidedMeshFilters。在载具附件配置编辑界面点击烘焙双面网格按钮，选择 Assets 内的输出目录；doubleSidedMeshes 是生成结果，不需要手工填写。只为必要的活动区域生成背面，避免整个载具的三角形数量翻倍。

    配方使用独立复制的方片网格演示输入和输出引用，通过同一个烘焙实现直接指定目录，跳过交互式文件夹对话框。重复烘焙会更新已有生成网格并保留 GUID；源模型临时开启的 Read/Write 会在结束后恢复。此步骤验证网格数据与引用，没有验证最终渲染效果。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/Light/AuthoringSamples/Square.obj",
        "${sourceMesh}"
      ]
    },
    "expect": {
      "contains": "True"
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "update",
        "component": "UnityEngine.MeshFilter",
        "child": "HatchPivot/HatchMesh",
        "references": [
          {
            "property": "m_Mesh",
            "asset": "${sourceMesh}",
            "type": "UnityEngine.Mesh"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.VehicleHatchAttachmentMonoComponent",
        "values": {
          "hatchAttachmentSlot": {
            "attachment": {
              "doubleSidedMeshFilters": [
                {}
              ]
            }
          }
        },
        "references": [
          {
            "property": "hatchAttachmentSlot.attachment.doubleSidedMeshFilters.Array.data[0]",
            "child": "HatchPivot/HatchMesh",
            "component": "UnityEngine.MeshFilter"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.VehicleHatchMeshBaker/BakePrefab",
      "args": [
        "${asset}",
        "",
        "${fixture}"
      ]
    },
    "expect": {
      "contains": "_DoubleSided_"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/GetComponent(ShanghaiWindy.Core.VehicleHatchAttachmentMonoComponent)/hatchAttachmentSlot/attachment/doubleSidedMeshes/Length"
    },
    "expect": {
      "contains": "1"
    }
  }
]
