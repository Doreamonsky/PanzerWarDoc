    安装 FMOD Studio

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run fmod-installation

    1. 下载与运行时匹配的版本

    登录 FMOD 官方下载页，下载适合系统的 FMOD Studio 安装包。当前 SDK 的 Windows FMOD 运行时使用 2.02.30，优先选同版本的 Studio。使用其他 2.02.x 补丁版时，按 FMOD Bank 兼容规则 核对。

    2. 确认版本

    运行安装程序后打开 Studio，从 Help → About 查看版本。下方 Unity MCP 配方读取客户端运行时的版本。已有 Studio 并启用其脚本连接时，也可执行 FMOD MCP 的 ping 查询 Studio 版本。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:FMOD.VERSION/number"
    },
    "expect": {
      "contains": "(Int32) 131632"
    }
  }
]
