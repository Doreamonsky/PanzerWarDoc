    为每个目标平台分别构建 .modpack。游戏需要与运行平台匹配的 AssetBundle。

    前提

    • 安装匹配的 Unity 版本和目标平台模块。
    • 项目已加入 GameHub。若未加入，在 GameHub 中点 Add Path 指向该 Unity 工程。
    • 本地 file: 依赖（相邻 UnityProject / Packages 布局）可用，SDK 依赖与本平台构建保持一致。

    创建软链接工程

    1. 在 GameHub 中选择要打包的目标平台。
    2. GameHub 为该平台创建软链接工程，点 Copy 复制该路径。
    3. 打开 Unity Hub，点 Add project from disk，填入第 2 步复制的路径。
    4. 点击版本号，把 Current Platform 改为与所创建的工程一致的平台，确认名称匹配后点 Open。
    5. 工程打开后，在 File → Build Settings 确认目标平台，等待导入完成。

    GameHub 的链接工程共享源资源，各平台保留独立的 Library。GameHub 和 Unity Hub 步骤由读者完成，MCP 可以检查已打开工程的目标平台。

    点击展开 MCP 操作点击收起 MCP 操作

    样例读取当前 Windows 构建目标。按工程需要在编辑器里手动选择目标平台。

    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEditor.EditorUserBuildSettings/activeBuildTarget"
    },
    "expect": {
      "contains": "(BuildTarget) StandaloneWindows64"
    }
  }
]

    每个平台分别构建与校验

    1. 对该平台执行 BuildPipeline 的 Build Linked Objects to AssetBundle。
    2. 再对关联 ModPackage 执行 Package Mod Now。
    3. 保留生成的 .modpack 和同名 .modpack.json。核对包内平台、Unity 版本、资源清单与元数据，在对应平台的游戏中测试。

    资源改动或平台切换后，重新执行前两个打包步骤。下方回放验证 Windows 教学包，Android 和 iOS 包需在对应环境另行验证。
