    项目下载参考

    中文 | English

    1. 获取发行包

    1. 打开 装甲纷争模组 SDK 发行页，展开 Assets，下载 Panzer-War-Mod-SDK-sdk-*.zip（公开版 sdk-2026.11.04.1 约 600 MB）。
    2. 同一发行版的 Assets 中还有 SHA256SUMS.txt 和 release.json，一并下载。release.json 记录该版本的 Unity 发行信息，字段名为 sdk.unity；具体编辑器版本号 m_EditorVersion 不在 release.json 中，而在解压后的 UnityProject/ProjectSettings/ProjectVersion.txt。
    3. 不要使用自动生成的 Source code (zip) / Source code (tar.gz)；它们可能只含 Git LFS 指针。下载后按 项目初始化 解压并打开工程。若 GameHub 提供 Create Project（创建工程），也可通过 GameHub 创建工程。

    2. Windows 校验下载文件

    在 PowerShell 中进入下载目录，把文件名换成你实际下载的名字：

    Get-FileHash -Algorithm SHA256 .\Panzer-War-Mod-SDK-sdk-2026.11.04.1.zip

    将输出的 Hash 与 SHA256SUMS.txt 中同一文件名对应行的哈希逐字符比较，并且忽略大小写：PowerShell 输出为大写，清单可能为小写或混合大小写，十六进制摘要应大小写不敏感地比较。两者一致才继续解压。文件名不一致说明比较了错误条目；哈希不一致说明下载损坏或不完整，也可能下载了错误的文件或版本，应核对文件名和版本后重新下载。

    macOS 可用：

    shasum -a 256 Panzer-War-Mod-SDK-sdk-2026.11.04.1.zip

    Linux 可用：

    sha256sum Panzer-War-Mod-SDK-sdk-2026.11.04.1.zip

    3. 发行 ZIP 与 Git + LFS 两种流程

    使用发行 ZIP（推荐）：解压完整压缩包，保持 UnityProject 与 Packages 同级，然后直接用 Unity 打开 UnityProject。发行包内含真实的 DLL 和本地依赖，不需要安装 Git 或 LFS，也不需要执行 git lfs pull。

    使用 Git 克隆：适合需要跟踪仓库更新或查看历史的读者。必须先安装 Git LFS 并完成拉取，再打开工程：

    git lfs install
git clone https://github.com/WindyVerse/Panzer-War-Mod-SDK.git
cd Panzer-War-Mod-SDK
git lfs pull

    LFS 拉取未完成、或下载了源码压缩包时，二进制文件会变成指针文件。若某个 DLL 打开后只有几行文本，且第一行是 version https://git-lfs.github.com/spec/v1，说明它是 LFS 指针而不是真实二进制：Git 流程请重新执行 git lfs pull，ZIP 流程请改用发行 ZIP 而不是 Source code。指针文件会导致 Unity 报插件加载或 DLL 相关错误。

    SDK 是公开的模组开发包。官方载具、地图等素材在独立的私有仓库 Panzer-War-Mods，游戏本体由 Panzer-War-Client 构建。除修改官方素材或客户端代码外，使用 SDK 即可。
