    旧工程迁移到新模组工程

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run migrate-old-project
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    把完整 SDK 解压到新目录，再迁入自己的资源及其 .meta 文件。

    1. 备份旧工程并打开新工程

    复制旧工程的完整目录或保留版本库快照。按 项目初始化 下载 SDK，完整解压到新目录，保留同级的 UnityProject 和 Packages。按新工程的 ProjectSettings/ProjectVersion.txt 选择 Unity 版本，等待首次导入和编译完成。

    2. 复制自己的资源

    把自己创建的 Assets 子目录复制进新工程，保留相对路径，并带上文件和目录对应的 .meta。Unity 用其中的 GUID 识别资源引用。

    点击展开 MCP 操作点击收起 MCP 操作

    3. 检查引用并重新构建

    打开迁入的 prefab 和配置，检查缺失脚本、材质、着色器和依赖。按 多平台打包 逐个目标构建、测试，期间保留旧工程。

    点击展开 MCP 操作点击收起 MCP 操作

    检查当前连接的编辑器。真实新工程中的引用、编译和平台包需另行验证。
