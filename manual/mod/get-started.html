    项目初始化

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run get-started
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "sdkCheckout": "../../../Panzer-War-Mod-SDK"
  },
  "calls": []
}

    1. 下载并解压 SDK

    打开 装甲纷争模组 SDK 发行页，展开 Assets，下载名称为 Panzer-War-Mod-SDK-sdk-*.zip 的发行包。它包含 DLL 和本地依赖，不需要 Git。自动生成的 Source code (zip) 可能只包含 Git LFS 指针。点击全部解压，保持 UnityProject 和 Packages 同级。使用 Git 的读者可改走克隆与 LFS 流程。

    2. 确认工程根目录和版本

    打开 UnityProject，确认包含 Assets/、Packages/manifest.json 和 ProjectSettings/ProjectVersion.txt。已核验的公开发行版 sdk-2026.11.04.1 声明 Unity 2022.3.62f1。若下载的是更新版，读取该包的 m_EditorVersion，按版本要求安装。

    点击展开 MCP 操作点击收起 MCP 操作

    3. 在 Unity Hub 打开工程

    1. 在 Unity Hub 的 Projects → Add → Add project from disk 中选择 UnityProject。选到正确目录时，应能看到本教程第 2 节列出的三个位置。
    2. 在项目列表打开刚添加的工程。如果 Hub 提示缺少版本，先安装 ProjectVersion.txt 声明的编辑器，再重新打开。第一次打开需要导入包和编译。
    3. 等进度结束后查看 Console。编译通过时，顶部会出现 Framework - 框架 菜单。找不到菜单时，先确认选择的是内层 UnityProject，再检查相邻的 Packages 是否完整解压。

    4. 先用随包模板验收项目

    1. 在 File → Build Settings 选择目标平台。Windows 选 PC, Mac & Linux Standalone → Windows → x86_64，Android 选 Android，再点击 Switch Platform。
    2. 在 Project 选中 Assets/ModManager/BuildPipline-Template-Vehicle.asset，点击 Build Linked Objects to AssetBundle，等待资源构建结束。
    3. 选 Assets/ModManager/Template-Blank-Vehicle.asset，点击 Package Mod Now。Windows 示例输出在 UnityProject/Build/Mod-Package/StandaloneWindows64/Template-Blank-Vehicle/ 下。切平台或改资源后，先重新构建链接资源再打包。
    4. 按安装模组导入与游戏平台一致的 .modpack。地图模板在同一目录下，改选 BuildPipline-Template-Blank.asset 与 Template-Blank-Scene.asset。

    接着按需设置 Steam 游戏目录，或开始从零制作第一辆坦克。如果使用能创建项目的 GameHub 版本，可参照环境配置打开它生成的工程。
