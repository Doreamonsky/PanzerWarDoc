    项目初始化

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run get-started

    1. 下载并解压 SDK

    打开 装甲纷争模组 SDK 发行页，展开 Assets，下载名称为 Panzer-War-Mod-SDK-sdk-*.zip 的发行包。它包含可用的 DLL 和本地依赖。用压缩工具选择全部解压，保留 UnityProject 和同级 Packages。单独复制工程目录会使引用失效。已有工程可从下一步开始，也可以参照 GameHub 环境配置 创建工程。

    2. 确认工程根目录和版本

    打开 UnityProject，确认包含 Assets/、Packages/manifest.json 和 ProjectSettings/ProjectVersion.txt。按 Unity 引擎版本要求 安装工程声明的版本。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/Exists",
      "args": [
        "Assets"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "Packages/manifest.json"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "ProjectSettings/ProjectVersion.txt"
      ]
    },
    "expect": {
      "contains": "m_EditorVersion: 2022.3.62f2"
    }
  }
]

    3. 在 Unity Hub 打开工程

    1. 在 Unity Hub 的 Projects → Add → Add project from disk 中选择 UnityProject。选到正确目录时，应能看到本教程第 2 节列出的三个位置。
    2. 在项目列表打开刚添加的工程。如果 Hub 提示缺少版本，先安装 ProjectVersion.txt 声明的编辑器，再重新打开。第一次打开需要导入包和编译。
    3. 等进度结束后查看 Console。编译通过时，顶部会出现 Framework - 框架 菜单。找不到菜单时，先确认选择的是内层 UnityProject，再检查相邻的 Packages 是否完整解压。

    接着按需设置 Steam 游戏目录，或开始从零制作第一辆坦克。
