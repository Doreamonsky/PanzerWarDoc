    05. Create Mech 创建机甲

    在阅读此文本之前，请务必有普通坦克模组的开发经验。

    Before reading this document, make sure you already have experience developing a normal tank mod.

    前期准备 Preparation

    1. 模型 Model

    骨骼模型：一个绑定骨骼的机甲模型。

    Skeletal model: a mech model with a rigged skeleton.

    伤害模型：一个将各个关节分离的简易的伤害模型。

    Damage model: a simple damage model with each joint separated.

    2. 动画 Animation

    你至少需要拥有以下动画：

    1. 待机动画
    2. 走路动画：笔直向前走路动画，向左的走路动画，向右的走路动画，原地左转的动画，和原地向右的动画。

    You need at least the following animations:

    1. Idle animation
    2. Walking animations: walking straight forward, walking to the left, walking to the right, turning left in place, and turning right in place.

    注：倒退走路动画可以在动画树中，以-1倍的速度播放，实现倒退。

    Note: the backward walking animation can be produced by playing the animation at -1x speed in the animator controller.

    你可以额外制作以下动画:

    1. 飞行动画：飞行起步动画，飞行中待机动画，和飞行结束落地动画。

    You can additionally create the following animations:

    1. Flight animations: the take-off animation, the in-flight idle animation, and the landing animation at the end of the flight.

    3. 导入引擎动画的设置 Animation Import Settings

    动画导入引擎后有相关设置，才可以使机甲符合物理模拟效果。

    After the animations are imported into the engine, a few settings are required so the mech matches the physics simulation.

    1. 需要将 Root Transform Position (Y) 中的 Bake Into Pose 勾上。

      Tick Bake Into Pose under Root Transform Position (Y).

    2. 在 Curve 增加 GravityWeight 属性，并将曲线设置为值为1的水平线。

      Add a GravityWeight property under Curves, and set the curve to a horizontal line with a value of 1.

    3. 含脚步落地的动画帧，在 Events 中添加 WalkSound 事件。

      On the animation frames where a foot touches the ground, add a WalkSound event under Events.

    机甲预制体制作 Building the Mech Prefab

    1. 动画控制器。在含有Animator组件的物体上增加 MechAnimatorController 组件 和 CharacterController 组件。

      Animator controller. On the object that holds the Animator component, add the MechAnimatorController component and the CharacterController component.

    1. 物理碰撞。调整 CharacterController 的属性，使胶囊体底部与脚底一致。

      Physics collision. Adjust the CharacterController properties so that the bottom of the capsule lines up with the soles of the feet.

    1. 机甲脚底碰撞。在机甲两个脚底均增加 MechLegEndPoint 组件，与BoxCollider 组件。并勾选 BoxCollider 的 isTrigger 属性。若机甲可以飞行，则增加 MechFireBurst 组件,并调整相应参数。

      Mech foot collision. Add a MechLegEndPoint component and a BoxCollider component to both of the mech's feet, and tick the isTrigger property on the BoxCollider. If the mech can fly, also add the MechFireBurst component and adjust its parameters.

    1. 炮塔同步。增加 Turret/Gun/Dym 的空物体。在机甲模型上，上半身旋转控制的位置增加 MechTurretSync 组件，来同步相应位置。

      Turret sync. Create empty objects for Turret/Gun/Dym. On the mech model, add the MechTurretSync component at the position that drives the upper-body rotation, so the corresponding positions stay in sync.

    Create a new Animator Controller in the Project window and drag it onto the Animator component of the mech prefab.

      Add the parameters shown below. The types must match the picture exactly.

    1. 增加动画状态。 若含飞行的三个状态动画，则一定要与图中的三个Jet开头的动画命名一致。

      Add the animation states. If you include the three flight state animations, their names must match the three Jet-prefixed animation names in the picture.

    向前走路（Walk）由多个动画的混合组成（Blend Tree）。 混合使用的参数为 Turn。0.5为笔直向前的动画。 0为向左的走路动画，1为向右的走路动画。可以在中间插入更多动画作补帧，使动画更加自然。

    Walking forward (Walk) is a blend of several animations (a Blend Tree). The blend parameter is Turn: 0.5 is the straight-forward animation, 0 is the walk-left animation, and 1 is the walk-right animation. You can insert more animations in between to fill in the motion and make it look more natural.

    注：倒退动画可以在动画树中，以-1倍的速度播放，实现倒退。

    创建 VehicleData Creating VehicleData

    像普通坦克一样，创建坦克配置参数。然后删除生成的 VehicleTrack 文件。

    Create the vehicle configuration parameters just like you would for a normal tank, then delete the generated VehicleTrack file.

    其他配置信息和坦克一样进行配置即可。

    All the other configuration can be done exactly the same way as for a tank.

    在 VehicleTextData 需要额外关心，设置机甲专用参数。

    VehicleTextData needs extra attention: set the mech-specific parameters there.
