    模型不显示

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run model-not-displaying --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "asset": "${fixture}/Tutorial_RenderCheck.prefab",
    "material": "${fixture}/Tutorial_RenderCheck.mat"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}

    1. 检查材质 Shader

    在 Project 窗口选中模型使用的材质。在 Inspector 的 Shader 字段检查它是否支持当前渲染管线。示例读回项目载具材质的 Shader 和本机支持情况。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/Altius-U/Art/Default-FastProp.mat",
        "${material}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${material}/shader/name"
    },
    "expect": {
      "contains": "WindyVerse/Vehicle/FullPBR"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${material}/shader/isSupported"
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    2. 检查 Renderer 和材质槽

    选中实际负责绘制的子物体，确认 Mesh Renderer 或 Skinned Mesh Renderer 标题上的启用复选框已选中。展开 Materials，检查各槽引用的材质。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "create",
        "component": "UnityEngine.MeshRenderer",
        "child": "Hull",
        "children": [
          "Hull"
        ],
        "values": {
          "m_Enabled": true
        },
        "references": [
          {
            "property": "m_Materials.Array.data[0]",
            "asset": "${material}",
            "type": "UnityEngine.Material"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/Hull/GetComponent(MeshRenderer)/enabled"
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/Hull/GetComponent(MeshRenderer)/sharedMaterial/shader/name"
    },
    "expect": {
      "contains": "WindyVerse/Vehicle/FullPBR"
    }
  }
]

    3. 检查相机的 Culling Mask

    记下模型物体顶部的 Layer。选中实际渲染当前视图的 Camera，在 Culling Mask 里确保勾选了该层。示例先排除 Default 层，再把它加回。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "update",
        "component": "UnityEngine.Camera",
        "values": {
          "m_CullingMask": {
            "serializedVersion": 2,
            "m_Bits": 0
          }
        }
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/GetComponent(Camera)/cullingMask"
    },
    "expect": {
      "contains": "(Int32) 0"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/Hull/layer"
    },
    "expect": {
      "contains": "(Int32) 0"
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${asset}",
        "mode": "update",
        "component": "UnityEngine.Camera",
        "values": {
          "m_CullingMask": {
            "serializedVersion": 2,
            "m_Bits": 1
          }
        }
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/GetComponent(Camera)/cullingMask"
    },
    "expect": {
      "contains": "(Int32) 1"
    }
  }
]
