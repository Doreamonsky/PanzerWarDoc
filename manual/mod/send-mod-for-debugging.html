    导出模组问题的复现包

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run send-mod-for-debugging
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "payload": "${fixture}/TutorialDebugVehicle.asset",
    "pipeline": "${fixture}/TutorialDebugPipeline.asset",
    "unitypackage": "Temp/Docs_${runId}_Export.unitypackage"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}
    1. 记录游戏和 SDK 版本、打包平台、复现步骤、预期结果与实际结果。保留相关的运行日志。
    2. 在 Unity Project 窗口选中相关的 VehicleData 和模组构建管线。点击 Assets → Export Package，勾选 Include dependencies。检查资源清单，导出复现所需的文件。
