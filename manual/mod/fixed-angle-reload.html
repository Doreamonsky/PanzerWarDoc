    定角装填配置

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run fixed-angle-reload --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {

    {

      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CopyAsset",

    定角装填使用火控增益 TankFireSpecificAngleReloadBuff。开火或切换弹种后，它可按设定延迟约束炮塔角度、调整转速，并在装填完成后解除约束。

    1. 准备共享火炮参数

    在 Project 窗口选择 Create > A Panzer War - 装甲纷争 > G Ground Vehicle - 地面载具 > Shared Data - 共享数据 > Gun - 炮管，创建 SharedGunData。展开 tankFireParameter，找到增益引用列表 buffRefs。

    本配方复制一个现有火炮配置作为教学样例，保留必要的初始化数据。共享火炮的修改会影响所有引用它的载具；只调整一辆载具时，先创建独立的共享数据副本，或清除该载具的 sharedGunData 后编辑自己的 TFParameter。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "static:UnityEditor.Selection/activeObject",
      "value": "@asset:${sharedGun}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${sharedGun}/tankFireParameter"
    },
    "expect": {
      "contains": "TankFireParameter"
    }
  }
]

    2. 添加定角装填增益

    在 buffRefs 新增一条，选择 TankFireSpecificAngleReloadBuff。展开其配置，按下表设置教学值：

    字段 教学值与含义
    hasDelay / delay 勾选启用延迟，填写 0.5 秒
    isTraverseLocked 勾选锁定水平旋转
    hasSpecificTraverseAngle / specificTraverseAngle 启用特定水平角度，填写 0 度
    hasSpecificElevationAngle / specificElevationAngle 启用特定垂直角度，填写 5 度
    isOverrideTraverseSpeed / overrideTraverseSpeedCoff 覆盖水平旋转速度，系数填 -0.5，表示降低 50%
    isOverrideElevationSpeed 本例关闭，保持原垂直旋转速度

    延迟、角度和速度系数字段分别受对应开关控制。未指定角度时，代码使用进入定角状态时的当前角度。上面的数值只用于演示。

    当前列表是 AbstractTankFireBuffCasterSafeRef[]，旧的 buffs 字段已弃用。MCP 配方会同时写入真实类型和配置 JSON，创建安全引用元素。

    点击展开 MCP 操作点击收起 MCP 操作

    数组 JSON 赋值创建真实 SafeRef，类型名与序列化配置一起写入。本配方验证保存内容；不修改弃用的 buffs。

    [
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${sharedGun}/tankFireParameter/buffRefs",
      "value": "[{\"fullName\":\"ShanghaiWindy.Core.TankFireSpecificAngleReloadBuff\",\"className\":\"ShanghaiWindy.Core.TankFireSpecificAngleReloadBuff, Core\",\"json\":\"{\\\"hasDelay\\\":true,\\\"delay\\\":0.5,\\\"isTraverseLocked\\\":true,\\\"hasSpecificTraverseAngle\\\":true,\\\"specificTraverseAngle\\\":0,\\\"hasSpecificElevationAngle\\\":true,\\\"specificElevationAngle\\\":5,\\\"isOverrideTraverseSpeed\\\":true,\\\"overrideTraverseSpeedCoff\\\":-0.5,\\\"isOverrideElevationSpeed\\\":false}\",\"safeRefAssetProvider\":{\"assets\":[]}}]"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${sharedGun}/tankFireParameter/buffRefs/0/fullName"
    },
    "expect": {
      "contains": "TankFireSpecificAngleReloadBuff"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${sharedGun}/tankFireParameter/buffRefs/0/json"
    },
    "expect": {
      "contains": "\"specificElevationAngle\":5"
    }
  }
]

    3. 绑定载具

    把共享火炮资产赋给目标 VehicleTextData.sharedGunData。非空时，GetTankFireParam() 读取共享资产的 tankFireParameter；为空时才读取该载具的 TFParameter。

    保存后读回增益配置，确认载具使用了预期资产。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/sharedGunData",
      "value": "@asset:${sharedGun}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vehicle}/GetTankFireParam()/buffRefs/0/json"
    },
    "expect": {
      "contains": "\"overrideTraverseSpeedCoff\":-0.5"
    }
  }
]

    4. 检查

    核对类型、延迟、角度、速度系数和共享引用。运行时代码在装填完成后通过周期检查解除约束；本教程没有进入游戏验证定角过程或恢复效果。

    点击展开 MCP 操作点击收起 MCP 操作

    这里验证编辑器配置、共享引用及保存结果。定角、转速和装填完成后的恢复行为仍需游戏内检查。

    [

    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/SaveAssets",
      "args": []
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${sharedGun}/tankFireParameter/buffRefs/0/json"
    },
    "expect": {
      "contains": "\"delay\":0.5"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vehicle}/sharedGunData/name"
    },
    "expect": {
      "contains": "Tutorial_FixedAngleReload_SharedGunData"
    }
  }
