    Blender 轴向修正

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run blender-axis-fix
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "asset": "${fixture}/Tutorial_AxisCheck.fbx"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}

    这组操作适用于需要重设物体局部旋转基准的模型。先复制模型，用副本做以下调整。

    1. 调整旋转并导出

    1. 在 Unity 的 Scene 视图选择要排查的对象，把工具方向切为 Local，枢轴模式切为 Pivot。记录车体的已知长度，观察 Z 轴是否沿车头、Y 轴是否朝上。
    2. 在 Blender 中用模型副本，进入物体模式，选中需要修正局部旋转基准的对象。按 R、X、-90，按 Enter。
    3. 按 Ctrl+A，选择旋转（Rotation）。应用后检查对象的旋转值已经归零。
    4. 再按 R、X、90，按 Enter。选择 File → Export → FBX。设置 Scale 1.00、Apply Scalings → FBX Units Scale、Forward → −Z Forward、Up → Y Up。把导出的 FBX 导入 Unity 的测试目录。

    Blender 后台脚本可重做本页示例。下方 Unity MCP 配方导入由它生成的教学 FBX。

    blender --background --factory-startup --python-exit-code 1 --python Tools/ManualMcp/BlenderAxisFix/build_model.py -- Tutorial_AxisCheck.fbx
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/Editor/DocumentationSamples/blender-axis-fix/Tutorial_AxisCheck.fbx",
        "${asset}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/ImportAsset",
      "args": [
        "${asset}",
        "ForceSynchronousImport"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. 检查模型前方和上方

    在 Unity 里检查模型的前方沿 +Z，上方沿 +Y，并对照之前记录的车体长度。在副本中分别旋转炮塔和主炮，确认各自围绕正确的枢轴转动。示例的 NoseMarker 在 (0, 0, 1)，RoofMarker 在 (0, 1, 0)。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/NoseMarker/transform/position"
    },
    "expect": {
      "contains": "(0.00, 0.00, 1.00)"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${asset}/RoofMarker/transform/position"
    },
    "expect": {
      "contains": "(0.00, 1.00, 0.00)"
    }
  }
]

    有其他轴向问题时，分别核对源模型的局部轴、FBX 导出选项和 Unity 导入设置。载具结构见 基础载具。
