    安装 VS Code 和 EmmyLua

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run install-vs-code-emmylua
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {},
  "calls": [
    {
      "tool": "inspect",
      "arguments": {
        "path": "static:System.Environment/GetFolderPath(LocalApplicationData)"
      },
      "expect": {
        "contains": "(String)"
      },
      "capture": {
        "localApp": {
          "regex": "\\(String\\) ([^\\r\\n]+)"
        }
      }
    },
    {
      "tool": "inspect",
      "arguments": {
        "path": "static:System.Environment/GetFolderPath(UserProfile)"
      },
      "expect": {
        "contains": "(String)"
      },
      "capture": {
        "profile": {
          "regex": "\\(String\\) ([^\\r\\n]+)"
        }
      }
    }
  ]
}

    1. 安装编辑器和扩展

    从 VS Code 官网 下载安装。在 扩展视图搜索 @id:tangzx.emmylua，安装 EmmyLua。新开终端后用 code --list-extensions 确认结果包含 tangzx.emmylua。新版 EmmyLua 使用自带的语言服务，按扩展的当前说明选择依赖。

    点击展开 MCP 操作点击收起 MCP 操作

    检查本机 Windows 用户安装位置。安装程序和扩展商店操作由读者完成。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${localApp}/Programs/Microsoft VS Code/Code.exe"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/GetDirectories",
      "args": [
        "${profile}/.vscode/extensions",
        "tangzx.emmylua-*"
      ]
    },
    "expect": {
      "contains": "tangzx.emmylua"
    }
  }
]

    2. 加入项目的 API 定义

    用 VS Code 打开 Lua 源码所在文件夹。在 Unity 可执行 XLua → Generate EmmyLua for LuaCallCSharp，从工程的 Build/EmmyLua/ 取生成的 API 定义。把这些定义与 Lua 源码一起纳入 VS Code 工作区。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:GeneralEditor.Utility_XluaDefineEditor"
    },
    "expect": {
      "contains": "GenerateEmmyLuaForLuaCallCSharp"
    }
  }
]
    点击展开 MCP 操作点击收起 MCP 操作

    在自己的工程中生成或更新 Build/EmmyLua；日常回放只查入口。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:GeneralEditor.Utility_XluaDefineEditor/GenerateEmmyLuaForLuaCallCSharp",
      "args": []
    }
  }
]

    接下来可做 Lua 断点调试。
