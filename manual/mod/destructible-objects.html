    用模型替换制作可破坏物体

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run destructible-objects --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "building": "${fixture}/TutorialDestructible.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}
    1. 在预制体根节点添加 Building 与 Rigidbody。让根的第一个子物体包含 MainModel、DestroyedModel 和 CollisionTrigger。把完整和破损的显示网格分别放到前两个节点下。
    2. 在 CollisionTrigger 内添加一个触发子物体，挂 Collider 与 TriggerProxy，勾选 Collider 的 Is Trigger。显示网格的碰撞应独立配置，避免重复碰撞器。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${building}",
        "mode": "create",
        "component": "UnityEngine.Rigidbody",
        "values": {
          "m_IsKinematic": true
        },
        "children": [
          "root/MainModel",
          "root/DestroyedModel",
          "root/CollisionTrigger/TriggerBox"
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${building}",
        "mode": "update",
        "component": "UnityEngine.BoxCollider",
        "child": "root/CollisionTrigger/TriggerBox",
        "values": {
          "m_IsTrigger": true
        }
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${building}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.TriggerProxy",
        "child": "root/CollisionTrigger/TriggerBox"
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${building}/root/CollisionTrigger/TriggerBox/GetComponent(BoxCollider)/isTrigger"
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]
    1. 在 Building 中把 Destroy Type 设为 By Model Replace，配置 Health，在 Trigger Proxies 中引用上一步的组件。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${building}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.Building",
        "values": {
          "DestroyType": 1,
          "Health": 200,
          "isMasterServerObject": true,
          "triggerProxies": [
            null
          ]
        },
        "references": [
          {
            "property": "triggerProxies.Array.data[0]",
            "child": "root/CollisionTrigger/TriggerBox",
            "component": "ShanghaiWindy.Core.TriggerProxy"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${building}/Building/DestroyType"
    },
    "expect": {
      "contains": "(BuildingDestroyType) ByModelReplace"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${building}/Building/triggerProxies/0/name"
    },
    "expect": {
      "contains": "(String) TriggerBox"
    }
  }
]
    1. 把预制体放进地图，进游戏测试受击或碰撞后从完整模型切换到破损模型，并确认触发器随之关闭。其他破坏模式见可破坏物体制作。
    点击展开 MCP 操作点击收起 MCP 操作
