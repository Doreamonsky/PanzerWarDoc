    将载具拆解为 DIY 配件

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run convert-to-diy-equipment --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "source": "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar",
    "vehicleData": "${fixture}/Tutorial_NativeVehicleData.asset",
    "vehicleText": "${fixture}/Tutorial_NativeText.asset",
    "vehicleInfo": "${fixture}/Tutorial_NativeVehicleInfo.asset",
    "packModel": "${fixture}/Tutorial_NativePackModel.prefab",
    "vehicleName": "Docs-DIY-Convert-${runId}",
    "vehicleGuid": "fd9092ed4d67429f44c5${runId}"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}
    1. 准备有对应 VehicleInfo 的 VehicleData。主模型使用约定的车体与 Turret/Gun/Dym 层级。检查伤害模型和节点位置，保存手头的场景。
    2. 在 VehicleData 的 Inspector 打开载具工具。在导出设置中选目标模型质量，给 Folder 赋一个独立的工程目录，勾选本次要导出的车体、炮塔和炮管。

    1. 点击拆解为 DIY 配件并确认，工具只导出勾选的部件。新版副炮塔与额外开火节点会从模型副本移除。分别检查输出的部件数据、模型原点、伤害模型、插槽与虚节点位置。

    点击展开 MCP 操作点击收起 MCP 操作

    在自己的编辑器中执行，先保存场景并给 VehicleData 的 exportFolder 指定输出。将变量替换成目标 VehicleData 的工程路径。

    [
  {
    "tool": "gm_run",
    "arguments": {
      "id": "ExportVehicleDIY",
      "action": "Export",
      "params": "{\"vehicleListType\":\"List\",\"vehicleList\":[\"${yourVehicleData}\"]}",
      "confirm": true
    }
  }
]
    1. 将要使用的部件加入 DIY 配件构建组，构建和安装后在坦克工坊检查装配。
