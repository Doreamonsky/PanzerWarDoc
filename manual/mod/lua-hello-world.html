    第一行 Lua：Hello World

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run lua-hello-world --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "script": "${fixture}/HelloWorld.lua",
    "prefab": "${fixture}/Tutorial_HelloWorld.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    在这个例子里，Lua 行为启动时会调用 OnStarted，输出 Hello World。

    1. 创建脚本

    在 Unity 项目的资源目录中保存 HelloWorld.lua。导入器会将它识别为 Lua 行为资产。

    Behavior()
Property = {}

local HelloWorld = class("HelloWorld")

function HelloWorld:OnStarted()
    print("Hello World")
end

return HelloWorld
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/WriteAllText",
      "args": [
        "${script}",
        "Behavior()\nProperty = {}\n\nlocal HelloWorld = class(\"HelloWorld\")\n\nfunction HelloWorld:OnStarted()\n    print(\"Hello World\")\nend\n\nreturn HelloWorld\n"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/ImportAsset",
      "args": [
        "${script}",
        "ForceSynchronousImport"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. 绑定组件

    在目标物体上添加 LuaBehaviorMono，将 HelloWorld 资产赋给「行为脚本」，然后保存 prefab。这个脚本没有声明实例参数。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${prefab}",
        "mode": "create",
        "component": "ShanghaiWindy.Core.Lua.LuaBehaviorMono",
        "references": [
          {
            "property": "luaBehavior",
            "asset": "${script}",
            "type": "ShanghaiWindy.Core.Lua.LuaBehaviorScript"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    3. 检查结果

    重新打开 prefab，确认已保存脚本引用与 OnStarted 内容。把该物体加载到游戏后，可以检查启动日志中的 Hello World。教学重放已验证导入和引用，游戏内日志尚未核验。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${prefab}/LuaBehaviorMono/luaBehavior/name"
    },
    "expect": {
      "contains": "(String) HelloWorld"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${prefab}/LuaBehaviorMono/luaBehavior/lua"
    },
    "expect": {
      "contains": "print(\"Hello World\")"
    }
  }
]
    点击展开 MCP 操作点击收起 MCP 操作
