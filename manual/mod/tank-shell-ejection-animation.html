    本教程改编自樱花的《坦克抛壳动画》。示例先在 Blender 准备炮塔下的弹壳和抛壳装置，再在 Unity 制作动画，最后用 Lua 将剪辑接到开火事件。

    1. 准备并导入模型

    在 Blender 中将弹壳放到炮塔内，设为炮塔的子级。本例将弹壳节点命名为 Casing。把抛壳装置的枢轴设在旋转中心。如果旋转轴和全局坐标轴不重合，可以放置并旋转一个空物体作为父级。本例用 MechanismPivot 表示这个空物体。

    导出 FBX 后导入 Unity，确认模型下保留 Turret/Casing 和 Turret/MechanismPivot，再创建用于配置的 prefab。配方用 Blender 后台模式生成并导出教学样例。如果 Unity 找不到 Blender，启动编辑器前设置 BLENDER 指向可执行文件。

    2. 制作并分配动画

    在 Unity 的 Animation 窗口中选择 prefab 根节点，创建 Tutorial_ShellEject.anim 剪辑。为 Casing 的局部 Position 添加起点、抛出和复位三个关键帧。本例在 0.2 秒沿局部 X 轴移动 0.35 个单位，在 0.4 秒回到起点。装置通过 MechanismPivot 的局部 Rotation 曲线在 0.2 秒转到 35° 的打开姿态，随后复位。

    将剪辑设为 Legacy，Wrap Mode 保持 Default。在根节点添加 Animation，指定默认剪辑并关闭 Play Automatically，让 Lua 控制播放。

    3. 绑定开火事件

    在同一个根节点添加 LuaBehaviorMono，将以下脚本保存为 PlayAnimationComponent.lua 并赋给「行为脚本」。脚本在载具加载后监听第一个火力系统的开火事件。多炮载具应按实际火力列表选择索引。

    Behavior()
Property = {}

local PlayAnimationComponent = class("PlayAnimationComponent")

function PlayAnimationComponent:OnStarted()
    local animation = self.script:GetNativeComponent("Animation")
    local found, vehicle = self.script:TryGetTankInitSystem()
    if not animation or not found then
        return
    end

    VehicleAPI.RegisterVehicleLoadedEvent(vehicle, function()
        VehicleAPI.RegisterBulletFiredEvent(vehicle, 0, function()
            animation:Play()
        end)
    end)
end

return PlayAnimationComponent

        "ok": true
      }
    }
  }
]

    4. 保存并核对

    保存 prefab，检查 Animation 和 LuaBehaviorMono 在同一个节点上，再核对默认剪辑、Legacy 设置和 Lua 引用。配方回读了位置曲线和旋转曲线。还需在完整载具上试射，确认开火回调和动画在游戏中按预期运行。
