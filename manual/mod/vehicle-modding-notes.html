    祝昔的载具 Mod 开发总结

    中文 | English

    原作者 @情绪薫。本页保留原有案例，并标出当前工具中的对应入口。第一次搭载具先完成坦克制作。

    找到模型

    原作者从 Sketchfab、GameModels3D、CGTrader 和其他素材渠道挑选模型。少数模型带内部结构，下载之前核对具体素材的修改和再分发许可。已有许可的素材也要检查贴图、部件层级及比例。 Sketchfab · GameModels3D · CGTrader

    制作时遇到的问题

    1. 模型的原点在哪里

    在 Blender 物体模式打开 3D 视图的 Options。选中 Affect Only → Origins 后用 Move 把原点移到轴心。分别检查炮塔座圈、Gun 的俯仰轴、Dym 的炮管后坐轴，以及 Wheel 和 UpperWheel 的轮轴。对规则车轮可用 Set Origin → Origin to Center of Mass (Volume)。原例若需保持子部件位置也勾选 Parents。完成后取消这些选项，测试旋转时模型是否仍在原位。

    2. 没有炮塔的坦歼

    原例使用猎虎。按 Shift+A → Empty → Plain Axes，用 G 将空轴移到炮座位置，命名为 Turret。将 Gun 放到这个空轴下面，展开确认仍是 Turret → Gun → Dym。

    3. 内部模块不显示

    在 VehicleInfo 查 Is Module Ready，并确认测试场选择模块模式。若仍缺失，核对伤害预制体的内部模块组和当前载具的绑定。模块命名 · 试车场模式

    4. 编辑时突然看不到 HitBox

    先检查 Hierarchy 的可见性，再检查伤害编辑器的隐藏选项。原图通过右侧选择菜单恢复可见性。回到目标预制体选一个装甲板，确认它仍在 HitBox 分组里。伤害模型

    5. 车库里车辆腾空或翻倒

    先确认 VehicleTextData → 移动 → Mass 已填写实际车重。再看轮碰撞是否接地、车体碰撞是否穿过地面。物理轮

    6. 命中贴图过大

    打开该弹种资产，检查 Caliber 是否用毫米填对，再比对匹配的 Bullet VFX。分别以近距和远距测试同一弹种。

    7. 模组出包后在列表找不到

    旧案例中缺的是音效引用。现在先看运行日志，确认包的平台和版本、发动机／开火音效与 VehicleInfo → Spawn Policy。普通载具使用 Player Pick。 载具排查

    做出更完整的载具

    1. 让雷达绕自己的轴旋转

    在 Blender 将雷达挂到轴心空物体，再把空物体挂在炮塔下。Unity 中选中该轴，打开 Window → Animation → Animation，创建旋转片段，为开始和结束的旋转设关键帧。激活播放此片段的 Animator 和控制器。应用材质，配置物理碰撞并保存碰撞预制体。进场检查雷达随炮塔转动时还能独立转动。 原动画操作视频

    2. 统一实体履带节朝向

    在 Blender 分离单节，Set Origin → Origin to Center of Mass (Volume)，再 Snap → Selection to Cursor。摆正后按 Ctrl+A → Rotation。原作者的左右履带样例将左节相对右节旋转 180°。将对应模型给 TrackMesh 和 LeftTrackMesh，预览整圈，检查转折和镜像方向。 履带预览

    3. 不同方向限制俯仰角

    打开 VehicleTextData → 炮塔 → Override Ranges。为经过发动机舱等有遮挡的角度新增区间，分别填起止回转角、最大仰角和最大俯角。旧例是对称区间 138° 至 180°，仰角 20°、俯角 11°。用自己的模型测试炮口是否碰到上层结构。

    4. 为载具生成缩略图

    导入图片，选 Texture Type → Sprite (2D and UI)，Sprite Mode → Single，点击 Apply。将 Sprite 绑定到 VehicleInfo 的缩略图。 缩略图

    5. 外置与内置反应装甲

    在外部 HitBox 选择 Reactive。旧作品另用一份内部网格表示反应装甲，其材料在内部结构中按内部装甲归类。先确认外部块的厚度与消耗范围，再按需要增加内部表示。 反应装甲

    6. 装甲查看中某片透明

    在 Blender 用 Face Orientation 查看法线。按 Tab 进编辑模式，选中异常面后按 Shift+N 重新计算外侧。导出覆盖 FBX 后刷新 Unity，检查该板件和 HitBox 分组都会出现。透明也可能来自缺失的板件或分组。 原法线讲解

    7. 去掉内部模型的表面贴图

    将内部模型放入场景，再打开其 Mesh Renderer → Materials。旧例在材质菜单点 Reset。如果这个材质也供显示模型使用，先在 Project 复制材质，再给内部网格分配该副本或合适的无贴图材质。保存内部预制体，到游戏的内构视图检查。

    8. 载具在界面内如何命名

    旧图高亮的是 VehicleInfo → Localized Name。编辑默认显示名，再按语言填写本地化名字。项目中的内部资产名保持唯一。保存后切换语言检查车辆列表。

    9. 让多边形炮管的表面看起来连续

    在 Blender 选炮管，右键 Shade Smooth。从侧面和炮口确认平滑边界和轮廓可接受，再导出。

    10. 旧版车顶与同轴武器

    原例的 SubTurret02 是车顶机枪，用空轴当 Dym。同轴的 SubTurret01 用三个空节点套在主炮 Dym 下，让它随主炮移动。把三段路径和开火点逐项核对。 旧版多炮塔 · 当前多炮塔参数

    11. 配对节点与重力节点

    打开 VehicleTrackData。在 SpringNode 填允许自然下垂的路径节点。用 PairNodes 将上层与负重轮附近节点配对，让上下履带随轮子移动。旧图的节距为 0.12 m，重力节点为 15，配对为 2→14、3→13、4→12、5→11、6→10。先确认自己模型编号，再用 Preview Track 看悬挂压缩时的形状。

    12. 起步和刹车时车体点头

    在 VehicleData 编辑 CenterOfGravity，小幅下移，按 K 保存。再用 WheelCollider → Forward Friction / Sideways Friction 调整轮胎摩擦。旧图示例纵向刚度 1.7、横向刚度 4。每次改一个变量，用相同速度测试起步和制动。 物理车轮 · 原 WheelCollider 讨论
