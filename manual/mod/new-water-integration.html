    新水体集成

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run new-water-integration
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "sdkCheckout": "../../../Panzer-War-Mod-SDK"
  },
  "calls": []
}

    1. 检查 SDK 自带的水体包

    按 项目初始化 完整解压 SDK。确认 UnityProject/Packages/manifest.json 已声明 com.windyverse.urp.water，其包文件位于 SDK 根目录下的 Packages/Sdk/com.windyverse.urp.water/package.json。打开 Window → Package Manager 查看 Urp Water。旧版工具曾要求手动添加此包。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${sdkCheckout}/UnityProject/Packages/manifest.json"
      ]
    },
    "expect": {
      "contains": "\"com.windyverse.urp.water\": \"file:../../Packages/Sdk/com.windyverse.urp.water\""
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "${sdkCheckout}/Packages/Sdk/com.windyverse.urp.water/package.json"
      ]
    },
    "expect": {
      "contains": "\"name\": \"com.windyverse.urp.water\""
    }
  }
]

    2. 核对水面画质

    客户端按 PC 和移动设备使用各自的画质档位。高和极高档位会请求几何细分，由支持细分着色器的设备启用。回放读取档位配置和本机支持情况，实际画面在目标设备进入有水的地图检查。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.WaterQualityTable/Get(high,false)/tessellation"
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.WaterQualityTable/Get(middle,true)/tessellation"
    },
    "expect": {
      "contains": "(Boolean) False"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.WaterSurfaceComponent/TessellationSupported"
    },
    "expect": {
      "contains": "(Boolean)"
    }
  }
]
