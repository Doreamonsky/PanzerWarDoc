    将 DIY 地图导入 Unity 工程

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run diy-map-project-import

    1. 准备资源与 YAML

    1. 从项目初始化打开公开 SDK 的 UnityProject。需要官方地图的生产资源时，有访问权限的维护者使用 Panzer-War-Mods/Projects/Maps。地图资源入口
    2. DIY 存档按物件的 itemGuid 查找资源。官方 Projects/Maps 已在 manifest 中列出 DIY 本地包。用公开 SDK 时，如已有权使用相应的本地 UPM 包，可在 Window → Package Manager → + → Add package from disk 逐个选择它们的 package.json。确认资源和配置都已出现在 Project 的 Packages 下。
    3. 在游戏的保存目录中找到对应的 .yaml，先复制一份供编辑。地图引用的资源须和写出存档时的 GUID 一致。

    2. 载入基础场景再导入

    1. 打开 Framework → 1. Editor Tools → 05. DIY 工坊 → DIY 地图编辑。点击 加载基础资源（Load Base Asset），确认后进入基础 Playground 的 Play 模式。
    2. 等待游戏环境就绪，在 选择 DIY 地图 YAML 指向文件，再点击 Load DIY Map from Yaml。构建结束后检查场景和 DIYMapConfig。
    3. 有物件缺失时，在 Console 找报出的 itemGuid。先核对引用的包和资源是否已装配，再继续调整位置。保留 GUID，避免旧存档引用断开。
    点击展开 MCP 操作点击收起 MCP 操作

    用编辑器所用的 YAML 解析器回读地图名称和 itemGuid。完整场景导入需要已加载的基础资产。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.AssetBundleManager/LuaEnv/DoString",
      "args": [
        "local typed = CS.ShanghaiWindy.Core.Data.DIYMapUserDefined\nlocal util = CS.ShanghaiWindy.Core.Utils.YamlUtil\nlocal decode = xlua.get_generic_method(util, \"DeserializeYaml\")(typed)\nlocal encode = xlua.get_generic_method(util, \"SerializeYaml\")(typed)\nlocal input = [[\nguid: 2f7d6e7d-b518-4f6f-9c2d-1d2c728f82da\ndefinedName: Tutorial Town\nrules:\n- ruleGuid: 167798a3-6d87-4ec8-a701-ae59775eb7ce\n  itemGuid: 08951884-e54b-4c7e-a449-9f2ef826cbc1\n  itemJson: '{}'\n]]\nlocal map = decode(input)\nlocal restored = decode(encode(map))\nassert(restored.definedName == \"Tutorial Town\" and restored.rules.Count == 1)\nassert(restored.rules[0].itemGuid == \"08951884-e54b-4c7e-a449-9f2ef826cbc1\")\nreturn \"DIY YAML round-trip passed\"",
        "manual-validate",
        "null"
      ]
    },
    "expect": {
      "contains": "DIY YAML round-trip passed"
    }
  }
]

    3. 保存或打包

    如果只调整物件位置，填写输出文件名和文件夹，再点 Save Map as Yaml。名称不加扩展名，工具会写入 <名称>.yaml。要作为完整模组场景发布，则按地图向导处理场景、预览和构建。
