    用 GameHub 搭建模组环境

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run mod-env-setup-hub

    公开 SDK 的首次设置见 GitHub SDK 项目初始化。如果你手上的 GameHub 提供创建工程按钮，可以用下面的步骤打开它生成的工程。

    1. 用 GameHub 创建工程

    1. 在 GameHub 中点击 创建工程，选择一个空文件夹。
    2. 工程生成后打开输出目录。找到包含 Assets、Packages/manifest.json 和 ProjectSettings 的目录，复制该路径。如果生成内容多套了一层 UnityProject，使用内层目录，在磁盘上保留同级本地依赖。
    3. 读取生成工程自己的 ProjectSettings/ProjectVersion.txt 中的 m_EditorVersion，按 Unity 引擎版本要求安装对应版本。GameHub 工程的版本取决于生成时用的模板。

    2. 用 Unity Hub 打开工程

    在 Unity Hub 的 Projects → Add → Add project from disk 中选择复制的路径。打开工程，等待首次导入和编译完成。若当前 GameHub 没有创建入口，可以从正式 SDK ZIP直接初始化。下方 MCP 配方检查已经打开的工程。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "editor_status",
    "arguments": {},
    "expect": {
      "contains": "\"projectPath\""
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "ProjectSettings/ProjectVersion.txt"
      ]
    },
    "expect": {
      "contains": "m_EditorVersion:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "Packages/manifest.json"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    3. 绑定 Steam 游戏资源

    需要在编辑器中读取 Steam 游戏资源时，先 设置 Steam 游戏资源路径。然后可从 基础载具、地图向导 或 语音包实战 开始。
