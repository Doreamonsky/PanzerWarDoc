    用 GameHub 搭建模组环境

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run mod-env-setup-hub

    使用 GameHub 创建工程，再通过 Unity Hub 打开它。也可以从 模组 SDK ZIP 开始。

    1. 用 GameHub 创建工程

    1. 在 GameHub 中点击 创建工程，选择一个空文件夹。
    2. 工程生成后复制路径。
    3. 读取生成工程里 ProjectSettings/ProjectVersion.txt 的 m_EditorVersion，按 Unity 引擎版本要求 安装。

    2. 用 Unity Hub 打开工程

    在 Unity Hub 的 Projects → Add → Add project from disk 中选择复制的路径。打开工程，等待首次导入和编译完成。GameHub 创建工程和 Unity Hub 操作由读者完成。下方 MCP 配方检查已打开的工程。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "editor_status",
    "arguments": {},
    "expect": {
      "contains": "\"projectPath\""
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/ReadAllText",
      "args": [
        "ProjectSettings/ProjectVersion.txt"
      ]
    },
    "expect": {
      "contains": "m_EditorVersion:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "Packages/manifest.json"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    3. 绑定 Steam 游戏资源

    需要在编辑器中读取 Steam 游戏资源时，先 设置 Steam 游戏资源路径。然后可从 基础载具、地图向导 或 语音包实战 开始。
