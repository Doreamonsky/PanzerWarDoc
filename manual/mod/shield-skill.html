    本教程从基础护盾参数开始，再用独立 prefab 演示自定义模型。armor 会写入护盾碰撞部件的 HitBox.Armor，不是可吸收多少伤害的生命值。

    1. 创建技能槽

    在 CrewData.upgradableSkillContents 的 skills 中添加条目，friendshipRequirement 设为 0。crewSkillRef 选择 CrewSkillBuff，其 crewSkill 选择 EnergyShieldSkillConfig。配置 version 必须等于当前 GetVersion()（3）。基础乘员设置见指挥官教程。

    教学乘员复用 Aino 的有效头像引用，原始乘员保持不变；正式内容请配置自己的头像。头像引用是后续打包的前提。

    3. 设置护盾参数

    展开 energyShieldInfo，填写 duration = 10、armor = 200、distance = 15、sizeScale = (1,1,1)。shieldType 默认 Box，也可选 Sphere 或后续示例的 Custom；下图展示最终自定义配置。

    护盾位置跟随炮塔位置加 forward * distance。Box 会跟随炮塔朝向；Custom 由 isCustomModelFacingForward 决定是否跟随。模型加载后，代码绑定护盾装甲组，把各 hitBoxes 的 Armor 设为配置值并设为间隙装甲。移除时解绑该装甲组并归还资源。

    4. 配置自定义 prefab 与命名

    本例复制官方 EnergyShield.prefab 为 Tutorial_Shield.prefab。保留根节点的 EnergyShieldMonoComponent，检查 aabb 引用 VehicleHitBoxAABBComponent，hitBoxes 引用有效护盾 HitBox。替换美术时保留这些绑定及相应碰撞体；缺引用不能视为有效护盾。

    创建 ManualNameBuildPiplineData，在 bundleNameMaps 设置 bundleObject 为该 prefab，bundleName 使用“名称.变体”，例如 tutorial-shield-shared.prefab。将此命名资产加入 ModPackageBuildPiplineData.linkedObjects。当前收集器按点拆分名称与变体，示例只使用一个点。

    将 shieldType 改为 Custom，把同一个完整名称写入 customModel。它是运行时资源键，不是项目文件路径；isCustomModelFacingForward 默认 true。本配方按运行 ID 生成独立资源键，避免教学包互相覆盖。

    5. 保存、检查与打包

    保存配置，检查版本、模型引用和命名管线，构建并验证 Windows 教学包。此操作不安装或发布内容。

    技能只向离线 VehicleInitSystem 注册。实际持续时间、穿甲交互和画面效果仍需在启用指挥官增益的离线对局中验证；本配方未执行这些游戏测试。
