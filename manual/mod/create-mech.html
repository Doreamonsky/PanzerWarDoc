    创建机甲

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run create-mech --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "source": "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar",
    "vehicleData": "${fixture}/Tutorial_NativeVehicleData.asset",
    "vehicleText": "${fixture}/Tutorial_NativeText.asset",
    "vehicleInfo": "${fixture}/Tutorial_NativeVehicleInfo.asset",

    "vehicleName": "Docs-Mech-${runId}",

    1. 准备带骨骼的显示模型和分关节的伤害模型。先制作待机、前进、横移和原地转向动画，再调试骨骼与碰撞的对应关系。
    2. 在模型的 Rig 节点挂 Animator、CharacterController 和 MechAnimatorController。控制器以 Walk、Turn 两个 Float 接收移动与转向。旧动画中的 WalkSound 事件可继续解析，这个兼容方法当前没有播放逻辑。
    点击展开 MCP 操作点击收起 MCP 操作
