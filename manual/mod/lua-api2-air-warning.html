    这段载具 Lua 行为在本地玩家附近发现敌机时显示一次日志，可附带 FMOD 告警音。先完成 Lua Hello World，以便知道在哪里导入并绑定脚本。

    1. 导入并填写参数

    1. 在 Unity 项目的资源目录创建 AirThreatWarning.lua，复制下方完整脚本。选中载具的 VehicleTextData，在杂项 → 载具 Lua 行为新增一项并绑定脚本，点击同步属性。通过预制体绑定时，可用 LuaBehaviorMono，将组件放在所属载具的层级内。
    2. 将 warnDistance 保持在 3000 m。把可用的 FMOD 事件 GUID 填到 soundGuid，第一轮可留空以便只查日志。
    3. 保存，重打包并试驾这辆车。脚本复用 OnVehicleReady 中建立的查询，每 0.5 秒检查一次。
    查询字段 本例取值与用途
    Kind VehicleKind.Flight，只收飞机。其它筛选包括 Any、Ground、Army。
    Relation VehicleRelation.Enemy，以调用 Run(vehicle) 的载具所属队伍为准。也可选择 Any 或 Friendly。
    MaxDistance warnDistance，单位为米。设为 0 时该属性不限制距离。
    MaxCount 1，配合距离排序仅保留最近的一架。未设置时查询默认容量为 32。
    SortByDistance true，将最近目标放在第一个。 
    Behavior()
Property = {
    warnDistance = { type = "number", value = 3000 },
    soundGuid = { type = "string", value = "" },
}

local AirThreatWarning = class("AirThreatWarning")

function AirThreatWarning:OnVehicleReady(vehicle)
    self.vehicle = vehicle
    self.query = VehicleAPI.CreateQuery()
    self.query.Kind = VehicleKind.Flight
    self.query.Relation = VehicleRelation.Enemy
    self.query.MaxDistance = self.warnDistance
    self.query.MaxCount = 1
    self.query.SortByDistance = true
    self.warned = false
    self.script:SetUpdateInterval(0.5)
end

function AirThreatWarning:OnUpdated()
    if self.query == nil or not VehicleAPI.IsLocalPlayer(self.vehicle) then
        return
    end
    local count = self.query:Run(self.vehicle)
    if count == 0 then
        self.warned = false
        return
    end
    if self.warned then
        return
    end
    local nearest = self.query:Get(0)
    if nearest == nil then
        return
    end
    self.warned = true
    print(string.format("[AirWarning] %s at %.0f m",
        VehicleAPI.GetDisplayName(nearest), self.query:GetDistance(0)))
    if self.soundGuid ~= "" then
        SoundAPI.PlayOneShot(self.soundGuid, self.transform.position)
    end
end

return AirThreatWarning

    2. 确认触发与重新触发

    1. 在试车场用本地玩家驾驶载具，让一架可见敌机进入警戒距离。在日志查 [AirWarning]，应显示最近目标的名称和当前距离。Lua 用 Get(0) 与 GetDistance(0) 访问这一条结果。
    2. 目标留在范围内时保持单次告警。目标离开或不可见、查询回到零条以后，应能再次触发。填了声音 GUID 时确认飞进范围会在载具位置播放声音。
    3. 检查本地玩家、敌友与可见性。联机查询会经过队伍可见性筛选，不保证隐藏目标出现。地图或模式脚本可用 RunAt(position, team) 以一个位置和队伍为参考。

    旧脚本曾定时遍历所有刚体再在 Lua 筛选飞机。这个例子复用已有查询，筛选及排序在游戏内部执行。MCP 回放模拟目标进入、停留和离开。实际声音与联机可见性在游戏中验证。
