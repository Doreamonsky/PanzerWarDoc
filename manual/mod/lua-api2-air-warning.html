    22.7.4 用例：敌机接近告警 Example: Enemy Aircraft Warning

    敌方飞机进入 3 公里内时，播放一次告警音效并打印最近一架的名字；飞机离开后重新开始监视。

    When an enemy aircraft comes within 3 km, play an alert sound once and print the name of the nearest one; resume monitoring once the aircraft leaves.

    以前常见的写法是每秒取出场景里的所有刚体，再逐个判断是不是飞机、是不是敌人。VehicleAPI.CreateQuery() 在游戏内部完成筛选和排序，Lua 只拿到结果；它的数据来自战场玩家列表，联机时也包含其他玩家。

    A common approach in the past was to retrieve all rigid bodies in the scene every second and then check each one to see if it was an aircraft and an enemy. VehicleAPI.CreateQuery() performs the filtering and sorting internally within the game, so Lua only receives the results; its data comes from the battle player list and includes other players during online battles.

    Behavior()
Property = {
  warnDistance = { type = "number", value = 3000 },   -- 米 / Metres
  soundGuid = { type = "string", value = "" },        -- 告警音效的 FMOD 事件 guid / FMOD event guid of the warning sound
}

local AirThreatWarning = class("AirThreatWarning")

function AirThreatWarning:OnVehicleReady(vehicle)
  self.vehicle = vehicle

  -- 查询对象只建一次，之后反复使用 / Create the query once and reuse it
  self.query = VehicleAPI.CreateQuery()
  self.query.Kind = VehicleKind.Flight
  self.query.Relation = VehicleRelation.Enemy
  self.query.MaxDistance = self.warnDistance
  self.query.MaxCount = 1                 -- 只要最近的一架 / Only the nearest one
  self.query.SortByDistance = true

  self.warned = false
  self.script:SetUpdateInterval(0.5)
end

function AirThreatWarning:OnUpdated(dt)
  if not VehicleAPI.IsLocalPlayer(self.vehicle) then
    return
  end

  local count = self.query:Run(self.vehicle)
  if count > 0 and not self.warned then
    self.warned = true
    local nearest = self.query:Get(0)
    print(string.format("[AirWarning] %s at %.0f m", VehicleAPI.GetDisplayName(nearest), self.query:GetDistance(0)))
    if self.soundGuid ~= "" then
      SoundAPI.PlayOneShot(self.soundGuid, self.transform.position)
    end
  elseif count == 0 then
    self.warned = false
  end
end

return AirThreatWarning

    查询对象的属性：

    Properties of the query object:

    属性 Property 含义 Meaning
    Kind VehicleKind.Any / Ground / Flight / Army，单选
    Pick one
    Relation VehicleRelation.Any / Enemy / Friendly，相对于 Run 传入的载具
    Relative to the vehicle passed to Run
    MaxDistance 最大距离（米），0 为不限
    Maximum distance in metres, 0 for no limit
    MaxCount 最多返回几辆，默认 32
    At most this many results, 32 by default
    SortByDistance 按距离从近到远排序，默认开启
    Nearest first, on by default

    要点：

    Key points:

    • 查询对象在 OnVehicleReady 里建一次，之后反复调用 Run，不会产生垃圾。

    • Run(vehicle) 以这辆载具的位置和队伍为准，结果里不包含它自己；地图和模式脚本可以用 RunAt(position, team)。

    • 结果按序号读取：Get(i) 返回载具，GetDistance(i) 返回距离，序号从 0 开始。

    • 联机对战中，只会返回你的队伍当前看得见的敌人。

    • Create the query object once in OnVehicleReady, then call Run repeatedly; this will not generate garbage.

    • Run(vehicle) uses the position and team of this vehicle as the reference, and the results do not include the vehicle itself; map and mode scripts can use RunAt(position, team).

    • Read the results by index: Get(i) returns the vehicle, GetDistance(i) returns the distance, with indices starting from 0.

    • In online battles, only enemies currently visible to your team are returned.
