    FMOD 工程设置

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run fmod-project-setup
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "sdkCheckout": "../../../Panzer-War-Mod-SDK"
  },
  "calls": []
}

    1. 打开工程并构建 Bank

    先 安装 FMOD Studio。有完整的 .fspro 工程时，在 Studio 打开它并为目标平台构建 Bank。Desktop 构建后，确认输出里有 Master.strings.bank。已有各平台 Bank 时，直接做第 2 步。

    SDK 内的 PanzerWar-FMod-UGC-Project/PanzerWar-FMod-Project.fspackage 可通过 File → Open 解包到新目录。实测 Studio 2.02.09 解包后报告 Workspace、Mixer 和 Master Bank 等数据未能载入。遇到此提示时，可以改用完整工程或已有 Bank。

    已连接 Studio 的用户可以用 FMOD MCP 的 list_banks 检查项目，再执行 build_banks。以下 Unity MCP 配方检查 SDK 压缩包和已有 Desktop Bank。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${sdkCheckout}/PanzerWar-FMod-UGC-Project/PanzerWar-FMod-Project.fspackage"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "../Fmod/Build/Desktop/Master.strings.bank"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    2. 让 Unity 找到构建结果

    打开 FMOD → Edit Settings → Bank Import。在 Source Type 中选择 FMOD Studio Project，用 Studio Project Path 指向 .fspro。如果只有分平台的 Bank，选择 Multiple Platform Build，用 Build Path 指向包含 Desktop、Mobile 等子目录的输出根目录。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:FMODUnity.Settings/Instance/HasSourceProject"
    },
    "expect": {
      "contains": "(Boolean)"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:FMODUnity.Settings/Instance/sourceBankPath"
    },
    "expect": {
      "contains": "Build"
    }
  }
]

    3. 刷新并检查事件

    执行 FMOD → Refresh Banks，再打开 FMOD → Event Browser 搜索目标事件。需要制作语音时，继续 语音包实战。回放从当前 Editor 的事件缓存读取已知事件。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:FMODUnity.EventManager/EventFromPath",
      "args": [
        "event:/aircraft/engines/engine01/engine01_cockpit"
      ]
    },
    "expect": {
      "contains": "parameter:/engine01_cockpit/zoom"
    }
  }
]

    命令行已用 Studio 自带示例构建 Desktop Bank。Unity 设置界面的保存和刷新仍待实测。
