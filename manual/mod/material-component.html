    配置载具材质组件

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run material-component --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "material": "${fixture}/Tutorial_Prop.mat",
    "settings": "${fixture}/Tutorial_MaterialSettings.asset",
    "model": "${fixture}/Tutorial_Material.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    下面在 Unity 2022.3.62f2 的 DE 工程中配置透明材质。CoreRPMatData 保存材质参数，CoreRPMatComponent 把配置带入载具的资源加载流程。

    1. 准备原材质

    在模型 prefab 中找到目标 Mesh Renderer，确认要覆盖的材质槽。教学配方复制现有桨叶材质为 Tutorial_Prop.mat，把它放入 Tutorial_Material.prefab 的第一个材质槽。实际制作时沿用模型自己的贴图和网格。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/Altius-U/Art/Default-FastProp.mat",
        "${material}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "create",
        "component": "UnityEngine.MeshRenderer",
        "values": {
          "m_Materials": [
            {}
          ]
        },
        "references": [
          {
            "property": "m_Materials.Array.data[0]",
            "asset": "${material}",
            "type": "UnityEngine.Material"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    2. 创建材质配置

    在 Project 窗口选择 Create > A Panzer War - 装甲纷争 > C Config - 配置 > SRP Material Config - SRP 材质配置，创建 CoreRPMatData。展开 coreRPMatParams，添加一项并设置：

    1. coreRPShaderType 选 Transparency。
    2. 展开 transparencyMatParam，把颜色的 Alpha 设为 0.35，smoothness 设为 0.4。
    3. 将 linkedMaterial 指向 Mesh Renderer 材质槽实际使用的同一个资产。

    若配置载具涂装，选 VehicleCamouflage。遮罩通过 vehicleCamoflageMatParam 的 hasMask 和 maskTex 传给对应着色器，通道用途以所选着色器为准。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.Data.CoreRPMatData)",
        "${settings}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${settings}/coreRPMatParams",
      "value": "[{\"coreRPShaderType\": 1, \"transparencyMatParam\": {\"color\": {\"r\": 1, \"g\": 1, \"b\": 1, \"a\": 0.35}, \"smoothness\": 0.4}}]"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${settings}/coreRPMatParams/0/linkedMaterial",
      "value": "@asset:${material}"
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    3. 挂载组件

    在目标物体上添加 CoreRPMatComponent。保持 isComponentBased 关闭，将 matData 设为刚才创建的 Tutorial_MaterialSettings。这条流程允许多个渲染器复用同一份配置。

    另一种模式是开启 isComponentBased，用 indexCoreRPMatParams 的 index 读取同一物体的 Mesh Renderer 材质槽，从 0 开始计数。更换材质槽顺序时需要同步检查索引。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.CoreRPMatComponent",
        "values": {
          "isComponentBased": false
        },
        "references": [
          {
            "property": "matData",
            "asset": "${settings}",
            "type": "ShanghaiWindy.Core.Data.CoreRPMatData"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    4. 保存并核对

    保存 prefab，读回 Mesh Renderer 的材质、linkedMaterial 和组件的 matData 引用。资源加载时按源 Material 对象匹配配置，再把参数应用到材质实例。透明度和光滑度的视觉效果需要在载具加载后查看。本例验收了编辑器资产与参数。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${model}/MeshRenderer/sharedMaterials/0/name"
    },
    "expect": {
      "contains": "Tutorial_Prop"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${settings}/coreRPMatParams/0/linkedMaterial/name"
    },
    "expect": {
      "contains": "Tutorial_Prop"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${model}/CoreRPMatComponent/matData/name"
    },
    "expect": {
      "contains": "Tutorial_MaterialSettings"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${settings}/coreRPMatParams/0/transparencyMatParam/color/a"
    },
    "expect": {
      "contains": "0.35"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${settings}/coreRPMatParams/0/transparencyMatParam/smoothness"
    },
    "expect": {
      "contains": "0.4"
    }
  }
]
