    Lua 方法的点号和冒号

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run lua-self-dot-vs-colon

    item:add(3) 在参数前自动传入 item，等价于 item.add(item, 3)。声明 function item:add(n) 时，第一个形参自动命名为 self。不接收实例的普通函数可继续用点号调用。

    在 Lua 中比较两种调用

    local item = { total = 2 }

function item:add(n)
    return self.total + n
end

assert(item:add(3) == 5)
assert(item.add(item, 3) == 5)
assert(math.abs(-3) == 3)

    若写成 item.add(3)，3 会被当作 self，n 则没有实参。需要把方法传给事件时，可参阅在 Lua 回调中保留 self。
