    22.7.1 用例：导弹挂架随弹药显示 Example: A Missile Rack That Follows the Ammo

    每发射一枚导弹，挂架上就少一枚模型；补给后模型重新出现。弹药数量由游戏提供，脚本不用自己统计发射次数，也不需要判断是否在车库：车库里弹药是满的，模型自然全部显示。

    Each time a missile is fired, one model is removed from the rack; the models reappear after resupply. The ammunition count is provided by the game, so the script does not need to track the number of shots fired itself, nor does it need to check whether the vehicle is in the garage: in the garage, the ammunition is full, so all models are naturally displayed.

    把脚本挂在载具模型上，把导弹模型命名为同一个前缀加序号（例如 Missile_1、Missile_2……），在属性里填写武器序号和前缀。

    Attach the script to the vehicle model, name the missile models with the same prefix followed by a sequence number (for example Missile_1, Missile_2...), and fill in the weapon index and prefix in the properties.

    Behavior()
Property = {
  weaponIndex = { type = "number", value = 1 },   -- 第几件武器（0 开始） / Weapon index, from 0
  modelPrefix = { type = "string", value = "Missile_" },
}

local MissileRack = class("MissileRack")

function MissileRack:OnVehicleReady(vehicle)
  self.weapon = WeaponAPI.GetWeapon(vehicle, self.weaponIndex)
  if self.weapon == nil then
    print("[MissileRack] weapon " .. tostring(self.weaponIndex) .. " not found")
    return
  end

  -- 只在这里找一次，按层级顺序；空数组说明模型上没有这些节点
  -- Look them up once, in hierarchy order; an empty array means the model has none
  self.models = TransformAPI.FindAllDeep(self.transform, self.modelPrefix)

  -- 每发一枚、每次补给都会触发；行为销毁时自动退订
  -- Fires on every shot and every resupply; ends with the behaviour
  WeaponAPI.OnAmmoChanged(self.script, self.weapon, function()
    self:Refresh()
  end)

  self:Refresh()
end

function MissileRack:Refresh()
  local left = WeaponAPI.GetTotalAmmo(self.weapon)
  for i = 0, self.models.Length - 1 do
    self.models[i].gameObject:SetActive(i < left)
  end
end

return MissileRack

    要点：

    Key points:

    • TransformAPI.FindAllDeep 只在 OnVehicleReady 里调用一次。返回的数组按层级顺序排列，所以模型在层级里的顺序就是消耗的顺序。

    • WeaponAPI.OnAmmoChanged 在每次开火和每次补给时触发；传入 self.script 后，行为销毁时自动退订。

    • 这个脚本没有 OnUpdated，完全由事件驱动，平时没有任何每帧开销。

    • TransformAPI.FindAllDeep should only be called once in OnVehicleReady. The returned array is arranged in hierarchy order, so the order of the models in the hierarchy is the order in which they are consumed.

    • WeaponAPI.OnAmmoChanged is triggered on every shot and every resupply; passing self.script ensures that the subscription is automatically unsubscribed when the behaviour is destroyed.

    • This script has no OnUpdated, is entirely event-driven, and has no per-frame overhead during normal operation.
