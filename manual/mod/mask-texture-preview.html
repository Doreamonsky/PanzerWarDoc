    在 Unity 预览遮罩贴图

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run mask-texture-preview
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "material": "${fixture}/Tutorial_Prop.mat",
    "settings": "${fixture}/Tutorial_MaterialSettings.asset",
    "model": "${fixture}/Tutorial_Material.prefab",
    "texture": "${fixture}/TutorialMask.png"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}
    1. 将自己的遮罩贴图导入 Unity，关闭 sRGB (Color Texture)。用遮罩合并教程核对通道。
    2. 复制要预览的材质，选择 WindyVerse/Vehicle/FullPBR。将贴图赋给遮罩字段 _MaskMap，把预览材质拖到独立模型上。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.AssetBundleManager/LuaEnv/DoString",
      "args": [
        "local U = CS.UnityEngine\nlocal source = U.Texture2D(2, 2, U.TextureFormat.RGBA32, false, true)\nlocal color = U.Color(0.24, 0.76, 0, 0.5)\nfor x = 0, 1 do\n    for y = 0, 1 do source:SetPixel(x, y, color) end\nend\nsource:Apply()\nlocal png = U.ImageConversion.EncodeToPNG(source)\nCS.System.IO.File.WriteAllBytes('${texture}', png)\nlocal copy = U.Texture2D(2, 2, U.TextureFormat.RGBA32, false, true)\nassert(U.ImageConversion.LoadImage(copy, png, false))\nlocal pixel = copy:GetPixel(0, 0)\nassert(math.abs(color.r - pixel.r) < .005 and math.abs(color.g - pixel.g) < .005)\nassert(math.abs(color.b - pixel.b) < .005 and math.abs(color.a - pixel.a) < .005)\nU.Object.DestroyImmediate(source)\nU.Object.DestroyImmediate(copy)\nreturn \"PNG channel sample verified\"\n",
