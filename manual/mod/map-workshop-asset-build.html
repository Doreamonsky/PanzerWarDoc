    为地图工坊构建道具

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    1. 在 URP 工程中把道具模型放到原点，添加 Box Collider 或 Mesh Collider。将根对象和子对象设为 Building 层，保存为预制体。
    2. 在 Project 中右键预制体，选择 ShanghaiWindy → DIYMap → PropFromSelection。选择 Assets 下的输出目录，检查生成的 DIYMapPropData 已引用显示模型。
    3. 在 DIYMapPropData 把 渲染类型 设为 URP。点 创建预制体，再点 创建缩略图。Unity 还在生成预览时，等预览出现后再点一次。已有资源时对应按钮显示 更新预制体 和 更新缩略图。

    1. 创建 DIYMapDataBuildAssemble，把要发布的道具添加到 BuildMap。按目录收集时，设置 Pack Folder 后点击 设置文件夹下的文件打包，并检查填充结果。
    2. 将构建组拖入 ModPackageBuildPiplineData 的 Linked Objects，对目标平台构建。归档应包含 .diymapassemble 构建组和对应的 .mapdiy 道具。
