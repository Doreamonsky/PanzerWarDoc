    准备模型

    1. 按 SDK 环境配置准备项目。建模时使用米作为长度单位，Unity 中保持 +Z 朝前、+Y 朝上。预留车体、炮塔、主炮和炮管的转轴。履带车还需要设置两侧车轮与履带。准备贴图、引擎和开火音效。参见 Blender 轴向修正。
    2. 单独制作伤害模型，并按伤害模型命名配置装甲和模块节点。导入后检查模型材质与碰撞体。

    配置资产

    1. 在 Framework - 框架 → 0. Home Page 打开载具制作引导，再打开载具创建工具。输入新名称，按 Ground 创建。
    2. 在 VehicleInfo 填写载具信息。在 VehicleHitBox 绑定伤害模型和模块配置。在 VehicleData 绑定主模型、VehicleHitBox 和 VehicleTextData。按载具配置武器、音效、车轮参数和履带资源。模型节点和开火位置可从 VehicleData Inspector 打开载具工具检查。

    点击展开 MCP 操作点击收起 MCP 操作

    构建和试车

    1. 在 VehicleData 的 Inspector 点击打包生成载具预制体。修改伤害模型或节点后重新打包。
    2. 用模组构建工具创建与目标平台匹配的包，将 VehicleInfo 加入构建管线。安装后进入载具测试场，检查移动、瞄准、开火和受损表现。
