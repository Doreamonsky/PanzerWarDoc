    本教程从 Blender 模型开始，制作、打包并试开一辆单炮塔履带车 Tutorial-Tank。参数表给出了首轮可照填的教学值。KV-2 的实图展示同一套节点与资产关系，最后可用它做试车对照。

    1. 准备工程、模型和声音

    1. 按 项目初始化 安装并打开 SDK 工程。使用 SDK 要求的 Unity 版本，等待 Console 中的编译错误解决后再打开模组工具。找不到工具菜单时先检查这一项。
    2. 在 Blender 中准备显示模型和独立的伤害模型。贴图可用 Substance 3D Painter、Photoshop 等工具制作。准备基本色和法线等贴图，以及引擎启动、怠速、运行与开火近声、远声。首次测试可以引用 SDK 中兼容的 FMOD 配置。
    3. 为这辆车在 Project 窗口建一个文件夹，再为模型、材质和碰撞预制体建立子目录。保留源文件，后续更新原有 FBX 时沿用原路径和 .meta，以保留 Unity 引用。

    2. 整理 Blender 模型并导出

    在 Blender 的 Outliner 中为载具保留一个根对象。选择子对象，再按住 Shift 选择它的父对象，通过 Ctrl+P → Object (Keep Transform) 建立父子关系。分离部件时可在 Edit Mode 选中该部件的面，再按 P → Selection。将部件原点放在实际转轴处，避免旋转时围绕车体原点公转。

    根对象下的节点 放入的对象与检查项
    MainBody 车体网格。
    Turret → Gun → Dym 炮塔、主炮俯仰节点、炮管后坐节点。炮塔原点在座圈中心，主炮原点在俯仰轴，炮管向车头伸出。三个节点逐层嵌套。
    LeftWheel、RightWheel 空的分组对象。负重轮分别命名 l_1、l_2…和 r_1、r_2…，原点在轮轴中心。
    LeftUpperWheel、RightUpperWheel 空的托带轮分组。将两侧托带轮放到各自分组，可分别用 lu_1、ru_1 编号。当前打包器会按前后位置重新排序轮子。
    LeftTrack、RightTrack 静态履带网格或对应的占位节点。后面还会为动态履带设置履带节和路径。
    1. 在 Blender 按实际尺寸建模，以米为单位。选中前述对象，点 File → Export → FBX。旧教程图中使用 Scale 1.00、Apply Scalings → FBX Units Scale、Forward → −Z Forward 和 Up → Y Up。导入 Unity 后确认 +Z 朝前、+Y 朝上，再用已知长度测量车体。轴向问题参见 Blender 轴向修正。
    2. 另存一份低面数的伤害模型。按装甲厚度、材质类型和活动部位拆开板件。在引擎中每块独立设置厚度，随炮塔、主炮或炮管转动的板件后续要挂在相应父节点。内部模块也要独立拆分。按伤害模型命名规范命名后导出。
    3. 小型入门载具可沿用旧指南的预算作为起点，显示模型约 2 万面以内、约 4 个材质、贴图 2048 × 2048 或更低，伤害模型约 5000 面以内。先合并重复材质、简化看不见的面和碰撞轮廓，保留可辨识的车体、炮塔与轮组。

    把 FBX 拖入 Unity 场景，展开模型根节点。下面是载具工程的 KV-2。先在 Hierarchy 找到 MainBody 与 Turret，再逐级展开 Turret → Gun → Dym，对照 Scene View 的部件位置。

    KV-2
├── MainBody
├── Turret
│   └── Gun
│       └── Dym
├── LeftWheel / LeftUpperWheel / LeftTrack
└── RightWheel / RightUpperWheel / RightTrack

    3. 在 Unity 中绑定材质和物理碰撞

    1. 将显示 FBX、伤害 FBX 和贴图拖进 Project。选中显示 FBX，在 Inspector 的 Model 页从 Scale Factor = 1 开始。沿用 FBX 文件单位，关闭 Generate Colliders，保留子节点层级。伤害 FBX 在 Model 页启用 Read/Write，便于生成伤害网格。点 Apply 后检查实例根缩放为 1, 1, 1，车头沿 +Z、炮口朝前。用长 1 米的参考立方体核对比例。
    2. 在 Project 右键 Create → Material，选工程支持的载具材质。把基本色图放进 Base Map，把法线贴图在导入设置中设为 Normal map 后填入法线槽。展开模型的 Mesh Renderer → Materials 按槽绑定车体、轮组和履带材质。载具表面应显示正常贴图。若为粉色，先查当前渲染管线与材质 Shader。
    3. 在 Hierarchy 展开模型。分别给车体和炮塔的实体网格添加 Box Collider，关闭 Is Trigger，点 Edit Collider 调整 Center 和 Size。从正面及侧面检查盒体：覆盖硬质车体，底边高于负重轮接地点，炮口与轮子留给各自的节点控制。
    4. 把模型根对象拖回 Project 的 Collision 文件夹，保存为预制体。后续 MainModel 引用这个预制体。用于击穿判定的板件由独立的伤害模型提供。
    点击展开 MCP 操作点击收起 MCP 操作

    4. 创建并核对载具数据

    1. 在 Unity 顶部打开 Framework - 框架 → 0. Home Page，点击载具制作引导。在引导的创建步骤点击打开，进入 GM 编辑器的载具 → 载具创建。也可直接在 GM 编辑器选择这个分类。
    2. 类型选择 Ground，输入唯一内部名，例如 Tutorial-Tank。当前创建工具接受英文大小写、数字和短横线。前缀可选，显示名稍后单独设置。点击创建载具，确认创建。
    3. 在 Project 打开 Assets/Res/Vehicles/Ground/Data/Vehicle/Tutorial-Tank/。对照下表核对生成的资产。把内部名填回制作向导可跳转到相应文件。
    生成的资产 在哪里使用
    Tutorial-Tank.asset（VehicleInfo） 设置显示名称、等级、国家、缩略图。最后把它拖入模组构建管线。
    Tutorial-Tank_VehicleHitBox.asset 绑定外部装甲、内部模块和生成的伤害预制体。
    Tutorial-Tank_VehicleTextData.asset 配置基础、移动、开火和炮塔参数。
    Tutorial-Tank_VehicleData.asset 汇总模型与数据，编辑关键节点，并生成载具预制体。
    Tutorial-Tank_WheelCollider.prefab 与 Tutorial-Tank_VehicleTrack.asset 给 移动参数提供轮碰撞与动态履带配置。

    5. 生成并编辑伤害模型

    1. 在 Project 选中 VehicleHitBox。把外部装甲 FBX 拖入 外部装甲模型（External Armor Model）。有单独制作的模块模型时，同时填入 Internal Module Model。可给 Refer Model 绑定显示模型作为定位参考。
    2. 点击 生成预制，再点击 编辑模式。确认 Unity 进入这辆车的 Prefab Mode，编辑窗口显示相同的预制体。点击 外部装甲模型 - Generate External Armor 生成板件。已有内部模块模型时，使用 内部模块模型 - Generate Internal Armor。
    3. 在 Hierarchy 选中一个板件，在其 HitBox 组件中核对装甲厚度和类型。把板件拖到 HitBox/Main、HitBox/Turret、HitBox/Gun 或 HitBox/Dym 对应组。上下移动或转动某部件时，它的板件应跟着对应部件。命名解析和数据图见 伤害模型命名与导入。
    4. 在编辑窗口选择模块类型和预设，点击放置后移动到实际位置。在 InternalModule 下用相同的四组关系整理模块。通过 InternalModule 组件可逐个给模块设置 HP。批量调整时，在 VehicleHitBox 里填写总血量并设置需要的按类型覆盖，然后点击 自动设置模块血量。
    5. 对乘员勾选其岗位。准备支持模块模式的履带载具时，检查车长、驾驶员、炮手和通讯员，还需要装填手或自动装填模块。第一轮只验证基础车时可先保留模块模式关闭，完成内部配置后再开启。
    6. 选中弹药架节点的 InternalModule。为它添加边界并调整到覆盖相应的弹药区域，再点击 创建弹药架模型缓存 - Create Ammo Cache。可以在伤害编辑窗口用批量更新弹药架模型缓存处理多个弹药架。检查边界与生成的网格缓存一一对应。
    7. 在 Prefab Mode 按 Ctrl+S 保存并退出。回到 VehicleHitBox 检查已绑定生成的预制体。

    在 Scene View 比较两份模型。KV-2 的显示模型保留材质和细节，橙色伤害模型按装甲区域拆分，供伤害和装甲检查使用。两份模型在示意图里并排摆放。配置时应保持它们的原点和方向一致。

    6. 设置载具信息、炮弹、音效和参数

    1. 打开 VehicleInfo，显示名称填 Tutorial Tank、等级填 3。找到 出生方式 - Spawn Policy，设为 玩家选择（Player Pick）。如果从雷达或召唤物复制，尤其要检查这个字段。将国家与 VehicleTextData → 基础保持一致，打包会同步国家。用 载具缩略图 设置列表图片。
    2. 项目中已有适用音效时，先用现成的 VehicleEngineFmodSoundData 和 BulletFmodSound。自制音效时，将录音导入匹配的 FMOD 工程，给引擎的启动和运行事件安排怠速与加速声音，并配置开火的近、远听感以及相应事件。构建并刷新 Bank 后，用事件选择器绑定资源。旧教程中的 Fire Near、Fire Far 是旧音频资产的字段。FMOD 工程配置
    3. 打开 VehicleTextData，从 Inspector 底部点打开炮弹编辑器，新建穿甲弹 Tutorial-76mm-AP。首轮填 Caliber = 76 mm、Velocity = 650 m/s、Penetration = 90 mm、Damage = 100，弹头选 AP。在 模块中填入弹体质量 6.5 kg。这发实心弹的引信延迟和 TNT 当量均为 0。选择匹配的 AP Bullet VFX，再把资产拖入 开火 → 炮弹列表。第一轮只留这一项。
    4. 按表配置 VehicleTextData。修改后保存并重新选中，确认字段和引用都保留。教学车使用本地炮和炮塔设置。若栏位被共享资产隐藏，先清空 Shared Gun Data 或 Shared Turret Data，再编辑本地值。
    标签页 要完成的操作
    基础 · PSParameter Health 600、View Range 360 m。先关闭自定义瞄准点，待前向和开火点通过试车后再配置。
    移动 · PTCParameter 保持履带控制器。质量 30,000 kg，前进／倒车限速 35／10 km/h，正向／倒车扭矩 3500／2600、制动扭矩 5000。扭矩曲线的示例点是 (0, 1)、(35, 0.35)，先关闭模拟挡位。绑定有效的引擎音效，在下一节检查 TankWheelCollider 与 Track Data。
    开火 · TFParameter 标准（Standard），装填 6 秒，主炮总弹数 30，关闭 Has Slot。射击间隔 0，后坐比例 1，保留一项 AP 弹和有效开火音效。基础 dispersion 用 0.003。展开 Spread，按 76 mm 的默认值填下段参数。口径从炮弹资产读取。
    炮塔 · MTParameter 对称回转半角 180°，炮塔 18°/s，炮管俯仰 12°/s，最大仰角 20°、最大俯角 6°。俯角这里填正数。先留空各方向的覆盖范围。

    Spread 中的缩圈数据和基础 dispersion 是两组设置。76 mm 的默认缩圈数据为散布 0.35、瞄准时间 1.92 秒、移动／炮塔转向系数各 0.14、炮管移动系数 0.11，开火后系数 3、损毁系数 2。保存后检查 Inspector 已消除散布和炮弹后效提示。

    7. 绑定主模型并定位开火节点

    1. 选中 VehicleData。将第 3 节的碰撞预制体拖进 Model Data → MainModel。确认 VehicleTextData 和 HitBox 分别指向这辆车的详细数据和伤害资产。
    2. 点击 编辑进入变换编辑。Scene 视图中会出现橙色节点。每改好一组，在 Scene 视图按 K 保存。用前视核对横向，侧视核对高度，再从斜前方检查节点朝向。

    | 节点 | 应放的位置 | | --- | --- | | FFPoint、EffectStart | 炮口正中、朝 +Z，略出炮口避免与炮管相交。教学车以 Gun 为父节点，局部坐标 (0, 0, 2.45)。 | | CenterOfGravity | 车体内、左右轮之间。教学车局部坐标 (0, 0.78, 0)。悬挂下沉与起步点头异常时回查。 | | MainCameraFollowTarget、MainCameraGunner | 前者给第三人称相机追随，放在车体上方。后者给炮手视角，放在炮口方向的瞄准装置。 | | EngineSound、EngineSmoke | 分别放在发动机舱和排烟口。每次调整后回到编辑模式检查位置已保存。 | 3. 点击 解锁视图（Unlock Inspector）。回到 Project 核对选中的仍是这辆车，重开编辑模式时节点应保留刚保存的位置。

    8. 调整负重轮与履带

    1. 把显示预制体和 WheelCollider 预制体拖进场景，按轮子对照轮碰撞的半径与悬挂行程。修改场景实例后，通过 Overrides → Apply 或右键值选择 Apply to Prefab 把修改写回正确的资产。也可以直接在 Prefab Mode 修改并保存。
    2. 教学车轮半径 0.43 m、轮质量 320 kg。当前模板的 Suspension Distance 为 0.2，Spring 为 205000，Damper 为 14500，Target Position 为 0.5。Forward Friction 的四个滑移/值项为 1，Stiffness 为 1.7。Sideways Friction 的 Extremum Slip/Value 为 1.2，Asymptote Slip/Value 为 1，Stiffness 为 4。按你的车重与轮径试车后再调。车轮设置与图示
    3. 选中 VehicleTrackData，为**履带模型（TrackMesh）**绑定单节履带预制体。左右形状不同时还可设置左履带模型。**履带长度（手动设置）**对应字段 TrackDistance，可先从默认 0.12 开始，按实际履带节长度调整。保留编辑器生成的悬挂数据。
    4. 在 VehicleData 点击**编辑悬挂（Edit Track）**打开编辑器。若直接从履带资产进入编辑模式，把已有的载具编辑对象填给 Target Edit Object 后点击 读取悬挂信息。编辑对象还未生成时，回到 VehicleData 进入编辑模式，生成后再来编辑履带。
    5. 从侧面观察轮组，按绕履带一圈的顺序点击 创建节点并放置节点。把路径放到负重轮下方、托带轮上方和前后转折处，检查每一侧形成闭环。可以临时隐藏伤害模型或静态履带，便于观察。
    6. 点击 预览悬挂（Preview Track），检查履带节的方向、转角与间距。调整后使用 更新预览，完成后点击 保存数据与解锁视图。检查履带数据仍绑定在这辆车。履带 IK 与悬挂图示

    下面用载具工程的 KV-2 数据展示履带环路。橙点是路径节点，青线依次把它们连成闭环，整条示意线向外移开一点以便观察。自己的车也应沿负重轮底部绕过两端轮，再从上方闭合。

    10. 构建、安装和验收你的模组

    1. 在 GM 编辑器打开模组打包 → 创建模组包，用清楚的包名，例如 Vehicle-Tutorial-Tank。打开创建的 ModPackageBuildPiplineData，将这辆车的 VehicleInfo 拖入 Linked Objects。检查 Linked Mod Package 已引用相应的 ModPackageData。
    2. 在 File → Build Settings 或 Ctrl+Shift+B 选定目标平台，并完成平台切换。检查当前活动平台，再在构建管线里构建链接的资源。在 ModPackageData 填写名称、简介、作者和版本，执行 Package Now。每次更换平台都重新构建资源并打包。
    3. 在工程的 Build/Mod-Package/<平台>/ 下找到生成的 .modpack，核对平台后按安装模组导入。Windows 产物用于 Windows 试车。以实际输出路径和文件扩展名为准。
    4. 在 SDK 中也可先选 VehicleData → 试驾（重打包），使用载具测试场验证当前工程。初次只验证外装甲时选 Health Based，确认能选中 Tutorial Tank 并生成在地面。完成内部模块后，再以 Module Based 测试。
    5. 用默认移动键测试前进、倒车和左右转向，松开后车辆应减速。观察负重轮接地、履带节是否反向或离开车轮。瞄准与车头不同方向的目标，检查炮塔回转和炮管俯仰。在靶场用第一个弹种开火，确认弹从炮口出现、弹数减一且约 6 秒后重新装填。最后测试命中反馈。
    6. 若包已成功安装而列表找不到车，先查 Player Pick、测试场伤害模式及地图可用的载具类型。若能上车却不动，先查移动扭矩与 TankWheelCollider。若转向后炮口错位，回到第 7 节检查 Gun → Dym 层级与开火点，再重打包试驾。

    变体 如何在基础车上继续
    轮式载具 对沿用履带控制器的轮式车，保留 LeftTrack 和 RightTrack 占位节点，按原流程调整轮碰撞，并配置轮式和履带控制差异。
    机炮（旧教程的 M3 Stuart 示例） 在主炮开火数据选标准模式，勾选 Has Slot，设 Slot Count 与 Slot Duration。旧图示例为 5 与 3.35，试车时检查连发和随后装填的节奏。
    弹鼓炮（Progetto 65 示例） 将 Fire State 设为 Drum，填写 Fire Duration 与 Reload Times。旧图示例为 2 秒与 [12.4, 10.3, 8.6, 6.8]，逐档核对装填。
    弹夹炮（Bat 25t 风格示例） 选 Advance，在 Advance Fire Class 填短装填、长装填与每夹弹数。旧图演示短装填 2 秒、长装填 33 秒、每夹 4 发。
    多炮塔（BMD-1、T-35） BMD-1 示例将副武器配置为导弹。T-35 示例在模型根节点下增加 SubTurret01 → SubGun01 → SubDym01，其余三个副炮塔用 02、03、04 编号。设置从模型根到炮塔、从炮塔到炮根、从炮根到炮管的路径，核对发射点与特效偏移。
    双管（ST-II） 旧示例把 SubTurret → SubGun → SubDym 放在 Turret/Gun 下。把第二根炮管的支点设在其炮尾回转位置。旧配置中的炮塔路径为 Turret/Gun/SubTurret，枪和炮管路径分别为 SubGun、SubDym。按旧版多炮塔复现核对它与主炮的瞄准方向。

    以上旧图读数用于理解界面，可按你的模组重新调校。新载具的多炮塔优先看 VehicleTextData 的多炮塔配置。遇到模型不显示、开火方向错误或打包后找不到载具时，先查看载具开发排查。
