    在 Lua 回调中保留 self

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    回调通常会在事件发生时由引擎调用。若处理函数需要访问当前对象，用闭包捕获实例，再在闭包内用冒号调用它的方法。

    1. 注册两个按键回调

    将以下内容保存到 InputTutorial.lua，再把脚本绑定到 LuaBehaviorMono。这个示例绑定 W 键，只为一个物体使用动作名 ManualInputTest。若多个物体都需要注册，各用一个唯一动作名。

    Behavior()
Property = { keycode = { type = "string", value = "w" } }

local InputTutorial = class("InputTutorial")

function InputTutorial:OnStarted()
    InputAPI.RegisterKeyInput("ManualInputTest", self.keycode,
        function(context) self:OnKeyPerformed(context) end,
        function(context) self:OnKeyCanceled(context) end)
end

function InputTutorial:OnKeyPerformed(context)
    print("pressed")
end

function InputTutorial:OnKeyCanceled(context)
    print("released")
end

function InputTutorial:OnDestroyed()
    InputAPI.UnregisterKeyInput("ManualInputTest")
end

return InputTutorial

    传给 RegisterKeyInput 的两个函数保留当前 self。对象销毁时，用相同的动作名调用 UnregisterKeyInput。

    2. 核对绑定和参数

    保存 prefab 后，确认「行为脚本」为 InputTutorial，实例属性 keycode 为 w。回放已验证组件绑定和 Lua 闭包。测试真实按键时，检查按下与释放是否各调用一次处理函数，以及销毁物体后是否解除绑定。
