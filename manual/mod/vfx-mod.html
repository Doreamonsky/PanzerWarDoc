    这个例子将特效注册为 TutorialVFX，再把这个键绑定到炮弹的弹道。第一次制作炮弹时，可以先使用坦克教程的原装特效，确认炮口、弹道和命中都能显示，再改成自己的资源。

    1. 建立资源标识和特效预制体

    1. 在 Project 右键选 Create → A Panzer War → P Pool → Pool Resource Identifier。给标识填显示名。游戏用标识把已安装的特效包列到选择项中，GUID 由 Unity 自动生成。需要给旧「马哥特效包」追加资源时，请向作者取得原标识资产。同名新资产会生成自己的 GUID。
    2. 把粒子效果做成独立 GameObject，将它拖到 Project 保存为 prefab。双击打开，在根节点挂 PoolItemComponent。做弹道时，在子节点 Trail 添加 Trail Renderer，然后把这个子物体拖进**武器拖尾（Weapon Projectile）**列表。后效回放和炮弹展示会隐藏这份拖尾。保存 prefab，再从根节点打开组件检查引用。

    2. 配置对象池资源

    在相同 P Pool 菜单创建 Pool Resource。将第一步的标识拖入 Identifier，再展开 Spawn Reses，点击 + 添加一项。

    字段 教学值 用途
    特效名称 TutorialVFX 运行时查找的键。建议为自己的模组取独立名字。
    特效物体 第一节保存的 prefab 调用时由对象池生成。
    预加载实例化数量 -1 按需生成。正数会预建实例，可减少首次播放时的卡顿。数量越多，占用的内存和加载时间越大。
    生命时长 3 秒 普通一次性效果到时回收。0 留给由逻辑主动回收的喷火、激光等效果。

    保存后点击刷新特效下拉框。如果选不到新键，检查资源条目是否保存、Prefab 引用是否为空，再刷新一次。

    3. 绑定炮弹、构建并试用

    1. 选中炮弹并打开引用的 BulletVFX。把 TutorialVFX 选到弹道。如果想保留原弹道作为回退，在重载弹道列表里添加 TutorialVFX，保留原基础键。制作着弹效果时可同样填写击中地面或击中装甲。回到炮弹确认它仍引用刚编辑的 BulletVFX。
    2. 如果特效与载具同包，把 Pool Resource 和载具数据加入同一构建管线。如果分包，把 Pool Resource 加进特效包的 Linked Objects，构建特效包。把该包的 ModPackageData GUID 加到载具包的依赖，再重打包载具。这里的依赖指整个模组包，资源标识的 GUID 用于区分特效选择项。
    3. 用同一平台的包安装并试车，射击空地和装甲目标，观察新弹道是否播放、旧效果是否能回退、短时效果是否能回收。若只显示基础效果，先查键名拼写、依赖是否加载，再核对优先使用的特效包。多个已安装对象池注册同一个键时，游戏优先用当前选中的特效包。
