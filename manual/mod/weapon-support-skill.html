    本教程配置离线武器支援，并复制官方 Altius 支援 prefab 演示自定义资源、飞行路径和武器节点。它不是一份从零制作可用无人机模型的教程。

    1. 创建技能槽

    在 CrewData.upgradableSkillContents 的 skills 中新增条目，设 friendshipRequirement = 0。crewSkillRef 选择 CrewSkillBuff，其 crewSkill 选择 WeaponSupportSkillConfig。version 必须等于当前 GetVersion()（3）；详细乘员设置见指挥官教程。

    教学乘员复用 Aino 的有效头像引用，原始乘员保持不变；正式内容请配置自己的头像。头像引用是后续打包的前提。

    3. 初始化支援配置

    先创建 weaponSupportInfo 实例，再设置字段；该字段声明时没有默认实例。visualType 可选 None（0）、Altius（1）、Custom（9999）。Altius 使用资源键 Altius-U-Skill.prefab，需要对应资源可加载；None 不加载模型。

    设置 duration = 30、isScouting = false、scoutSpottingDuration = 5、maxScoutingDistance = 1000。开启侦察后才执行距离与视线检查。下面的截图展示后续切到 Custom 后的最终配置。

    4. 指定自定义模型

    复制官方 Altius-U-Skill.prefab 为 Tutorial_Support.prefab，保留根节点的 WeaponSupportMonoComponent 及其 visualModel、rigidBody 和武器引用。customZoomPoint 是炮手视角点。

    创建 ManualNameBuildPiplineData，在 bundleNameMaps 把 prefab 赋给 bundleObject，设置一个完整的“名称.变体”资源键，例如 tutorial-support-shared.prefab。把命名资产加入 ModPackageBuildPiplineData.linkedObjects，再设 visualType = Custom、customVisualModel 为同一个完整资源键。配方按运行 ID 生成独立名称。

    5. 配置路径并刷新武器节点

    选择 moveType = FollowSpine，将 followSpline 指向有长度的 SplineContainer。本例保留模板的航线，把 followSplineVelocity 设为 50，并把 followSplineVelocityCurve 在整个 0–1 区间设为 1。实际推进速度由曲线倍率乘速度决定；新组件默认的单键曲线值为 0，直接保留会不移动。Stationary 不推进路径。

    修改 fireSystemParameters 中的炮管、炮塔和节点路径后，点击“刷新武器节点”。它生成 fireSystemTransforms、simpleFireGunGuids 和 simpleFireTurretGuids。这些引用必须在支援 prefab 内部保持一致，支援火力来自资产本身，不要求套用母载具主炮的 GUID。配方调用同一刷新方法并保存 prefab。

    6. 保存、检查与打包

    检查技能版本、非零曲线倍率、模板武器的生成节点与 GUID，构建并验证 Windows 教学包。技能仍只面向离线载具；打包成功不代表游戏内模型、开火、冷却或侦察已经通过测试。
