    14. Upload to Steam Workshop 上传 Steam 创意工坊

    You should read this doc before getting started. This will help you to update Mods on multi-platform without re-importing all your resources. (In mainland China, you may need a network accelerator to access the Steam Workshop.)

    在开始之前，请阅读本文档。这将帮助你在多平台上更新模组，而无需重新导入所有资源。（在中国大陆地区，访问 Steam 创意工坊可能需要使用网络加速器。）

    4. Multi-Platform Build 多平台打包

    Preparation 准备

    You need to build the pipeline. And you get a folder with Mod resources.

    首先，你需要构建流水线，以获得包含模组资源的文件夹。

    Mod Upload Tool 模组上传工具

    Select Mod upload tool from Steam.

    从 Steam 中选择模组上传工具。

    Or from Mod project

    或者从模组工程的菜单中打开。

    Create your Mod Package 创建你的模组包

    Input the mod package file name to create item

    输入模组名称，然后点击 Create Item 按钮。

    Copy your Mod resources. 拷贝你的模组资源

    Copy the prepared Mod resources (PanzerWar-Mods\UnityProject\Build\Mod-BuildPipline\StandaloneWindows64\StandaloneWindows64__ShipSteam) to new folder: SteamLibrary\steamapps\common\PanzerWar-DE\Mod-PW-Uploader\WorkshopContent<Your item name>

    将准备好的模组资源（PanzerWar-Mods\UnityProject\Build\Mod-BuildPipline\StandaloneWindows64\StandaloneWindows64_<你的 ModPack 名称>_ShipSteam）拷贝到以下新文件夹：SteamLibrary\steamapps\common\PanzerWar-DE\Mod-PW-Uploader\WorkshopContent<你的Item名称>

    Preview Icon 预览图片

    Preview icon should be a jpg or png image file size less than 1mb.

    预览图片应为 JPG 或 PNG 格式，文件大小需小于 1MB。

    You can click pick icon to select icon faster.

    你可以点击 Pick Icon 按钮快速选择图片。

    Basic Information 基础信息

    You need to input title and description.

    你需要输入标题和简介。

    Tag 标签

    You can select the following tag to help sorting. Vehicle,Skin,Voice,Map

    你可以选择以下标签以便分类：Vehicle, Skin, Voice, Map。

    Visibility 可见性

    Visibility will decide who can see your workshop item. Private means only you can see it. Friend means only you and friends can see it. Public means everyone can see it.

    可见性将决定谁可以看到你的创意工坊内容。Private 表示仅你自己可见；Friend 表示仅你和好友可见；Public 表示所有人可见。

    Click Submit to upload 点击提交以上传

    FAQ 常见问题

    1. You need to accept the Steam Workshop legal agreement for this game before you can upload items!

    Visit: [https://steamcommunity.com/id//myworkshopfiles/](https://steamcommunity.com/id//myworkshopfiles/) and accept the legal agreement. Replace in url to your steam id

    访问 [https://steamcommunity.com/id//myworkshopfiles/](https://steamcommunity.com/id//myworkshopfiles/) 并同意法律协议。将链接中的 替换为你的 Steam ID。
