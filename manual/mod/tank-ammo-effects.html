    坦克炮弹与弹道、命中特效

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    先完成主炮配置。本例用 SDK 内的 76 mm AP 教学弹，把弹种数据、游戏内弹道和效果资源分别核对。

    1. 创建并绑定一发可试射的弹药

    1. 在 Project 找一份已能开火的 Penetrate Bullet，按 Ctrl+D 复制。也可在 Create 的装甲纷争炮弹分类下选 Penetrate - 穿甲弹，然后核对同类型样例。用明确的文件名，保持 warhead 为 AP。
    2. 在新资产的 Inspector 填入下表。先保存，再把资产拖入当前主炮实际读取的 弹药数组。有共享主炮时在对应的 SharedGunData 上替换。弹药切换后重打包，并确认测试车使用最新包。
    3. 准备多种弹药时，为每种弹分别创建资产，给列表中的弹药配置易区分的名称和图标。
    字段 教学弹数值和作用
    caliber 76 mm，用于口径相关计算。
    velocity 650 m/s，决定出膛速度。
    gravityDamper 9.8 m/s²，控制弹道下坠。
    damage 100，是血条模式中伤害计算的基础值。
    penetration 90 mm，是该穿甲弹的基础穿深。实际结果还看命中角度和距离。
    isDeclineByDistance 教学弹启用随距离衰减。先做近距离基准测试，再比较远距离表现。
    maxCapability 0 表示沿用载具给出的上限。需要单独限制某弹种时填正数。

    模块模式同样使用这份炮弹资产，并读取其中的模块数据、弹体和穿甲相关字段。修改血条伤害后，模块损伤需另测。建议先保留工作样例的模块字段。

    2. 分配飞行和命中特效

    1. 在 Project 复制一份现有 BulletVFX，把副本拖到炮弹资产的 炮弹特效（bulletVFX）对象槽。
    2. 打开 BulletVFX，从对象池键下拉框设置下表中的条目。确认相应特效资源随包加载。
    3. 按需设置 isOverrideSprite 和 bulletSprite，使玩家能在 HUD 中识别该弹。炮口火焰和开火音效仍在火炮参数里配置。
    发生时机 对应字段
    出膛后随弹飞行 weaponProjectileEffect 与 overrideWeaponProjectileEffects
    打到地形 hitGround 与 overrideHitGrounds
    命中装甲 hitArmor 与 overrideHitArmors
    装甲跳弹 hitArmorRicochet 与 overrideHitArmorRicochets
    入水 hitWater 与 overrideHitWaters，水体交互设为可手动配置的类型时可见。

    新资源用对象池键配置。Inspector 中直接引用 GameObject 的 isOverrideWeaponProjectileEffect 与 overrideWeaponProjectileEffect 属于兼容旧资源的 Instantiate 路径。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${bullet}/bulletVFX",
      "value": "@asset:${vfx}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${bullet}/bulletVFX/name"
    },
    "expect": {
      "contains": "Tutorial_AP_Effects"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vfx}/hitGround"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vfx}/hitArmor"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vfx}/weaponProjectileEffect"
    }
  }
]

    3. 分别检查弹道和命中反馈

    进入载具测试场，从弹种栏选择新弹。先向近处靶车正面发射，核对弹道、命中记录和装甲反馈。再打地面、斜角装甲或水面，检查对应效果。比较远近两次穿深时，尽量使用同一块装甲和同一入射角。

    • 找不到弹种时，查看当前主炮的有效 Bullet Data，并核对是否重打包。
    • 有命中记录、缺少画面时，检查 BulletVFX 引用和对应的对象池键。
    • 想验证飞行表现时，在 MCP 靶场使用 range_fire 的 shell 模式。它会发射弹体。impact 直接执行命中逻辑，适用于单独核对损伤。
    点击展开 MCP 操作点击收起 MCP 操作

    "tool": "inspect",
    "arguments": {
      "path": "asset:${bullet}/velocity"
    },

      "contains": "650"

  }
]
