    用 InstaLOD Studio 减少网格面数

    中文 | English

    InstaLOD Studio 可以在把模型导入 Unity 之前，对它的副本做减面。下面的按钮名来自旧版操作图。当前安装和界面以软件官方指南为准。 InstaLOD Studio 入门

    1. 建立预设并导入

    1. 点击 New Profile，选择 Optimize (AutoLow) 模板，再点 Create Profile。这套预设已包含网格简化所需的流程。
    2. 在 File → Import Scene 导入模型副本。

    2. 选择减面幅度

    首次可以先用自动质量设置。要指定目标比例时，关闭 Automatic Quality，在 Percent Triangles 填一个起始值，例如 20。处理后的面数以实际工具结果为准。

    3. 执行并对比

    点击 Start 并等待处理结束。旧图中的具体样例从 6,340 面降到 758 面、从 10,451 个顶点降到 1,415 个顶点。从玩家可能看到的角度检查薄零件、板件和外形是否保留。

    4. 导出为新文件

    通过 File → Export Scene 另存为新文件，方便在不替换源模型的情况下比较结果。

    5. 导回 Unity 检查

    把输出先放到测试目录内。检查轮廓、材质分配、UV 和轴心。载具还要旋转炮塔、炮管或车轮，确认枢轴和方向仍然正确。有问题时调整减面参数再导出。
