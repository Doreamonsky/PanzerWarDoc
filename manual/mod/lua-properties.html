    配置 Lua 实例属性

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run lua-properties --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "script": "${fixture}/Example.lua",
    "prefab": "${fixture}/Tutorial_LuaProperties.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    用脚本的 Property 表声明默认值，再在 prefab 的 LuaBehaviorMono 上设置实例值。以下示例将 multiplier 的脚本默认值保持为 2，只调整 prefab 的值。

    1. 声明数值属性

    保存 Example.lua，让导入器生成行为资产及数值定义。

    Behavior()
Property = { multiplier = { type = "number", value = 2 } }

local Example = class("Example")

return Example
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/WriteAllText",
      "args": [
        "${script}",
        "Behavior()\nProperty = { multiplier = { type = \"number\", value = 2 } }\n\nlocal Example = class(\"Example\")\n\nreturn Example\n"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/ImportAsset",
      "args": [
        "${script}",
        "ForceSynchronousImport"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. 同步定义

    将行为资产赋给 LuaBehaviorMono 的「行为脚本」。点「同步变量属性定义」为当前实例补上 multiplier。新条目从脚本读取 2。同步时会保留同名条目的现有值。

    点击展开 MCP 操作点击收起 MCP 操作

    清空列表的步骤仅用于重置教学样例。同步现有 prefab 时保留自己的实例值。

    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${prefab}",
        "mode": "create",
        "component": "ShanghaiWindy.Core.Lua.LuaBehaviorMono",
        "references": [
          {
            "property": "luaBehavior",
            "asset": "${script}",
            "type": "ShanghaiWindy.Core.Lua.LuaBehaviorScript"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${prefab}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.Lua.LuaBehaviorMono",
        "values": {
          "instanceLuaProperty": {
            "numberProperties": []
          }
        }
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "asset:${prefab}/LuaBehaviorMono/instanceLuaProperty/OverrideNilPropertyFrom",
      "args": [
        "@asset:${script}/luaProperty"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.PrefabUtility/SavePrefabAsset",
      "args": [
        "@asset:${prefab}"
      ]
    },
    "expect": {
      "contains": "--- GameObject ---"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${prefab}/LuaBehaviorMono/instanceLuaProperty/numberProperties/0/value"
    },
    "expect": {
      "contains": "(Single) 2"
    }
  }
]

    3. 改实例值

    在「实例属性」下展开数值列表，找到 multiplier，将它的值改为 3.5 并保存 prefab。序列化路径为 instanceLuaProperty.numberProperties。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${prefab}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.Lua.LuaBehaviorMono",
        "values": {
          "instanceLuaProperty": {
            "numberProperties": [
              {
                "variableName": "multiplier",
                "value": 3.5
              }
            ]
          }
        }
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    4. 核对同步结果

    再次同步。确认脚本资产的默认值为 2，当前 prefab 的实例值仍为 3.5。行为初始化时会将实例属性赋给 Lua 类实例。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "asset:${prefab}/LuaBehaviorMono/instanceLuaProperty/OverrideNilPropertyFrom",
      "args": [
        "@asset:${script}/luaProperty"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.PrefabUtility/SavePrefabAsset",
      "args": [
        "@asset:${prefab}"
      ]
    },
    "expect": {
      "contains": "--- GameObject ---"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${prefab}/LuaBehaviorMono/instanceLuaProperty/numberProperties/0/variableName"
    },
    "expect": {
      "contains": "(String) multiplier"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${prefab}/LuaBehaviorMono/instanceLuaProperty/numberProperties/0/value"
    },
    "expect": {
      "contains": "(Single) 3.5"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${script}/luaProperty/numberProperties/0/value"
    },
    "expect": {
      "contains": "(Single) 2"
    }
  }
]
