    合并 PBR 遮罩贴图

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run merge-texture-channels
    1. 在模组 SDK 的 GM 编辑器 → 合并遮罩贴图 打开 Remap PBR Masks。
    2. 按槽位填入 metallic、occlusion、smoothness。手里只有粗糙度图时，将它放入 smoothness 槽，勾选 Is Roughness。
    3. 点击 Create Mask Map 并保存 PNG。输出使用 metallic 贴图的尺寸，未指定 metallic 时使用 512 × 512。
    输出通道 读取内容
    R metallic 的红色通道
    G occlusion 的绿色通道
    B 0
    A smoothness 的红色通道，经工具的平滑度转换。使用 roughness 时转换后再反相
    点击展开 MCP 操作点击收起 MCP 操作
