    安装 TortoiseGit

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run install-tortoisegit
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {},
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:System.Environment/GetEnvironmentVariable",
        "args": [
          "ProgramFiles"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [A-Z]:\\\\"
      },
      "capture": {
        "programFiles": {
          "regex": "\\(String\\) ([^\\r\\n]+)"
        }
      }
    }
  ]
}

    TortoiseGit 为 Windows 资源管理器提供 Git 操作。先 安装 Git for Windows。

    1. 打开 TortoiseGit 官方下载页 https://tortoisegit.org/download/。
    2. 确认自己的 Windows 是 x64 还是 ARM64，然后下载对应架构的安装包。
    3. 运行安装程序并按提示完成安装。
    4. 如需中文界面，再下载同架构的语言包，并选择与已装版本一致的安装包。
    5. 在资源管理器里右键任意文件夹，菜单中应出现 TortoiseGit 项。
    6. Windows 11 的右键菜单可能收在“显示更多选项”下，展开后即可看到。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${programFiles}\\TortoiseGit\\bin\\TortoiseGitProc.exe"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    MCP 检查默认安装目录中的程序。安装和右键菜单由读者验证。
