    旧版多炮塔配置

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run multi-turret-legacy --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "source": "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar",
    "vehicleData": "${fixture}/Tutorial_NativeVehicleData.asset",
    "vehicleText": "${fixture}/Tutorial_NativeText.asset",
    "vehicleInfo": "${fixture}/Tutorial_NativeVehicleInfo.asset",
    "packModel": "${fixture}/Tutorial_NativePackModel.prefab",
    "vehicleName": "Docs-Legacy-Turret-${runId}",
    "vehicleGuid": "205563420ee989807e2${runId}",
    "cooked": "${fixture}/205563420ee989807e2${runId}_pre.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}

    现有载具可以继续使用 VehicleTextData → 旧版多炮塔系统。新配置可先查看同一 Inspector 中的新版多炮塔系统。

    1. 在模型中为副炮准备三层节点。示例中 TutorialSubTurret 位于主炮塔 Turret 下，再依次嵌套 TutorialSubGun、TutorialSubDym。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "${source}_Model.prefab",
        "${packModel}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${packModel}",
        "mode": "update",
        "component": "UnityEngine.Transform",
        "children": [
          "Turret/TutorialSubTurret/TutorialSubGun/TutorialSubDym"
        ],
        "child": "Turret/TutorialSubTurret/TutorialSubGun/TutorialSubDym"
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${packModel}/Turret/TutorialSubTurret/TutorialSubGun/TutorialSubDym/name"
    },
    "expect": {
      "contains": "TutorialSubDym"
    }
  }
]
    1. 在 MultiFireSystemData 添加一项。turretPath 从模型根节点开始，gunPath 从副炮塔开始，dymPath 从副炮开始。示例依次填 Turret/TutorialSubTurret、TutorialSubGun、TutorialSubDym。
    2. 将 ffPointOffSet 和 effectStartOffSet 设为从炮管原点沿局部 +Z 的距离。为该项配置开火和炮塔参数，可绑定对应的共享参数资产。
