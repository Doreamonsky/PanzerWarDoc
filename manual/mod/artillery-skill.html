    本教程在独立乘员资产中配置火炮支援。运行时技能只面向离线载具；本次验证覆盖编辑器资产和教学包，不包含游戏内齐射效果。

    1. 创建技能槽

    在 CrewData.upgradableSkillContents 中添加一组 skills，把该条的 friendshipRequirement 设为 0。crewSkillRef 选择 CrewSkillBuff，再在其 crewSkill 中选择 ArtillerySkillConfig。这是嵌套配置，不是独立 ScriptableObject。

    配置的 version 必须等于 GetVersion()，当前为 3，否则技能会被判定为不兼容。配方查询并写入当前版本；乘员的基础配置和解锁条件见指挥官教程。

    教学乘员复用 Aino 的有效头像引用，原始乘员保持不变；正式内容请配置自己的头像。头像引用是后续打包的前提。

    2. 设置冷却

    把 initialCdType 设为 Ready、coolDownTime 设为 20 秒。Ready 表示初始就绪，NotReady 从零开始冷却；CustomRatio 才显示 customInitialCdRatio，用于设置已完成的冷却比例。释放成功后冷却进度重置。

    在外层 CrewSkillBuff 填技能名与简介，分别添加需要的翻译。在技能配置内，可按需开启 hasSkillReadyVoice 和 hasSkillReleaseVoice，填写对应 FMOD 事件 GUID。 FMOD 配置

    3. 配置一组炮弹

    展开 spawnInfos，添加一项：dispersion = 10、attackAngle = 45、count = (2,4)、timeDelay = (0,2)、fromDistance = 800。发数使用整数随机区间，上界不包含，因此示例产生 2 或 3 发；每发独立抽取约 0–2 秒的延时。

    为这项填写 artilleryBulletData，并在同一个 SafeRef 的 safeRefAssetProvider.assets 中设置相同的 loadName 和实际 BulletData 引用。本例复制现有 105-HE 弹药，用复制资产的 GUID 作查询键。运行时代码按键匹配引用，不会把显示名或文件路径自动转换为弹药。

    选中复制出来的弹药资产。核对弹头是 HE，在 Inspector 检查 Bullet VFX 引用，再在爆炸参数区核对 Explosion Range。复制其他弹药时，先看这些字段是否符合游戏内预期效果，再绑定到技能。

    技能要求本地玩家的相机射线命中目标。生成点由命中点加上绕全局 Z 轴旋转后的 X 向偏移计算，45° 会同时改变水平位置与高度；它不是沿相机朝向的水平偏移。dispersion 随后交给弹体。

    4. 保存、检查与打包

    保存 SafeRef 配置，读回版本和序列化数据，将乘员加入教学打包管线。本配方实际构建 Windows 教学包并检查 ZIP、清单和 sidecar；不安装或发布它。

    游戏内验证还需要离线对局、启用指挥官增益、有效的乘员选择与目标命中。弹道、特效和声音尚未实测。
