    在载具的模型 prefab 中，使用 VehicleAttachmentMonoComponent 的通用挂载槽配置外置弹药模型和防浪板。载具打包时会从模型层级收集这些挂载。

    1. 连接外置弹药模型

    在模型 prefab 内添加一个 VehicleAttachmentMonoComponent，将 Attachment Slot Type 保持为 Universal。展开「插槽」，在类型下拉菜单中选择 VehicleAmmoVisualAttachment。

    1. 将「弹药可视化类型」设为 Show Hide。
    2. 将「连接炮管唯一 ID」填为对应火炮模块的 GUID。图中是教学占位值。
    3. 把 prefab 中的外置弹药物体拖到「显示模型」。本例物体为 ExternalShell。

    如需让模型跟随发射出的弹体，可选 Follow Bullet。此时才会显示跟随偏移和指定开火点的字段。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "create",
        "component": "ShanghaiWindy.Core.VehicleAttachmentMonoComponent",
        "child": "AmmoVisual",
        "children": [
          "AmmoVisual",
          "ExternalShell",
          "WaveShield",
          "ShieldPivot"
        ],
        "managedReferences": [
          {
            "property": "slot.attachment",
            "type": "ShanghaiWindy.Core.VehicleAmmoVisualAttachment",
            "values": {
              "ammoVisualType": 0,
              "connectGunGuid": "00000000000000000000000000000001"
            }
          }
        ],
        "references": [
          {
            "property": "slot.attachment.visualModel",
            "child": "ExternalShell",
            "component": "UnityEngine.GameObject"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    2. 设置防浪板

    在模型内另加一个通用挂载，选择 VehicleWaveShieldAttachment。将防浪板的转轴指定给「防浪板」字段。本例使用 ShieldPivot，将「默认角度」设为 0°、「激活角度」设为 35°、「角速度」设为每秒 30°。

    在场景视图可以通过红线和黄线检查两种姿态。船只控制器的启用状态决定运行时防浪板转向哪个姿态。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.VehicleAttachmentMonoComponent",
        "child": "WaveShield",
        "managedReferences": [
          {
            "property": "slot.attachment",
            "type": "ShanghaiWindy.Core.VehicleWaveShieldAttachment",
            "values": {
              "defaultAngle": 0,
              "activateAngle": 35,
              "angleSpeed": 30
            }
          }
        ],
        "references": [
          {
            "property": "slot.attachment.waveShieldTransform",
            "child": "ShieldPivot",
            "component": "UnityEngine.Transform"
          }
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    4. 重新生成载具并打包

    在 VehicleData 中确认 MainModel 引用了修改后的模型，再重新生成打包 prefab。检查防浪板挂载是否生成了 DefaultAngle 和 ActivateAngle 两个姿态节点，随后用链接了这辆车 VehicleInfo 的构建管线生成模组包。数据和管线的创建见载具基础配置。

    配方在完整载具副本上核对姿态节点、外置弹药引用及 Windows 教学包。游戏中的动作与显示效果留待实机查看。
