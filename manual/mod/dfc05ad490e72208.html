    11.2 Build 打包

    Press Ctrl + G to open the tool. And, create a DIYDataBuildAssemble

    Ctrl + G 打开工具。然后，创建 DIYDataBuildAssemble

    Add DIY equipment generated in Step.2 into BuildMap.

    将你在步骤.2 中生成的 DIY 配件加入到打包文件中。

    Add this file to your ModBuildPipline. And you can package it.

    将此文件添加到你的 ModBuildPipline 文件中，即可正常打包。
