    占点模式配置

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run capture-mode-config

    占点模式配置描述占点战斗使用的区域、占领点、每个区域的出生点以及区域连通关系。它是一份 CaptureZoneModeConfig JSON，存放在配置根目录下，出包时被打包成二进制配置数据。

    1. 准备地图场景

    1. 先完成 设置 Steam 游戏资源路径，让编辑器能读取游戏侧的 LuaProject 资源。
    2. DIY 地图按 导入 DIY 地图 把 YAML 导入基础场景；官方或其他非 DIY 地图只需在编辑器中打开对应场景。
    3. 编辑时保持场景打开。点位放置和 刷新位置 (NavMesh) 按钮会采样当前场景的 NavMesh，所以地图必须已经烘焙好寻路数据。

    2. 创建配置

    1. 打开 Framework - 框架 → 2. Config - 配置文件。
    2. 在创建表单中选择 配置文件（Config Path）。下拉列表来自框架设置中保存的配置路径，这个值同时决定配置会出现在哪个目录树里。
    3. 配置类型选择 CaptureZoneModeConfig。
    4. 填写 文件名称 并点击 创建（Create Config）。文件名为空只会弹出错误提示，所以要先填好。文件名不需要扩展名。
    5. 工具会写入 <配置根目录>/CaptureZone/<名称>.json，并在内部生成一个新的 GUID。不要从其他文件复制 GUID。

    创建出的对象包含以下字段，用途各不相同：

    字段 用途
    captureZoneName 内部标识。请使用独特且唯一的 ID，不要与其他配置重复。
    displayName 面向玩家的本地化显示名称。
    mapGuid 地图的运行时标识。普通地图用 MapData 的 GUID，DIY 地图用 Defined Name。
    backgroundCameraTransformInfo 可选的地图背景视角相机位置与旋转。

    编辑器菜单树会把文件显示为 <配置路径目录>/CaptureZone/<文件名>，选中它即可打开该文件的占点编辑器。

    3. 设置地图 GUID 与背景相机

    1. 在区域编辑器中，地图 Guid 一行显示当前值（为空时显示 —）。点击 使用当前场景 可从当前场景可发现的地图数据中填入 GUID。
    2. 普通地图核对写入值与 MapData 的 GUID 一致。DIY 地图填写导入 YAML 中的 Defined Name（definedName）原值，保留空格和标点。游戏按这个名称注册 DIY 地图。
    3. 背景相机是可选的。把 Scene 视图调整到想要的构图后点击 设置背景相机，会保存该相机的位置与旋转。模式不需要背景视角时保持为零即可。

    4. 添加占领区域

    1. 点击编辑面板或场景浮层上的 + 新区域。新区域会添加在当前场景视图指向的位置，pointName 为占位值（Zone_<n>），半径默认为 30。
    2. 点击区域标签选中它，然后填写：
      • pointName —— 必须唯一。区域连通关系按这个字符串解析区域，改名后要同步更新连通项。
      • 位置 与 范围 —— 占领点位置和占领圈半径。
      • 初始队伍拥有者 —— 初始归属队伍，中立则选 none。
    3. 用选中区域的 +Pt / -Pt 构建边界。zonePoints 是定义区域范围的边界多边形，它与占领点的位置、半径是两套独立数据。边界点应放在可行走地面，并用 刷新位置 (NavMesh) 和 合并附近点 吸附、整理。
    4. 按同样方式添加其余区域。小型地图通常 2-3 个区域就够，不必为了填满数组硬加区域。

    5. 添加每个区域的出生点

    1. 选中区域后点击 显示出生点（旧版本按钮名为 Edit），再点 + 添加出生点标记。
    2. 会出现带编号的标记。点击标记选中该出生点，用场景手柄移动或旋转它。数值保存在该区域的 spawnTransformInfos 中，也可以在序列化字段里直接编辑。
    3. 请选用清晰可驾驶的位姿：位于地面或其附近、朝向符合设计方向、不要卡进墙体、道具或其他载具。刷新位置 (NavMesh) 会把出生点吸附到寻路网格并清零俯仰与翻滚，但仍需人工确认视角。
    4. 完成后点击 隐藏出生点，让场景视图更清爽。

    6. 添加区域连通关系

    1. 在 zoneChains 中添加条目，A 与 B 填写与区域一致的 pointName 字符串。
    2. 只连接地图设计真正允许相连的相邻区域。运行时 CaptureZoneGameMode.Setup.cs 会把 fromZone 作为 toZone 的前置相邻区域，所以每条记录是有方向的。只有地图设计确实允许双向通行时，才补上反方向条目。
    3. 检查所有连接：名称必须能解析到已有区域。解析失败的名称在运行时会被直接跳过，编辑器也不会为它绘制连线，所以拼写错误只会让连接静默消失。

    7. 保存、打包与测试

    1. 保存配置。
    2. 在地图模组的构建管线中，把保存的占点 JSON 加到 Config file。选择目标平台并构建模组包。管线会把 JSON 转换为配置数据并随 .modpack 交付。地图场景仍由地图构建流程提供。
    3. 本地只导出配置时，可用 打包所有配置（Pack All Configs）。它重建 Build/Config，占点配置输出到 Build/Config/capturezone/<配置 GUID>.bytes。
    4. 安装刚构建的模组，在目标地图运行一次占点战斗。核对占领区、出生点与区域推进顺序。

    本例给 Tutorial Town 配置 Depot 和 Ridge 两个区域，连通方向为 Depot 到 Ridge。回放生成并核对本地 .bytes 文件。
