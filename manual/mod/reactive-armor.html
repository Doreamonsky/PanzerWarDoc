    配置反应装甲

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run reactive-armor --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "plate": "${fixture}/Tutorial_ReactivePlate.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    在载具伤害模型的 HitBox 上配置反应装甲。反应装甲会在有效命中点附近记录已消耗区域。

    1. 选择 HitBox

    打开载具的伤害模型 prefab，选中作为反应装甲的装甲部件。确认该物体有 HitBox 组件。教学配方新建一个独立的装甲样例。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${plate}",
        "mode": "create",
        "component": "ShanghaiWindy.Core.HitBox"
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    2. 设置反应装甲参数

    将「装甲类型」设为「反应 - Reactive」。展开「反应装甲」，将「反应装甲区块大小」设为 0.5，「反应装甲最大防御穿深厚度」设为 200。本例使用源码默认值。

    区块大小是从已激活命中点量起的距离。后续命中落在该范围内时，该位置返回的装甲值为 0。未消耗位置使用配置的反应装甲值，是否击穿还取决于游戏的穿深计算。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${plate}",
        "mode": "update",
        "component": "ShanghaiWindy.Core.HitBox",
        "values": {
          "hitBoxType": 3,
          "reactiveArmorSize": 0.5,
          "reactiveMaxProtectPenetration": 200
        }
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  }
]

    3. 保存并核对

    保存 prefab，重新核对装甲类型和两个数值。配方验证了编辑器保存回读。区块消耗、重复命中及修复应在游戏中检查。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${plate}/HitBox/hitBoxType"
    },
    "expect": {
      "contains": "ReactiveArmor"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${plate}/HitBox/reactiveArmorSize"
    },
    "expect": {
      "contains": "(Single) 0.5"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${plate}/HitBox/reactiveMaxProtectPenetration"
    },
    "expect": {
      "contains": "(Single) 200"
    }
  }
]
