    制作载具瞄具模组

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run sight-mod --capture
    点击展开 MCP 操作点击收起 MCP 操作

    1. 在 Unity 的 Create 菜单创建 UserSightData，填写显示名并选择密位制。
    2. 在 Ballistics 添加一组弹道。在 crosshairDistances 中为每条刻线填写 range（米）、number（旁边的数字）和 notchSize（线长调整值）。横向尺度 crosshairHorRanges 使用 mil。
    3. 需要自定义准星时，关闭对应的水平与垂直中心线，再添加自己的线条。

    1. 把 UserSightData 加入构建管线。要作为载具默认瞄具，将同一资源赋给 TankFireParameter.customSightData。使用共享开火数据的载具在共享数据中设置。
    2. 构建和安装后进游戏检查。游戏依次查找玩家为该载具设置的覆盖、载具自带的瞄具和全局默认瞄具。
