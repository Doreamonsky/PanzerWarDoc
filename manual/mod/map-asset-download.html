    地图工程与资源入口

    中文 | English

    用公开 SDK 制作自己的地图

    1. 按项目初始化下载正式 SDK ZIP，用 Unity Hub 打开 UnityProject。
    2. 在 Project 窗口查看 Assets/Template-Scene。按地图向导创建自己的场景。
    3. 要先验证打包环境，在 Assets/ModManager 选 BuildPipline-Template-Blank.asset 构建链接资源，再选 Template-Blank-Scene.asset 打包。Windows 和 Android 分别构建，安装与游戏平台相同的 .modpack。 多平台打包

    维护官方地图和 DIY 配件

    有权限的维护者从官方模组仓库获取源码，保留 Projects 和 Packages 的相对目录结构。按官方资源协作流程拉取所需 Git LFS 文件，打开 Projects/Maps。该工程的 Packages/manifest.json 所列本地 UPM 依赖从同一仓库解析。 官方模组仓库

    要找的内容 仓库目录
    官方地图 Packages/Maps/<地图包>，例如 Packages/Maps/Provisional
    DIY 地图物品 Packages/Maps/DIYBuildings、Packages/Maps/DIYJapaneseBuildings、Packages/Maps/DIYOfficial
    地图共用依赖 Packages/Maps/Shared 和地图包各自 package.json 声明的依赖

    在 Unity 的 Project 窗口从 Packages 展开上述包，编辑场景和其素材时保留 .meta。提交前新建工作分支，用 git status 逐项核对改动的包、依赖和 .meta。涉及共用资源时，也要核对该资源的上游来源，再提交和请求评审。 官方资源协作流程

    查找旧工程中的路径

    旧资料中的 OfficialURPMaps、com.shanghaiwindy.urpmaps/Scenes 和 com.shanghaiwindy.diymapconfigs 属于迁移前布局。旧 GitLab 的载具、地图、公共资源三个仓库曾要放在同一父目录。查找历史资产时可用这些名字定位旧记录。当前官方地图和 DIY 配件都从上面的统一仓库路径查找。
