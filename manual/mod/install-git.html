    安装 Git

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run install-git
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {},
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:System.Environment/GetEnvironmentVariable",
        "args": [
          "ProgramFiles"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [A-Z]:\\\\"
      },
      "capture": {
        "programFiles": {
          "regex": "\\(String\\) ([^\\r\\n]+)"
        }
      }
    }
  ]
}

    使用 Git 克隆模组工程时需要 Git for Windows。使用 官方 SDK ZIP 可以直接打开工程。

    步骤

    1. 从 Git for Windows 官方页 下载适合 Windows 架构的安装包。

    2. 运行安装程序，完成后打开一个新终端。

    3. 运行以下命令。看到版本号表示终端能调用 Git。

      git --version
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {

      "args": [

      "contains": "(Boolean) True"
    }
  }
]

    如果要用 Git 克隆 SDK

    用 Git 克隆 SDK 前，先检查 Git LFS。

    git lfs version

    克隆后在 SDK 工程的仓库目录执行以下命令，获取大文件。

    git lfs pull

    MCP 检查默认安装位置的程序。下载、安装和克隆由读者执行。
