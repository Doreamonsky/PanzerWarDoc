    设置 Steam 游戏资源路径

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run set-steam-game-folder --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "sampleLuaProject": "${fixture}/LuaProject"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    },
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:System.IO.Directory/CreateDirectory",
        "args": [
          "${fixture}/LuaProject/resources/windows/default"
        ]
      },
      "expect": {
        "contains": "DirectoryInfo"
      }
    },
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:System.IO.File/WriteAllText",
        "args": [
          "${fixture}/LuaProject/main.lua",
          "return {}\n"
        ]
      },
      "expect": {
        "contains": "OK:"
      }
    }
  ]
}

    1. 找到 Steam 安装目录里的 LuaProject

    在 Steam 的游戏条目中浏览本地文件。打开游戏安装目录中的 dlc/LuaProject，确认里面有 main.lua 和 resources/windows/default。

    点击展开 MCP 操作点击收起 MCP 操作

    用目录标记核对教学样例。Steam 的本地文件菜单由读者打开。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${sampleLuaProject}/main.lua"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.Directory/Exists",
      "args": [
        "${sampleLuaProject}/resources/windows/default"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  }
]

    2. 在编辑器里绑定目录

    打开 Framework - 框架 → 0. Home Page。首次绑定时，在 Steam 游戏路径 输入找到的 LuaProject 路径，或点击 浏览 选中该文件夹并确认。编辑器会把路径写入 Assets/EditorStorage.json。绑定后，首页显示试车场等快捷入口。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.EditorStorage/Info/luaProjectFolder"
    },
    "expect": {
      "contains": "(String)"
    }
  }
]
    点击展开 MCP 操作点击收起 MCP 操作

    保存当前工程的设置。将 ${steamLuaProject} 替换为实际的 LuaProject 绝对路径；日常回放不写入。

    [
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.EditorStorage/Info/luaProjectFolder",
      "value": "${steamLuaProject}"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.EditorStorage/Save",
      "args": []
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.EditorStorage/Info/luaProjectFolder"
    }
  }
]
