    配置水陆两栖载具

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run amphibious-vehicles --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "vehicle": "${fixture}/Tutorial_AmphibiousVehicle.asset",
    "engine": "${fixture}/Tutorial_ShipEngine.asset",
    "buoyancy": "${fixture}/Tutorial_ShipBuoyancy.asset",
    "model": "${fixture}/Tutorial_AmphibiousBody.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    从一辆已有地面控制的载具开始。下面保留地面控制，并添加船只控制器。

    1. 打开两栖控制

    在 VehicleTextData 的「移动」页签展开「船只参数」。保持「是否完全由船只控制器接管载具」关闭，勾选「是否启用船只控制器」。将「自动切换船只控制器方式」设为「当重心被淹」。

    该选项会在车轮离地且重心入水时切换到船只控制，恢复接地时切回地面控制。全程使用船只控制的载具可改用 isShip。只需被动水面交互的载具可保持两项关闭，使用单独的 PassiveWaterInteractParameter。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar_VehicleTextData.asset",
        "${vehicle}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/isStationary",
      "value": "false"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/isShip",
      "value": "false"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/isShipControllerEnabled",
      "value": "true"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/autoSwitchShipControllerType",
      "value": "WhenCenterOfGravityDrown"
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. 准备螺旋桨路径、引擎和浮力

    在载具模型 prefab 中布置螺旋桨节点，把相对模型根节点的路径添加到「螺旋桨路径」。本例使用 MainBody/Propeller。

    在 Project 窗口打开 Create > A Panzer War - 装甲纷争 > G Ground Vehicle - 地面载具 > Shared Data - 共享数据，创建 Ship Engine - 船舶引擎 和 Ship Buoyancy - 船舶浮力 资产。示例引擎的 maxSpeedInKnots 为 12，示例浮力的 buoyancyObjectLength 为 6。回到「船只参数」，将两个资产分别赋给「引擎数据」和「浮力数据」。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "prefab_edit",
    "arguments": {
      "json": {
        "path": "${model}",
        "mode": "create",
        "component": "UnityEngine.Transform",
        "children": [
          "MainBody",
          "MainBody/Propeller"
        ]
      }
    },
    "expect": {
      "equals": {
        "ok": true
      }
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.SharedShipEngineData)",
        "${engine}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.SharedShipBuoyancyData)",
        "${buoyancy}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${engine}/maxSpeedInKnots",
      "value": "12"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${buoyancy}/buoyancyObjectLength",
      "value": "6"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/propellerPointPaths",
      "value": "[\"MainBody/Propeller\"]"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/sharedShipEngineData",
      "value": "@asset:${engine}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/sharedShipBuoyancyData",
      "value": "@asset:${buoyancy}"
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    3. 保存并核对

    保存后核对地面控制仍使用 TrackController、船只控制已启用、两个共享资产均已绑定，并确认螺旋桨路径能在模型中找到。实际水线、推进和离岸切换取决于完整载具及测试地图。本例验证了编辑器中的配置和模型路径。

    点击展开 MCP 操作点击收起 MCP 操作

    },
    "expect": {
      "contains": "True"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/autoSwitchShipControllerType"
    },
    "expect": {
      "contains": "WhenCenterOfGravityDrown"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vehicle}/ShipControllerParameter/maxSpeedInKnots"
    },
    "expect": {

    }
  },
  {

    "arguments": {
