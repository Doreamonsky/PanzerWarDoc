    设置模组环境

    中文 | English

    先按自己的情况选择路线，具体步骤放在对应教程，本文只做入口。

    第一次安装

    1. 从 GitHub Releases 下载正式 SDK ZIP，并按下载参考校验哈希、完整解压。二进制文件随发行包提供，无需 Git。
    2. 按版本要求安装工程声明的 Unity 版本和目标平台模块。
    3. 按项目初始化在 Unity Hub 打开 UnityProject，保留同级 Packages，导入完成后构建随包模板验证环境。

    用 Git 维护工程

    1. 按下载与克隆说明安装 Git LFS，克隆仓库并完成 git lfs pull。
    2. 用工程 ProjectVersion.txt 声明的版本打开 UnityProject，按项目初始化完成导入。
    3. 更新 SDK 时解压或检出到新目录，不要用旧 SDK 的 Packages 覆盖新包，再按迁移步骤带走自己的资源。

    迁移旧工程

    1. 把个人资源连同 .meta 文件、mod package 和 build pipeline 一起迁入新版 SDK，保留原有资源引用和 mod 标识。
    2. 逐步确认引用有效，重新构建链接资源并打包测试。详细规则见迁移指南。
    3. 本地 GameHub 有创建工程入口时，也可沿用 GameHub 流程。
