    设置模组环境

    中文 | English

    1. 第一次制作模组，从 GitHub Releases下载正式 SDK ZIP，完整解压。二进制文件随发行包提供。要使用 Git 更新时，按下载与克隆说明安装 Git LFS 并拉取文件。
    2. 在 Unity Hub 打开里面的 UnityProject。保留其同级 Packages，按项目初始化导入并构建随包模板。
    3. 已有工程或旧工程的个人资源按迁移指南迁入新版 SDK。本地 GameHub 有创建工程入口时，也可沿用 GameHub 流程。
