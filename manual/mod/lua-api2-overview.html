    Lua API 2 概览

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run lua-api2-overview

    1. 检查客户端版本

    GAME_API_VERSION 为 2 或以上时使用本节接口。兼容旧客户端可用 (GAME_API_VERSION or 1) >= 2 判断。在编辑器检查客户端 API 版本，并用 xLua 验证版本分支。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.API.GameAPI/GetApiVersion",
      "args": []
    },
    "expect": {
      "contains": "(Int32) 2"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.AssetBundleManager/LuaEnv/DoString",
      "args": [
        "local function api2(v) return (v or 1) >= 2 end\nassert(not api2(nil) and not api2(1) and api2(2) and api2(3))\nassert(CS.ShanghaiWindy.Core.API.GameAPI.GetApiVersion() == 2)\nreturn \"API version verified\"\n",
        "manual-api-version",
        "null"
      ]
    },
    "expect": {
      "contains": "API version verified"
    }
  }
]

    2. 选择回调和查询

    • 用 OnStarted 处理脚本启动，用 OnVehicleReady 获取装配完成的载具。车库也可能触发 OnVehicleReady，用 VehicleAPI.IsGarage 判断场景。详见 载具初始化时序。
    • 用 VehicleAPI.CreateQuery 创建并复用战场查询，用 TransformAPI.FindDeep 或 FindAllDeep 在初始化缓存在模型上找到的节点。读取接口按各签名处理失败值。C# 数组和目标索引从 0 开始。
    • 将 self.script 传给事件订阅，在行为销毁时自动清理。武器、模块、起落架和雷达状态都提供事件。
    • 用 self.script:SetUpdateInterval(seconds) 调整更新间隔。全靠事件的行为可用 SetUpdateEnabled(false)。OnGUI 中绘制已有结果。
    • 角度通常用度，距离用米。速度的单位由接口声明，例如 GetSpeedKmh 返回千米/时。
