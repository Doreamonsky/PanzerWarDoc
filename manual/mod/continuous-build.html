    官方模组仓库

    1. 在模组仓库的 GitHub Actions 中打开 Build modpack。填写受影响的 packs 与目标 platform。
    2. 验收构建时设置 publish=none，留空 release。工作流会裁剪依赖、拉取相应的 LFS、构建并验证。
    3. 从该次运行的 Artifacts 下载 .modpack 与同名 .modpack.json，核对平台、GUID 和版本。

    SDK 工程中的本地构建清单

    1. 在 ModPackageBuildPiplineData 中引用 ModPackageData 和要打包的资源。
    2. 在 JSON 的 infos 中新增条目。将管线资源的路径填到 modNames，将活动平台与专用输出目录写进 copyInfo 的 platform、dstDir。先创建输出目录。设置 isPackage=true 生成归档，让 isCleanDstFolder=false 保留目录内容。
    3. 从自有编辑器入口调用 ShanghaiWindy.Editor.Utility_BuildPipline.BuildPiplineManifest(path)，检查目标目录的包。需要 sidecar 时调用 Frontend.Editor.ModPackageWorkshopMeta.WriteSidecar(archivePath)。
