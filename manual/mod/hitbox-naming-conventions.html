    伤害模型命名规则

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run hitbox-naming-conventions --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "external": "${fixture}/Tutorial_ExternalSource.prefab",
    "internal": "${fixture}/Tutorial_InternalSource.prefab",
    "armor": "${fixture}/Tutorial_ImportedArmor.prefab",
    "module": "${fixture}/Tutorial_ImportedModule.prefab"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "regex": "\\(String\\) [a-f0-9]{32}"
      }
    }
  ]
}

    伤害模型编辑器会从网格节点名读取装甲和内构参数。以下示例适用于载具的 VehicleHitBox 资源。

    2. 生成外部装甲

    外部名字的第二段必须是整数厚度。名称中包含 Inter 时导入为间隙装甲，包含 React 时导入为反应装甲。

    节点名 装甲类型 厚度
    Plate_100 普通 100
    Plate_100_Inter 间隙 100
    Plate_100_React 反应 100

    在伤害模型编辑器中点「外部装甲模型」。生成后将装甲移动到对应的父节点。需要单独配置反应区块时，见反应装甲。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.VehicleHitBoxModelImport/ImportPrefab",
      "args": [
        "${external}",
        "${armor}",
        "false"
      ]
    },
    "expect": {
      "regex": "\\(String\\) [a-f0-9]{32}"
    }
  }
]

    3. 生成内部模块

    以 Transmission_120_15 为例，三段名称依次对应模块类型、耐久和模块装甲。类型名区分大小写，另外两段按数值读取并向上取整。请填写完整三段。

    在伤害模型编辑器中点「内部模块模型」，把生成的内构移到对应父节点。图中的编号对应节点名的三段。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.VehicleHitBoxModelImport/ImportPrefab",
      "args": [
        "${internal}",
        "${module}",
        "true"
      ]
    },
    "expect": {
      "regex": "\\(String\\) [a-f0-9]{32}"
    }
  }
]

    4. 保存并核对

    保存伤害模型 prefab，检查外部 HitBox 和 InternalModule 的字段。配方在隔离 prefab 中运行相同的导入处理，并核对了表中的三个装甲值，以及传动模块的耐久和装甲。

    点击展开 MCP 操作点击收起 MCP 操作
