    中文 | English

    2. 生成外部装甲

    外部名字的第二段必须是整数厚度。名称中包含 Inter 时导入为间隙装甲，包含 React 时导入为反应装甲。

    节点名 装甲类型 厚度
    Plate_100 普通 100
    Plate_100_Inter 间隙 100
    Plate_100_React 反应 100

    在伤害模型编辑器中点「外部装甲模型」。生成后将装甲移动到对应的父节点。需要单独配置反应区块时，见反应装甲。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.VehicleHitBoxModelImport/ImportPrefab",
      "args": [
        "${external}",
        "${armor}",
        "false"
      ]
    },
    "expect": {
      "regex": "\\(String\\) [a-f0-9]{32}"
    }
  }
]

    3. 生成内部模块

    以 Transmission_120_15 为例，三段名称依次对应模块类型、耐久和模块装甲。类型名区分大小写，另外两段按数值读取并向上取整。请填写完整三段。

    在伤害模型编辑器中点「内部模块模型」，把生成的内构移到对应父节点。图中的编号对应节点名的三段。

    模块类型代码

    代码 说明
    Transmission 传动
    Engine 引擎
    HeatSink 散热器
    OilTank 油箱
    Traversing 方向机
    Breech 炮闩
    Elevator 高低机
    Sighting 瞄准具
    AmmoShell 弹药架
    Crew 乘员
    InternalArmor 内部装甲
    Radiator 雷达（当前 Inspector 标签）
    AutoReloader 自动装填机
    OilPipline 滑油系统
    SurfaceControlRope 舵面控制钢索
    WingSurface 机翼

    模块命名示例

    示例仅用于说明格式，不代表推荐的数值平衡。

    • Transmission_120_15：传动部件，生命值 120，装甲 15。
    • AmmoShell_50_15：弹药架部件，生命值 50，装甲 15。若 Blender 因重名自动追加后缀，会得到 AmmoShell_50_15.001、AmmoShell_50_15.002 这类名称。导入器支持保留这个 Blender 重名后缀。

    乘员命名格式

    乘员同样以 Crew 作为模块代码，并在末尾写出角色代码；多个角色用下划线分隔：

    Crew_{HitPoint}_{ArmorValue}_{RoleCode}
Crew_{HitPoint}_{ArmorValue}_{RoleCode1}_{RoleCode2}

    可用的角色代码只有以下五个，必须保持精确拼写与大小写：

    • Crew_10_0_Commander_Gunner：同时承担指挥官与炮手角色。
    • Crew_10_0_Radioer：通讯员角色。
    • Crew_10_0_Reloader：装填手角色。Blender 重名时会生成 Crew_10_0_Reloader.001、Crew_10_0_Reloader.002 等后缀名称，后缀不代表角色变化。

    Driver 驾驶员
    Gunner 炮手
    Radioer 通讯员
    Reloader 装填手

    4. 批量设置内构血量

    1. 回到 VehicleHitBox，在总体的 HitPoint中设置总基准。原指南和当前 Inspector 使用以下建议值。
    2. 同类模块需要固定值时，在 Override Module Hit Points 加一项并选择模块类型。未添加覆盖的条目使用下方系数。
    3. 在伤害模型编辑器中点击自动设置模块血量，选中生成的 InternalModule 核对血量，再按 Ctrl+S 保存。
    载具等级 1–3 4–6 7–8 9–10 11–12 13–15
    基准 HP 50 100 200 300 350 380

    旧指南建议基准 HP 不超过 400。下表各列是对应基准 HP 的结果。普通模块按系数乘基准 HP，再按编辑器规则取整，例如 50 × 0.25 在当前 Unity 中得到 12。

    模块类型 系数 50 100 200 300 350 380
    Transmission, WheelOrTrack 0.4 20 40 80 120 140 152
    Engine, MainStructure 0.8 40 80 160 240 280 304
    HeatSink, Breech, Barrel, Elevator 0.25 12 25 50 75 88 95
    OilTank, Traversing, AmmoShell, InternalArmor 0.5 25 50 100 150 175 190
    Sighting, Radiator 0.2 10 20 40 60 70 76
    其他类型（乘员除外） 1 50 100 200 300 350 380

    乘员按 Crew Wear Type 取固定值。None 为 10、Vast 为 20、Alien 为 50、Huawei 为 100。

    点击展开 MCP 操作点击收起 MCP 操作

    验证真实命名解析器、重复后缀和自动血量使用的取整规则。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.AssetBundleManager/LuaEnv/DoString",

        "local U, C = CS.UnityEngine, CS.ShanghaiWindy.Core\nlocal go = U.GameObject.CreatePrimitive(U.PrimitiveType.Cube)\nlocal ok, failure = pcall(function()\n    local sample = go:AddComponent(typeof(C.InternalModule))\n    C.VehicleHitBoxImportUtil.SetInternalModuleViaName('AmmoShell_50_15.002', sample)\n    assert(sample.moduleType == C.EInternalModuleType.AmmoShell)\n    assert(sample.HitPoint == 50 and sample.internalArmor == 15)\n    C.VehicleHitBoxImportUtil.SetInternalModuleViaName('Crew_10_0_Commander_Gunner.001', sample)\n    assert(sample.moduleType == C.EInternalModuleType.Crew)\n    assert(sample.isCommander and sample.isGunner and sample.HitPoint == 10)\n    assert(U.Mathf.RoundToInt(50 * 0.25) == 12 and U.Mathf.RoundToInt(350 * 0.25) == 88)\nend)\nU.Object.DestroyImmediate(go)\nassert(ok, failure)\nreturn 'Duplicate names, role flags, and HP rounding verified'\n",
