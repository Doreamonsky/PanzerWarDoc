    22.7.2 用例：蓄力伤害加成 Example: Charged-Shot Damage Bonus

    装填完成后，主炮开始蓄力，伤害加成随时间增长，蓄满后为 +50%；开火后蓄力清零。

    Once reloading is complete, the main gun begins to charge. The damage bonus increases over time, reaching +50% at full charge; the charge resets to zero after firing.

    以前的写法是每次数值变化都移除旧 buff、再新建一个，每帧都在分配内存。BuffAPI.CreateValueBuff 创建一个数值可变的 buff：挂到属性上一次，之后只调用 SetValue，属性会原地刷新。

    The previous approach removed the old buff and created a new one for every numerical change, allocating memory every frame. BuffAPI.CreateValueBuff creates a buff with a mutable value: attach it to a stat once, then only call SetValue, and the stat refreshes in place.

    Behavior()
Property = {
  maxBonus = { type = "number", value = 0.5 },    -- 蓄满时伤害 +50% / +50% damage when fully charged
  chargeTime = { type = "number", value = 4 },    -- 蓄满需要的秒数 / Seconds to charge fully
}

local ChargedShot = class("ChargedShot")

function ChargedShot:OnVehicleReady(vehicle)
  self.weapon = WeaponAPI.GetWeapon(vehicle, 0)
  if self.weapon == nil then
    self.script:SetUpdateEnabled(false)
    return
  end

  self.charge = 0
  -- 挂一次，之后只改数值 / Attach once, then only change the value
  self.buff = BuffAPI.CreateValueBuff("Charged Shot", false, 0)
  self.weapon.DamageBuffedCoff:AddBuff(self.buff)

  -- 开火后蓄力清零 / Firing resets the charge
  WeaponAPI.OnFired(self.script, self.weapon, function()
    self.charge = 0
    self.buff:SetValue(0)
  end)

  self.script:SetUpdateInterval(0.1)
end

function ChargedShot:OnUpdated(dt)
  if not WeaponAPI.IsReloaded(self.weapon) then
    return
  end

  self.charge = math.min(self.charge + dt / self.chargeTime, 1)
  -- 数值没变时 SetValue 什么也不做 / SetValue does nothing when the value is unchanged
  self.buff:SetValue(self.charge * self.maxBonus)
end

function ChargedShot:OnDestroyed()
  if self.buff ~= nil then
    self.weapon.DamageBuffedCoff:RemoveBuff(self.buff)
  end
end

return ChargedShot

    要点：

    Key points:

    • CreateValueBuff 的第二个参数为 false 时是加法系数，0.5 表示 +50%；为 true 时是乘法系数，会和其他乘法 buff 连乘。

    • SetValue 在数值没有变化时什么也不做，所以可以放心地在 OnUpdated 里调用。

    • SetUpdateInterval(0.1) 让 OnUpdated 每秒只调用 10 次，dt 会是对应的间隔，蓄力速度不受帧率影响。

    • 不再需要这个 buff 时，用属性的 RemoveBuff 把它取下。

    • When the second parameter of CreateValueBuff is false, it is an additive coefficient, where 0.5 means +50%; when true, it is a multiplicative coefficient, which multiplies with other multiplicative buffs.

    • SetValue does nothing if the value has not changed, so it is safe to call within OnUpdated.

    • SetUpdateInterval(0.1) ensures OnUpdated is called only 10 times per second, with dt corresponding to that interval, so the charge rate is unaffected by frame rate.

    • When this buff is no longer needed, take it off with the stat's RemoveBuff.
