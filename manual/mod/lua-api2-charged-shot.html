    1. 导入脚本并绑定载具

    在 Lua 源码目录创建 ChargedShot.lua，复制下方脚本，按 Lua Hello World 导入 Unity。选中 VehicleTextData 的载具级 Lua 行为，将导入资产加到列表。若要在独立测试预制体上试验，可用 LuaBehaviorMono 的挂载方式，并让它位于载具层级内。

    保留 chargeTime = 4 秒和 maxBonus = 0.5。示例选择武器索引 0。需要另一个武器时，先用 WeaponAPI.GetWeaponCount 看可用数量，再修改索引。找不到武器或蓄力时长不大于零时，脚本停用周期更新。

    用 BuffAPI.CreateValueBuff 创建一个可修改的 Buff，挂到武器的 DamageBuffedCoff。第二个参数 false 选加法，数值 0.5 表示加 50%。传 true 时系数参与乘法叠加。保留同一对象，只在数值变化时用 SetValue 更新它，省去反复移除和创建。行为销毁时调用 RemoveBuff。

    Behavior()
Property = {
    maxBonus = { type = "number", value = 0.5 },
    chargeTime = { type = "number", value = 4 },
}

local ChargedShot = class("ChargedShot")

function ChargedShot:OnVehicleReady(vehicle)
    local weapon = WeaponAPI.GetWeapon(vehicle, 0)
    if weapon == nil or self.chargeTime <= 0 then
        self.script:SetUpdateEnabled(false)
        return
    end
    self.weapon = weapon
    self.damage = weapon.DamageBuffedCoff
    self.charge = 0
    self.buff = BuffAPI.CreateValueBuff("Charged Shot", false, 0)
    self.damage:AddBuff(self.buff)
    WeaponAPI.OnFired(self.script, weapon, function()
        self.charge = 0
        self.buff:SetValue(0)
    end)
    self.script:SetUpdateInterval(0.1)
end

function ChargedShot:OnUpdated(dt)
    if self.buff == nil or not WeaponAPI.IsReloaded(self.weapon) then
        return
    end
    self.charge = math.min(self.charge + dt / self.chargeTime, 1)
    self.buff:SetValue(self.charge * self.maxBonus)
end

function ChargedShot:OnDestroyed()
    if self.buff ~= nil then
        self.damage:RemoveBuff(self.buff)
        self.buff = nil
    end
end

return ChargedShot

    2. 按装填、蓄力和开火顺序试验

    1. 让武器完成装填。装填期间脚本跳过蓄力。
    2. 等约两秒后开火一次，再完整装填并等超过四秒后开火。可先临时记录 self.charge，确认它随 dt / chargeTime 增长，达到 1 后不再增长。更新间隔设为 0.1 秒，按收到的 dt 积累。
    3. 检查 OnFired 同时清零蓄力与 Buff 数值。移除脚本后再查看 Buff 是否已从武器移除。测试实际伤害时使用相同的弹种和目标，并保持命中位置一致。
