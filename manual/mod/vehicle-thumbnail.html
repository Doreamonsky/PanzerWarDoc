    渲染并设置载具缩略图

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run vehicle-thumbnail --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "vehicleInfo": "${fixture}/TutorialThumbnailInfo.asset",
    "source": "Packages/com.shanghaiwindy.coreresources/BuiltInVehicles/PatriotRadar/BuiltIn-Patriot-Radar",
    "thumbnail": "${fixture}/TutorialThumbnail.png"
  },
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}
    1. 保存手头的场景。在 VehicleData 的 Inspector 绑定主模型并设置缩略图的相机范围 thumbnailSize。数值越大，画面包含的范围越广，图像仍固定为 640 × 360。
    2. 点击 渲染缩略图。Unity 会切换到预览场景，在 VehicleData 同目录输出与主模型同名的透明 PNG，并将它导入为 Sprite。同目录已有的同名 PNG 会被覆盖。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:UnityEngine.SystemInfo/graphicsDeviceName"
    },
    "expect": {
      "contains": "(String)"
    }
  }
]
    点击展开 MCP 操作点击收起 MCP 操作

    先保存场景。将变量替换成自己的资产与输出路径。短等待后工具可能报告仍在运行，等待 PNG 导入后再查验。

    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.VehicleDataEditor/AsyncCreateThumbnail",
      "args": [
        "@asset:${yourVehicleData}"
      ],
      "timeout": 1
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:System.IO.File/Exists",
      "args": [
        "${renderedPng}"
      ]
    }
  }
]
    1. 打开 VehicleInfo 的流式缩略图字段，确认已经关联新图。编辑器根据 VehicleTextData 的 AssetName 查找要更新的 VehicleInfo。如果未匹配，手动赋图。也可以导入自己的 640 × 360 图片并赋给该字段。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "${source}.asset",
        "${vehicleInfo}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CopyAsset",
      "args": [
        "Packages/com.shanghaiwindy.coreresources/Editor/DocumentationSamples/vehicle-thumbnail/TutorialThumbnail.png",
        "${thumbnail}"
      ]
    },
    "expect": {
      "contains": "(Boolean) True"
    },
    "phase": "build"
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/AssetPathToGUID",
      "args": [
        "${thumbnail}"
      ]
    },
    "expect": {
      "contains": "(String)"
    },
    "capture": {
      "imageGuid": {
        "regex": "\\(String\\) ([a-f0-9]{32})"
      }
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicleInfo}/streamingThumnail/assetGUID",
      "value": "${imageGuid}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "asset:${vehicleInfo}/streamingThumnail/extra",
      "value": "${thumbnail}"
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.EditorUtility/SetDirty",
      "args": [
        "@asset:${vehicleInfo}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/SaveAssets",
      "args": []
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect",
    "arguments": {
      "path": "asset:${vehicleInfo}/streamingThumnail/assetGUID"
    },
    "expect": {
      "contains": "${imageGuid}"
    }
  }
]
