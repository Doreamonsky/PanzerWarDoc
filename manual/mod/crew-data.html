    前置：1. GetStarted 项目初始化

    1. 创建路径

    在 Project 窗口选择 Create > A Panzer War - 装甲纷争 > C Config - 配置 > Crew - 成员，创建后将资产改名为 Tutorial_CrewData。

    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:UnityEditor.AssetDatabase/CreateAsset",
      "args": [
        "@static:UnityEngine.ScriptableObject/CreateInstance(ShanghaiWindy.Core.CrewData)",
        "${asset}"
      ]
    },
    "expect": {
      "contains": "OK:"
    }
  },
  {
    "tool": "inspect_set",
    "arguments": {
      "path": "static:UnityEditor.Selection/activeObject",
      "value": "@asset:${asset}"
    },
    "expect": {
      "contains": "OK:"
    }
  }
]

    2. 身份与名称

    在 Inspector 填 分类（category）为 Tutorial、年龄（age）为 28，在 名称（crewName）折叠项里填写 默认名称（defaultName）为 Tutorial Commander。唯一标识（guid）在为空时自动生成一次，之后保持稳定，不要改写已发布的标识。下图 guid 9a719528-38a2-4fd4-8e70-f8f07dd56f81 仅为教学示例，不是官方 ID，也不要给所有资产复用同一个。

    3. 解锁与美术

    示例勾选 是否已解锁（isUnlock），设置 好感度上限（maxFriendship）为 100、好感度成长系数（friendshipGrowCoff）为 1。为 avatarTex（256x256 头像）与 inGameAvatarTex（360x720 战斗头像）选择实际贴图；需要皮肤时，可在皮肤条目中分别覆盖这两项。

    4. 增益与技能

    在增益分组把引用加入 buffRefs；在可升级技能分组（upgradableSkillContents）的 skills[] 中设置 crewSkillRef 与 friendshipRequirement。技能按槽位选择与好感度门槛生效；弃用的 buffs / skillBuff 不要新填。

    点击展开 MCP 操作点击收起 MCP 操作

    示例复制现有 Aino 的有效 SafeRef 配置，再放入一个友好度门槛为 0 的独立技能槽；不会改动来源成员。技能是否在游戏内生效仍需离线验证。

    5. 生效与排查

    当前增益与技能（含召唤）只在离线模式且 commanderCrewBuff 未关闭时生效；效果缺失时先检查离线模式与该开关。当前代码中 SummonSkillsOnline = false，这是代码里的固定属性，不是需要改动的 Inspector 设置。

    点击展开 MCP 操作点击收起 MCP 操作

    可在编辑器查询固定的联机规则。离线状态和 commanderCrewBuff 属于运行态条件，本配方不启动游戏，也不把此查询记作技能效果验收。

    [
  {
    "tool": "inspect",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.CrewData/SummonSkillsOnline"
    },
    "expect": {
      "contains": "False"
    }
  }
]
    点击展开 MCP 操作点击收起 MCP 操作

    运行时 MCP 映射（未执行）：在已安装模组的离线游戏会话中检查离线状态，以及 commanderCrewBuff 是否关闭。这些调用不属于编辑器配方。

    6. 打包与验证

    将 CrewData 资产加入构建管线的资源数组（字段 linkedObjects）。打包前设置有效头像；需要技能时，再配置相应引用和资源。构建会生成以指挥官 guid 命名的 crew bundle，以及对应的头像 avatar bundle。出包后请离线检查条目显示、头像、解锁状态和已配置的技能。

    共享配方已验证教学包的编辑器操作、Windows 构建、ZIP 清单与 sidecar；没有安装此包或执行游戏内技能验证。截图只说明字段位置。
