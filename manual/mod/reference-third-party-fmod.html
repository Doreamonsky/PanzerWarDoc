    26.6 Refer ThirdParty FMod 引用第三方 Fmod

    选择他人打包好的 Banks 文件。请注意，必须提供 master.bank 文件，Fmod 才能正常解析其他所有 Banks 文件。

    Select the Banks files packaged by others. Note that the master.bank file must be provided for Fmod to correctly parse all other Banks files.
