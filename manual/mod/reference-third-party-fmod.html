    在 Unity 引用第三方 FMOD Bank

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run reference-third-party-fmod
    1. 准备同一次构建生成的主 Bank、对应的 .strings.bank 和内容 Bank。使用与项目兼容的 FMOD 版本。
    2. 打开 FMOD → Edit Settings → Bank Import。单平台选择 Single Platform Build，指向该平台的输出目录。多平台选择 Multiple Platform Build，指向含 Desktop、Mobile 等实际平台子目录的父目录。
    3. 导入完成后打开事件选择器，检查要用的事件路径是否存在。
    点击展开 MCP 操作点击收起 MCP 操作
