    22.7.6 用例：引擎转速与起落架 Example: Engine RPM and Landing Gear

    坦克上的风扇随引擎转速旋转，转速很高时打开排烟；飞机的起落架放下时亮灯、收起时熄灭。同一个脚本可以挂在两种载具上。

    The fan on a tank spins with the engine RPM, and the smoke turns on at very high RPM. When the landing gear of an aircraft is deployed, the lights turn on; when it is retracted, they turn off. The same script can be attached to both types of vehicles.

    Behavior()
Property = {
  fan = { type = "object", value = nil },          -- 坦克：随转速旋转的风扇 / Tank: fan that spins with the RPM
  smoke = { type = "object", value = nil },        -- 坦克：高转速时打开的排烟物体 / Tank: smoke object shown at high RPM
  gearLights = { type = "object", value = nil },   -- 飞机：起落架放下时亮的灯 / Aircraft: lights on while the gear is down
}

local EngineAndGear = class("EngineAndGear")

function EngineAndGear:OnVehicleReady(vehicle)
  self.vehicle = vehicle

  if VehicleAPI.IsFlightVehicle(vehicle) then
    -- 飞机：起落架用事件，不需要每帧检查 / Aircraft: the gear is an event, no per-frame check
    if self.gearLights ~= nil then
      self.gearLights:SetActive(FlightAPI.IsGearDown(vehicle))
      FlightAPI.OnGearChanged(self.script, vehicle, function(isDown)
        self.gearLights:SetActive(isDown)
      end)
    end
    self.script:SetUpdateEnabled(false)
    return
  end

  if self.fan == nil then
    self.script:SetUpdateEnabled(false)
  end
end

function EngineAndGear:OnUpdated(dt)
  local ok, rpm, rpmPercent, gear, speedKmh, reversing = TankAPI.GetEngineState(self.vehicle)
  if not ok then
    return
  end

  -- rpm 是每分钟转数，每秒转 rpm * 6 度；0.1 是视觉上的缩放
  -- rpm is revolutions per minute, i.e. rpm * 6 degrees a second; 0.1 scales it down visually
  self.fan.transform:Rotate(0, 0, rpm * 6 * dt * 0.1)
  if self.smoke ~= nil then
    self.smoke:SetActive(rpmPercent > 80)
  end
end

return EngineAndGear

    要点：

    Key points:

    • TankAPI.GetEngineState 一次返回多个值：是否成功、转速、转速百分比、挡位、速度（千米/时）、是否倒车。不同的载具填写的值不同：履带车全部都有；轮式车只有开启变速箱时才有转速；舰船的挡位总是 1；固定载具的转速和速度为 0、挡位为 1。

    • 起落架用 FlightAPI.OnGearChanged 事件，不需要每帧检查，所以飞机上直接关掉 OnUpdated。

    • FlightAPI.IsOnGround 在起落架放下、机轮离地时会做一次地面探测，不要每帧调用；需要时降低频率。

    • TankAPI.GetEngineState returns multiple values at once: success status, RPM, RPM percentage, gear, speed (km/h), and reverse status. The values populated differ by vehicle: tracked vehicles have all of them; wheeled vehicles only have RPM when the transmission is enabled; ships always have a gear of 1; fixed vehicles have RPM and speed of 0, and a gear of 1.

    • Landing gear uses the FlightAPI.OnGearChanged event, so there is no need to check every frame; therefore, OnUpdated is disabled directly on aircraft.

    • FlightAPI.IsOnGround runs a ground check while the gear is down and a wheel is off the ground, so do not call it every frame; call it less often when you need it.
