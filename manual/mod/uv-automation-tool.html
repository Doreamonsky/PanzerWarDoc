    用 Blender 排布 UV 岛

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run uv-automation-tool
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {},
  "calls": [
    {
      "tool": "invoke",
      "arguments": {
        "path": "static:UnityEditor.AssetDatabase/CreateFolder",
        "args": [
          "${fixtureParent}",
          "${folder}"
        ]
      },
      "expect": {
        "contains": "(String)"
      }
    }
  ]
}
    1. 进入 编辑模式并选中要处理的面。在 UV 编辑器中选中对应的 UV 岛，点击 UV → 拼排孤岛（Pack Islands）。
    2. 设置合适的 边距（Margin）。烘焙或绘制前，检查所有 UV 岛都在目标图块内，并确认重叠是有意保留的。
    点击展开 MCP 操作点击收起 MCP 操作 
    [
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Editor.ShellEjectionAuthoring/FindBlender",
      "args": []
    },
    "expect": {
      "contains": "blender.exe"
    },
    "capture": {
      "blender": {
        "regex": "\\(String\\) ([^\\r\\n]+)"
      }
    }
  },
  {
    "tool": "invoke",
    "arguments": {
      "path": "static:ShanghaiWindy.Core.AssetBundleManager/LuaEnv/DoString",
      "args": [
        "local S = CS.System\nlocal tool = S.IO.Path.GetFullPath('../../Tools/ManualMcp/BlenderUV/verify_pack.py')\nlocal receipt = S.IO.Path.GetFullPath('${fixture}/uv-pack.txt')\nlocal info = S.Diagnostics.ProcessStartInfo()\ninfo.FileName = [[${blender}]]\ninfo.Arguments = '--background --factory-startup --python-exit-code 1 --python \"' .. tool .. '\" -- \"' .. receipt .. '\"'\ninfo.UseShellExecute = false\ninfo.CreateNoWindow = true\nlocal proc = S.Diagnostics.Process.Start(info)\nassert(proc:WaitForExit(15000) and proc.ExitCode == 0, 'Blender packing did not complete')\nproc:Dispose()\nreturn S.IO.File.ReadAllText(receipt)\n",
        "pack-uv",
        "null"
      ]
    },
    "expect": {
      "contains": "UV islands packed inside the tile"
    }
  }
]
