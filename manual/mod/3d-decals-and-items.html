    11.1 3D Decal / Item 贴花与装饰

    DIY Item Data

    For 3D Decal and Tank Workshop items

    适用于 3D 贴花与 坦克工坊 物体

    Ctrl + G to open the tool and create the DIYItemData

    按 Ctrl + G 打开工具，然后创建 DIYItemData

    The data should be configured like the following.

    数据应按如下方式配置

    The objects in the visual model file should be under an empty root. The components on the root will not be packed!

    视觉模型文件中的所有物体需置于一个空物体之下。根节点上的组件不会被打包！

    (If the object has a LOD group)

    如果物体包含 LOD 组，请按如下方式放置
