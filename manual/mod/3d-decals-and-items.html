    制作三维装饰件

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。 命令也会重拍两种语言的配图。

    python Docs/Manual/manual/tools/tutorials.py run 3d-decals-and-items --capture
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "item": "${fixture}/TutorialDecoration.asset",
    "visual": "${fixture}/TutorialDecorationVisual.prefab",
    "collision": "${fixture}/TutorialDecorationCollision.prefab",
    "hitbox": "${fixture}/TutorialDecorationHitBox.asset",
    "itemGuid": "728f6b42d4bf4915b234${runId}",

  "calls": [
    {

        "contains": "(String)"

    1. 在 Unity 中创建 DIYItemData，填写在坦克工坊里显示的名称。
    2. 为显示预制体保留一个空根节点。把网格、渲染器和其他需保留的组件放在子节点上。打包时工具会把子节点转到生成的预制体。使用 LOD 时核对生成后的层级和渲染器。
    3. 将显示预制体赋给显示模型。给伤害模型赋上包含有效预制体的 VehicleHitBox，点击 Pack 生成配件预制体。
