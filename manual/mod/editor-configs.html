    自定义内构模块预设

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run editor-configs

    伤害模型编辑器里的模块预设列表来自两个内置目录和一个本地配置数组。按下面的顺序放好模型并登记根目录，就能在编辑器里直接选到自己的内构模型。

    1. 建立模块目录

    在 SDK 工程里建立根目录和模块类型子目录，把模型直接放在子目录中：

    Assets/MyModulePresets/
  Engine/
    EngineA.fbx
  Crew/
    CrewA.fbx

    当前扫描逻辑只读取 <根目录>/<类型> 下的直接 *.fbx 和 *.prefab 文件，不递归子目录。类型目录名必须是 EInternalModuleType 的枚举成员名，区分大小写，例如 Engine、Crew、AmmoShell、Breech、Transmission；不是 Inspector 里显示的中文或 E 引擎 (Engine) 这类标题。

    目录名 模块
    Transmission 传动
    Engine 引擎
    HeatSink 散热器
    OilTank 油箱
    Traversing 方向机
    Breech 炮闩
    Elevator 高低机
    Sighting 观察镜
    AmmoShell 弹药架
    Crew 成员
    InternalArmor 内部装甲
    Radiator 雷达
    AutoReloader 自动装弹机
    OilPipline 滑油系统
    SurfaceControlRope 舵面控制钢索

    2. 准备模型

    模型根节点需要有可用的 MeshFilter 和共享网格。选中预设时，如果模型没有碰撞体，ModulePresetUtil.SetupModule 会在根节点添加 MeshCollider 并引用该共享网格，同时添加运动学刚体。网格为空时碰撞体也无法生成。

    也可以把模块做成预制体，以 .prefab 放在同一类型目录下。文件名只用于显示，不影响分类。

    3. 把根目录写进本地配置

    1. 打开 Framework → 1. Editor Tools，在 01. ♥ Core Tools 中打开 Editor Config。
    2. 在 模块预设文件夹 添加 Assets/MyModulePresets，只填写根目录。
    3. 点击 Save，保存到当前 Unity 工程的 Assets/EditorStorage.json。

    需要离线配置时，先退出 Unity，再备份并编辑这个文件。公开 SDK 中的路径是 UnityProject/Assets/EditorStorage.json。保留其他键，把根目录加到现有的 modulePresetFolders 数组：

    {
  "modulePresetFolders": [
    "Assets/MyModulePresets"
  ]
}
    • 只写根目录，不要带上 /Engine，结尾也不要加斜杠。
    • 保留文件中的其他键，不要用最小对象覆盖已有配置。
    • 如果还没有这个文件，先在 Editor Config 中保存一次。
    • 不要在 Unity 打开时改这个文件：EditorStorage.Save 会把内存里的整个对象写回，旧值可能覆盖你的编辑。

    4. 在伤害模型编辑器中使用

    1. 用 伤害模型编辑器 - HitBox Editor（VehicleHitBoxEditorWindow）打开目标载具，并进入该伤害模型预制体的预制体编辑模式；窗口不在预制体模式时只显示提示。
    2. 点 刷新预设 - Refresh，让扫描重新读取目录。
    3. 在 选择的模块类型 - Pick Module Type 里选目标类型。
    4. 找到对应缩略图。点缩略图只会定位资源；点缩略图下方的 选择 - Pick 才会实例化到当前预制体。
    5. 调整位置和尺寸，按 Ctrl + S 保存预制体。
    点击展开 MCP 操作点击收起 MCP 操作

    5. 排查

    现象 检查
    列表里没有自定义模型 根目录是否已写入数组；类型目录名是否与枚举名完全一致；模型是否是目录下的直接 .fbx 或 .prefab；改完后是否点了刷新
    有缩略图但选中后没有碰撞 模型根节点是否带 MeshFilter 和有效共享网格
    换了模型仍显示旧的 先按刷新预设，再重新选择；确认没有把文件放到子目录
    分类不对 文件所在的类型目录与 EInternalModuleType 成员不一致

    现成的示例目录

    当前代码还会扫描两个内置位置：Assets/Res/InternalDamage/Preset/<类型> 和 Packages/com.shanghaiwindy.middlesharedresources/SharedInternalDamage/Preset/<类型>（包名常量 PackageConst.MIDDLE_SHARED_RESOURCES）。可以按其中的文件了解命名和结构；中间共享资源包是依赖包，本地 Packages 目录里不一定有它的源码。

    相关源码：ModulePresetUtil.RefreshModuleMapping、ModulePresetUtil.AddModule、ModulePresetUtil.SetupModule、ModulePresetUtil.DrawModulePreset、EditorStorageInfo.modulePresetFolders、VehicleHitBoxEditorWindow.RefreshPresets、EInternalModuleType。
