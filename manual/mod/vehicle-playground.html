    在载具测试场调试

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run vehicle-playground
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    测试场在 Unity 内加载模组，让你快速检查当前载具，无需先在正式客户端安装。测试工程仅供调试使用，禁止重新打包分发。软件著作权归 WINDYVERSE PTE. LTD. 所有。

    1. 启动测试场

    1. 按绑定 Steam LuaProject配置 SDK 工程，然后保存当前场景。
    2. 在 Project 选中目标 VehicleData，在 Inspector 底部点击试驾（Drive）。刚改过模型、伤害模型或关键数据时，选择**试驾（重打包）**并确认。编辑器会为这辆车生成临时资源，再打开测试场并进入 Play。
    3. 单独打开测试场时，在 Framework - 框架 → 0. Home Page 点击 打开测试场。也可在 Project 双击 Packages/com.shanghaiwindy.middlelayer/Tools/RuntimeDebugger/VehiclePlayground.unity，检查下面的模式设置，再按 Play。

    2. 模块模式和血条模式

    1. 在 Edit Mode 的 Hierarchy 展开 RuntimeDebugTool，选中 Scripts。
    2. 在 Editor Mode Startup 组件找到 Damage Mode。保持默认 Module Based 可测试装甲和模块。测试未完成内构的载具时，用 Health Based。
    3. 进入 Play，选择要测试的车。检查移动和转向、炮塔和主炮动作。测试装甲或模块时，核对命中效果和预期部件。

    3. 退出并重新测试

    切回 Unity 工具栏，再点亮着的 Play 退出。旧教程画面会按 Alt 把焦点从 Game 视图释放出来。保留编辑后的数据再重打包试驾，确认测试场使用的是最新版本。
