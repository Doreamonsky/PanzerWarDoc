    1. 导入贴花图

    把图片放进 SDK 工程的 Assets。用作图案时可以保留 PNG 的透明区域。确认 Unity 导入的是纹理，先在 Inspector 检查透明区域和图案朝向。

    2. 创建贴花数据

    1. 在 Project 右键，选 Create → A Panzer War → D Decoration → Decal。也可打开随 SDK 提供的 Assets/Template-Decal 作参考。
    2. 在 VehicleDecalData 的贴图列表（Texture List）点 +。把刚导入的纹理拖进条目里的 Tex Prop 资源槽，为它填写显示名称。每张图一项。下方灰色的贴图字段显示旧格式的直接引用。
    3. Inspector 会为资产和贴图条目生成 GUID。更新已发布的贴花时保留原本的资产与条目。需要只让海外版本显示时，再启用仅限海外版本显示（Is OverSea）。

    3. 构建并安装

    将 VehicleDecalData 加到构建管线的 Linked Objects。随包的示范是 Assets/ModManager/BuildPipline-Template-Decal.asset 与 Template-Decal.asset。按项目初始化切到相应平台，先构建链接资源，再打包。安装后在载具的贴花列表核对显示名、透明边缘与贴花方向。
