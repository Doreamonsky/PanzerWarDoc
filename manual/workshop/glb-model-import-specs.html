    工坊 GLB 模型导入规范

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run glb-model-import-specs

    1. 准备外观和贴图

    在 Blender 先检查模型外观。PBR 示例使用基础色、金属度与粗糙度、烘焙环境光遮蔽以及法线；基础做法至少要基础色，法线可选。法线贴图走 Normal 输入。先预览，再用 Blender 减面或外部工具准备远景网格。 Blender glTF 说明 · InstaLOD Studio

    2. 布置导入用的层级

    在 Blender 用 Shift+A → Empty → Plain Axes 建四个空物体。导入器按网格的直接父节点分类，名称区分大小写。

    父节点 直属子网格
    Visual 外观网格。若有 LOD，把简化网格放在原网格下方。
    Collider 车体物理碰撞块。用简单的凸形块覆盖必要区域。
    HitBox 外部装甲。不同装甲厚度或类型分成独立网格。
    Module 低面数内构，用于穿透后的损伤。每件独立标明类型、厚度与耐久。

    沿用 Body_LOD0、Body_LOD1 到 Body_LOD3 这样的命名。把 Body_LOD0 直接放在 Visual 下，把其余 LOD 做成它的子物体，并从近到远排序。当前流程识别大写 LOD，按子节点顺序读取层级。会被炮弹击中的部件需要外部装甲和对应的内部结构，车体另配物理碰撞。 伤害网格命名

    Visual
  Body_LOD0
    Body_LOD1
Collider
  HullCollision
HitBox
  HullFront_65
Module
  Engine_40_10

    如果下载了源码并且终端可以找到 Blender，用下列命令生成这份教学文件：

    blender --background --factory-startup --python-exit-code 1 --python Docs/Manual/tutorials/glb-model-import-specs/create_sample.py -- Temp/ManualMcp/WorkshopGLB/Tutorial.glb

    3. 导出并导入工坊

    1. 在 Blender 选中需要导出的空物体及其子网格。用 File → Export → glTF 2.0，选择二进制 .glb，勾选 Selected Objects 后导出。
    2. Windows 在坦克工坊打开模型导入，选中 GLB 文件。选择器可直接触发导入，也可确认文件后执行 Import Mesh。
    3. Android 通过系统文件管理器用装甲纷争：决定版打开 .glb。再进坦克工坊的模型导入，填文件名及 .glb 后缀。应用从自己的 Installs 目录找文件。
    4. 导入后预览外观、碰撞和伤害组，检查炮塔等有活动轴的部件在旋转时仍能正确对齐。和已有部件配在一起后再保存和试驾。 工坊入门
    点击展开 MCP 操作点击收起 MCP 操作
