    坦克工坊入门

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run tank-workshop-basics
    点击展开 MCP 操作点击收起 MCP 操作

    准备教学样例。${变量} 由配方提供。

    {
  "variables": {
    "testPreset": "Tutorial ARL-44 (local test)",
    "partSet": "Tutorial ARL-44 Turret (local test)"
  },
  "calls": []
}

    从车库进入坦克工坊。新建车辆后，放入车体，选中车体的炮塔插槽装炮塔，再在炮塔的火炮槽装炮。把车体、炮塔和火炮分别设为主要部件。可以用同一套 ARL-44 Hull、ARL-44 Turret 和 90 MM DCA 45 练习。SDK 中制作独立载具的流程见坦克制作。

    1. 查看和调整配件

    旧版桌面快捷键如下，若你在游戏里修改过按键，以当前设置为准。触屏可用界面上的对应工具。

    默认按键 操作
    W A S D、Q E 相机前后左右移动、升降
    1、2、3、4 插槽、移动、旋转、缩放
    Ctrl+Z、Ctrl+Y 撤销、重做
    Ctrl+C、Ctrl+V、Ctrl+X 复制、粘贴、剪切

    先在槽位模式选中配件，再在需要时用移动、旋转或缩放调整。误操作后可撤销，再从另一角度检查位置。

    2. 换车体并保留炮塔

    在原车上选中炮塔，点击复制。换到目标车体后选兼容槽位并粘贴。需要重复使用或跨存档转移时，先点存为部件组，再在目标车体放置该组。检查炮塔仍带有原来的火炮和子配件。复制出的配件会清除主要标记，分别选中炮塔和火炮，用 设为主要 重新指定。

    3. 保存和试驾

    先保存为独立方案，再点击试驾。起步、刹车、转向、瞄准与试射各做一次。点击停止扮演可以回到工坊继续调整。没有有效保存或部件未完成时，先补齐车体、炮塔、主炮和槽位。

    工坊的可回放入口包括 vehicle_catalog、vehicle_rules、vehicle_equip、vehicle_part_set_save、vehicle_part_set_place 与 vehicle_save。用它们复现时先确认当前是独立测试方案。

    点击展开 MCP 操作点击收起 MCP 操作
