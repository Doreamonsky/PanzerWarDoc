    在坦克工坊配置程序化履带

    中文 | English

    在仓库根目录运行以下命令，用本机 Unity MCP 回放本页示例。

    python Docs/Manual/manual/tools/tutorials.py run track-editor-tutorial

    1. 选择程序化履带车体

    新建车辆后在车体列表搜索 Procedural Track（程序化履带）。示例来自 Vehicle Extension Pack (III)，它本身是车体，有一个炮塔槽。选中车体，从右侧检查器的轮子和履带类别调整参数。先让负重轮贴合车体，再核对托带轮、主动轮、诱导轮和履带环路。

    负重轮可调整数量、半径、宽度、间距和位置。先把数量从 5 改为 6，转到侧视图检查环路没有穿入车壳，接地部分覆盖轮组。需要轮式车辆时，单独回查轮胎组、驱动和转向设置。

    2. 检查碰撞

    在程序化底盘上制作自己的车壳时，可用 Editable Poly 配件补碰撞。选中多边形配件，在它的设置中开启碰撞。观察碰撞轮廓是否贴着车身，避免车底大块碰撞先碰到地面而使负重轮悬空。不同的碰撞形状会改变车辆在坡面和障碍上的行为。 多边形编辑

    3. 调重心并试驾

    在车体／机动设置里检查重心，把它放在车体和左右负重轮之间。若起步、转向或通过斜坡容易倾翻，可逐次少量下调。保存方案，用同一段平地和坡道测试转向、制动及接地，再决定是否需要改悬挂。

    工坊回放先用 vehicle_rules 找配件，再用 vehicle_props 读当前版的字段结构。用 vehicle_set_props 只改需要的字段并重新读取确认。Unity SDK 的履带和 WheelCollider 单独见履带 IK与载具制作。

    点击展开 MCP 操作点击收起 MCP 操作

    在新建的工坊测试载具上回放。该组验证负重轮与重心参数，试驾和多边形碰撞按正文另行核对。

    "tool": "vehicle_new",
    "arguments": {},
    "expect": {
      "contains": "ok new vehicle"

  },
  {
    "tool": "vehicle_catalog",
    "arguments": {
      "type": "hull",
      "search": "Procedural Track"
    },
    "expect": {
      "contains": "1dae31c6-7e26-483d-8a88-4dd5ec25b830"
    }
  },
  {
    "tool": "vehicle_equip",
    "arguments": {
      "itemGuid": "1dae31c6-7e26-483d-8a88-4dd5ec25b830",
      "slotIndex": 0,
      "isMain": true
    },
    "expect": {
      "contains": "built=True"
    },
    "capture": {
      "track": {
        "regex": "ruleGuid=([\\w-]+)"
      }
    }
  },
  {
    "tool": "vehicle_props",
    "arguments": {
      "ruleGuid": "${track}"
    },
    "expect": {
      "contains": "roadWheelNumber"
    }
  },
  {
    "tool": "vehicle_set_props",
    "arguments": {
      "ruleGuid": "${track}",
      "json": "{\"roadWheelNumber\":{\"isEnabled\":true,\"value\":6},\"centerOfGravityHeight\":{\"isEnabled\":true,\"value\":0.45},\"centerOfGravityForward\":{\"isEnabled\":true,\"value\":0.05}}"
    },
    "expect": {
      "contains": "rebuilt"
    }
  },
  {
    "tool": "vehicle_props",
    "arguments": {
      "ruleGuid": "${track}"
    },
    "expect": {
      "contains": "\"roadWheelNumber\":{\"isEnabled\":true,\"value\":6}"
    }
