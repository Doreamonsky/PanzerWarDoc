    Manual maintenance instructions

    Docs/manual is the source of truth for the Panzer War manuals. Yuque is no longer available and must not be treated as an upstream source.

    Before editing

    1. Find documents by title in toc.yml; legacy exported filenames are hashes and should not be guessed.
    2. Search the complete manual before adding a new page. Older pages may use a renamed title.
    3. Run python tools/test_manual.py to inspect link health.

    Editing rules

    • Use relative Markdown links for all manual-to-manual references. Do not add Yuque article links.
    • Store page images in the section's imgs/ directory and reference them relatively.
    • Do not rename legacy hashed Markdown or image files unless every reference and toc.yml entry is updated in the same change.
    • New hand-authored pages use readable lowercase kebab-case filenames.
    • Add every navigable page to toc.yml.
    • Keep Chinese and English text when both already exist. Do not fabricate missing historical content.
    • When an old link points to content merged into another page, link to the surviving page or heading and record the decision in legacy-yuque-links.json.
    • Missing binary details and original Yuque URLs live in legacy-yuque-attachments.json. Keep the visible missing-attachment marker until a verified local replacement is available.

    After editing

    Run:

    python tools/test_manual.py

    Use --strict only after all missing items in RECOVERY.md have been recovered or intentionally retired. --fix reapplies the recorded legacy mapping when old exports or copied text introduce Yuque links.
